## 回归验证

- 服务 TypeScript 构建通过；原有 11 组离线测试共 541 项断言通过，覆盖歌词、旋律、织体、技法、MusicXML、音素、音符生成、速度图及音频转换。
- 新增依赖兼容回归 10 项：8 / 12 / 64 / 6144 点 FFT 与旧版结果比较及正逆变换，cwise 数组计算和固定脚本转换后的执行结果。未下载模型或执行模型推理。
- static-module 3 的安全求值机制会使部分含函数的 browserify 片段保留运行时调用，而非旧版内联；回归验证了固定样例的执行结果。插件使用 Node 服务，不宣称旧 browserify 输出逐字节一致。
- 插件集成与最终打包检查另记于 [测试说明](testing.md)。模型驱动的跨客户端音乐编辑、听感及未验收宿主不由依赖审计代替。

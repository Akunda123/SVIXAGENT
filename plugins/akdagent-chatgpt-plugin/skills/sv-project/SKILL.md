# 工程文件与迁移

按[资料读取说明](../../docs/references.md)调用 `akdagent_read_reference`，先读 `sv-project-format/SKILL.md`；有实际版本结构疑问再查原仓库相应版本的工程格式对比。确认源文件、目标宿主、目标轨道和输出路径，原文件不覆盖。

磁盘编辑无需桥，但不能在宿主打开同一文件时静默改其磁盘副本并期待界面自动更新：先保存/关闭或另存，再改副本并重载。用户要求实时看到修改时优先通过 `sv-live` 对宿主内存工程编辑。实时编辑与离线格式转换不能混为一谈。

验证轨道/音符数量、歌词、onset、时值、音高和所改参数的差异。新格式是结构正确不等于在 SV2 中声库可用；语言、Vocal 身份和音频路径需实际打开复核。对未知格式先读取证据，不猜字段。仅诊断请求不实施修复。

跨客户端读取：无法访问本地文档链接时，用 akdagent_read_workflow 读取 docs/runtime.md、docs/references.md 或关联的 skills/<名称>/SKILL.md；按 nextLine 分页直到完整读完。工具命名空间由客户端决定，以业务名称识别。

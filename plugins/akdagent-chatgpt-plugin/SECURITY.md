# 安全与隐私 / Security and privacy

这是具备读写能力的本地工具集，不是只读查看器。上游工具包含文件、工程编辑和 Lua 脚本执行；技能中的操作规范不是技术沙箱，不保证拦截所有错误操作。仅授权可信客户端，勿将 stdio 适配器随意暴露为网络服务。

适配器本身不收集遥测、不读取 AKDAgent 模型聊天的 API key，也不发起模型聊天请求。工具结果（例如路径、歌词、工程信息）会进入所选客户端会话并按该客户端及模型服务的数据政策处理。编辑工具可具有文件访问、网络或模型相关能力，以实际工具列表为准。

`akdagent_read_reference` 仅允许选定上游技能目录内的 Markdown/JSON，检查真实路径、扩展名、大小与分页范围。它不是任意文件读取接口。完整原版工具集仍保留其自身权限边界。

运行时路径是受信任代码来源。不要指向未知目录；只从可信上游安装 AKDAgent。编辑前另存副本、写后读回、试听后保存；桥超时先确认状态再重试。

反馈时只附脱敏版本号、错误与最小复现；勿上传 token、完整用户目录、私人歌曲或声库。安全敏感问题不要在公开 issue 粘贴敏感数据，应先使用仓库当前公布的私下联系渠道；若无此渠道，公开报告只说明需要安全联系方式。

## 锁定依赖审计（2026-10-07）

对本次固定 AKDAgent 源码的服务锁文件执行 `npm audit --omit=dev`，报告 14 项受影响依赖：3 moderate、7 high、4 critical，包含间接依赖及风险传播项。这是依赖审计结果，不是本插件漏洞可达性或完整安全审计结论；目前没有逐项证明其调用路径可达或不可达。

本次没有执行自动修复或更换 AKDAgent 的锁定依赖，避免未经回归测试改变编辑实现。0.3.0 安装包以预览版分发，并在 PR 中告知维护者，依赖升级与安全回归需后续处理。不要将服务暴露到网络、启用不可信客户端，或用未核验的外部文件/脚本进行敏感任务；工作流提示不能作为安全隔离。

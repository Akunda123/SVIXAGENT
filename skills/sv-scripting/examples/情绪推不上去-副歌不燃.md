# 案例：情绪推不上去 —— 副歌燃不起来、抒情段不动人

> 分类：动态 / 段落设计 ｜ 症状：副歌又响又亮却毫无爆发感、抒情段没味道、两段主歌一模一样

## 问题

- 副歌的张力已经叠到顶，声音很响很亮，可就是没有力度、没有爆发感；再往上加只会变电音。
- 抒情主歌听着"没什么感觉"，明明参数也画了。
- 整首歌从头到尾情绪一个样，两段主歌处理完全相同，听一半就腻。
- 该起来的地方起不来，该收的地方收不住。
- 脑子里有画面，但翻译不成参数。

## 诊断

**核心误判：把"力度"当成了"张力"。**

> 力度不是靠张力一个参数堆出来的。**Pit 画得平，就算拿到最强的 power 声库也未必有力度。**
> 反过来，张力一旦拉满，再叠只会换来一个电音满满的声音。

逐条查这八项，前四项是主因：

1. **Pit 的技巧密度不够。** 每一种力度表达，背后都有一套固定的 Pit 图形；不是"画个参数"力度就出来了，没这么简单。
2. **没做段落规划。** 张力会不由自主地越画越高，等写到副歌已经没有上升空间了。
3. **主歌就把真声顶满了。** 主歌力度拉满，副歌拿什么往上加。
4. **动态和 Pit 没绑在一起。** 只画音高不画动态、或者只画动态不画音高，力度都是假的。
5. **辅音的动态没人管。** 元音有动态了，轻辅音还停在原样，柔和的旋律被辅音毁掉。
6. **参数互相打架。** 想表达"哀"，Pit 却画得铿锵有力；想表达"燃"，还在画很细腻扭捏的动态，力度立刻掉下去。
7. **同一套技巧从头用到尾。** 两段主歌处理完全一样，第二段没给出任何新东西。
8. **动态幅度不够大。** 混音里的压缩会把动态压得很死；编曲越满越燃，动态越要画足，否则最后被压扁。

## 怎么改

### 第一步：动手画线之前先做段落规划

这一条是本案例的关键。给每个段落定一个**力度区间**，然后整段整段地把张力（AI 库用音区偏移）压到位，而不是逐句即兴地往上加。

规划时要同时想清楚四件事：这段打算给多大力、Pit 的技巧要多密（少而精还是又多又夸张）、动态画粗还是画细、咬字口型收着还是放开。四件事是配套的——副歌如果选了"大力度 + 密集 Pit + 粗动态 + 大口型"，主歌就必须在每一项上都留出余量，否则副歌无处可去。

**最容易踩的坑是主歌不留余量。** 主歌的真声一顶满，副歌只能靠加参数硬顶，结果就是电音。该转假声的高音就转，给后面留空间。

> 逐段的力度区间建议值见 `references/07-melody-accent-pitch-params.md` §3.5。

### 第二步：先加 Pit 技巧，再动张力

重音的做法是有固定模式的：音头先往下沉一点，接一个小幅的音头浮动（快速冲上去再落回），随后跟一段频率偏高、逐渐收掉的颤音。张力在音头之后立刻收下去，响度在音头处加重，后段用发声收到几乎只剩气声。**前提是前一个音的音尾必须先画下去**，否则音头顶不出来。

> 完整的五件套配方（Pit + 张力 + 响度 + 发声 + 气声）见 `07 §3.4`；本步只强调顺序：**Pit 在前，参数在后**。

- 低音区的采样声库，只画张力真的听不出来，**必须配响度**。
- AI 库上张力画小了无效、画大了嗓子立刻哑 → **改用音区偏移打底**，力度还不够再补一点点张力。

### 第三步：副歌张力已经拉满时的四条出路

1. **挑一两个字让它突然落下去。** 别的字都画得很满，就这么一个字往下掉，分界感立刻出来。
2. **把某些高音改成假声。** 假声夹在一堆真声里，反而会被凸显。
3. **一堆高音里突然出现的低音，把它的力度降下去。**
4. **真正的解法是回头把 Pit 技巧加上去**：音头再往下沉一点、音高浮动开大、颤音幅度加大，转音那几处浮动做得夸张些。

### 第四步：抒情段要"一个字一个字往前送"

抒情段的通用形态是**逐字弱起再往上推**——像拉弦乐器那样，每个字都有自己的起势和落点。带转音的字，先在转音处弱下去，再推上来。

**转音处挖坑**是抒情段的核心手法：画一个向下的小三角，不挖坑听起来自如放开，挖了坑更收敛更深情，**坑越深越哽咽**。用哪个参数挖坑听感不同：只画响度像"用力收起了嗓子"，只画发声像"嗓子哑了一下"（更适合哽咽），两者配合则是折中。

整段落到极弱时，**辅音的响度也要跟着拉低**——元音已经很轻、辅音还很响，就变成辅音在打耳朵。句尾需要泄力时，补一个很短的 `hen` / `heng`，把发声拉到 0 收出去。

### 第五步：段落对比——加法做不下去就改用减法

第一段已经调满、第二段加不上花时，别硬加。**反过来做**：先在第二段把所有合适的技巧都用上，再回头把第一段里这些技巧**弱化**，层次感自然出现。

其余几条同样有效：

- **同一句在两段用不同技巧。** 情绪可以一样，手法必须换（一段让颤音一路往上飘，另一段让幅度逐渐涨起来再收住）。
- **咬字也分层。** 第一段该收的口型全收，第二段再放开、换成开口更大的字。
- **弱段里埋一个亮点。** 全曲最弱的段落里，挑一个字让它突然抬高（照旧用假声、张力照旧拉到最底），先蓄力、再夸张地冲上去，然后滑回来——"平静中暗潮涌动"。否则整段一路弱下去会很无聊。

### 第六步：让所有参数指向同一个方向

调之前先定这一句的情绪，再逐个检查张力、Pit、气声、响度、颤音是不是都指向这个情绪。**所有参数应该往同一个方向使劲。**

- **大气与细腻不可兼得。** 最有爆发力的段落，真人歌手唱到那里也是在拼尽全力，根本细腻不起来。除了个别字拿假声 / 颤音 / 弱处理顶一下，其余就是一条线拉到底。潇洒爆发段还画很细腻扭捏的动态，力度一下就掉下去。
- **动态要画得比心里想的还大。** 混音里的压缩会把动态压平；编曲很满很燃时再不动手画动态，最后声音就被压扁了。

## 改后效果

- 副歌不靠堆张力也有爆发感，力度由 Pit 撑起来。
- 段落之间有明确的层次，从主歌到副歌是一条能感知到的上升曲线。
- 两段主歌不重复，第二遍有新东西。
- 抒情段每个字有推进感，转音处有哽咽的层次。
- 情绪落点清晰，听得出哪一句是重点。

## 可复用判断标准

1. **力度 ≠ 张力。** 副歌不燃，先回去看 Pit 的技巧密度，而不是先加张力。
2. **张力有天花板。** 一旦拉满，再叠只会出电音；此时要么加 Pit 技巧，要么用"挑一两个字落下去"做对比。
3. **先做段落规划再画线。** 没有力度区间规划，张力一定会无意识地一路走高。
4. **参数必须同向。** 出现"想哀却画得铿锵""想燃却画得扭捏"这类互斥，说明这一句的情绪还没定清楚。
5. **一个段落只需要一种气质。** 爆发段就粗线条拉到底，细腻留给抒情段；两边都要，结果两边都不像。
6. **动态宁大勿小。** 判据是"混音压完之后还听不听得出来"，而不是"我画得够不够含蓄"。
7. **段落对比优先用减法。** 当"加"已经加不动时，把前一段的同类技巧弱化，比继续堆新技巧有效。
8. **抒情歌不要用重音型唱法。** "音头重、音尾越收越小"是重音型；抒情歌反过来，音头要轻、逐字往上推。
9. **别闭门造车。** 没思路就先去听原唱、翻唱、同曲风的参考，再动手。

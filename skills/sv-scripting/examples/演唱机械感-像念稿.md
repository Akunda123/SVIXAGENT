# 案例：演唱机械感 —— 像念稿，没有人味

> 分类：Pit / 动态 / 咬字节奏 ｜ 症状：音准对、参数也画了，但一听就是"软件在唱"，一串等长音符上尤其明显

## 问题

一段调完，音准全对，参数栏里也画满了线，可听感就是"机器在唱"：

- 字与字之间没有起伏，每个字的进入方式一模一样，节奏死板，像在报菜名。
- 一串等长的八分音符主歌最明显——每个字听着都像复制粘贴。
- 段内只有"一个音色"，明暗层次完全靠段落切换来体现。

## 诊断

按这个顺序查，**前三条命中率最高**：

1. **音头的 Pit 从来没处理过。** 打开工程逐个看音头会发现：没有任何参数时，每个字的音头也自带一小段滑入——上扬或者下沉，而且取决于它前面的那个音。**这是引擎替你决定的，不是你的设计。** 后果是同一个乐句里有的字在撒娇、有的字在使劲，情绪互相打架。这条是机械感最大的来源，也是新手最普遍忽略的一条。
2. **辅音长度全是默认值。** 真人唱起来，辅音本来就长短不一：踩在重拍上的字辅音长、落在弱拍上的字辅音短，咬字的节奏感与呼吸感就是这么来的。一整句辅音一样长，咬字必然死板。
3. **张力只有两档。** 主歌一段整体压低、副歌一段整体拉高，段内是一条直线。听感就成了"只有两种音色的层次"。
4. **Pit 整体太平。** 人说话时几乎不出现完全平直的音高，大量滑音与微小浮动构成了语音语调；而 Pit 平直这件事，本身也是电音感的来源（→ `examples/电音感与音色突变.md`）。
5. **完全没加呼吸音和尾息。**
6. **采样库层面的干扰没关掉**：自动抖动开着、音符属性里的颤音深度还是原值，音高就会被采样自身的漂移带着跑，听起来又机械又发飘。

## 怎么改

### 第一步：先清理默认状态

这一步不做，后面的力气都落不到实处。要清的是四样：全选音符把颤音**深度归零**；关掉自动抖动（采样库需要，AI 库影响不大）；在歌手属性栏里把颤音起始位置拉满；把钢琴卷帘窗上方的显示开关全打开（波形、音素位置，以及 Pit 渲染）。

### 第二步：逐个音符处理音头 Pit

从头到尾过一遍，把不需要的自带音头**抹平**；需要力度、需要强调的字，主动画**音头下沉**。

这里有一条不能违反的位置规则：**下沉段画在前一个音的音尾，或者画在本字的辅音段上；元音起点必须已经回到标准音高。** 画在本字的元音上会得到一个"不像人唱的"东西，是音头处理里后果最严重的一种错法。幅度从 **3 个半音左右**起步就够。

另外两条配合作业：

- 想让某个音头凸显出来，**前一个音的音尾必须适当画下去**，否则顶不出来。
- 如果这个字以 `w` / `y` / `m` / `n` / `l` / `r` 打头，那段下沉就必须一路推到辅音起点之前，好让整个辅音段都从低处往上走；只覆盖元音段会变成"先下来再上去"的怪音。

**音头上扬只作偶尔点缀**，下沉的用量可以是上扬的好几倍。

### 第三步：给辅音做长短节奏

- 踩重拍的字辅音拉长，落在弱拍的字辅音缩短；一拍里塞两个字的，第二个字再短一档。
- 前一个字要做渐强，后一个字的辅音就必须缩，给力度留空间。
- 抒情段里 `/s/` `/x/` `/sh/` 一类摩擦音统统压短，咬字才连得住。
- 复元音内部怎么分配时长：`ai` 里的 `i` 只在最后一个瞬间点一下，主要时长留给口型大的那个音素。

### 第四步：在等长音符段落上人为制造差异

- 挑一两个字做明显的强弱对比，其余一律不动。**弱音放在一句最后的短促音符上**效果最好。
- 挑一两个字加颤音（其余保持直音），或者在音尾加一个深度小、频率偏高的颤音。
- 上行的字加一点滑音，增加诉说感——但一句里点一下就够，**滑音一多就非常油腻**。
- 别忘了转音：通俗抒情歌要是完全不转，唱出来就是直来直去。前倚音用得最多，哪儿都能加一点。

### 第五步：动态往细里做

段落的整体张力只是框架，**段内必须逐字调**。抒情歌的通用形态是每个字弱起再往上推；带转音的字，在转音处先弱下去（挖坑）再推。挖坑用哪个参数听感不同：只动响度，像用力把嗓子收住；只动发声，像嗓子哑了一下。按需要挑。

**辅音的动态也要跟着做。** 做渐强时轻辅音要跟着弱下去，否则元音有动态了、辅音还在捶耳朵。

### 第六步：加呼吸

该换气的地方加呼吸音，注意让它在下一个字的**辅音开始之前**结束，中间留一点点间隔。需要泄力收尾的句尾加尾息：补一个很短的 `hen` / `heng`，把**发声**拉到 0，再用响度微调力度。

## 改后效果

- 每个字的进入方式都不一样，句子有了推进感和落点。
- 咬字有了节奏感与呼吸感，不再是一串等间距的字块。
- 段内有明暗层次，不再是"主歌一个音色、副歌一个音色"。
- 换气点自然，听起来是一个人在唱，而不是一段音频在播。

## 可复用判断标准

1. **机械感先查音头 Pit，再查别的。** 引擎自带的滑入不是你的设计；把它留着，这个字表达的情绪很可能和你想的正好相反。
2. **音头下沉的位置不能错。** 只能落在前一个音的音尾或本字辅音段上，且元音起点已回到标准音高。这是全局最严重的一条错法。
3. **等长音符段落必须人为制造差异。** 挑一两个字做对比就够了，其余不动；全动一遍反而乱。
4. **强效果用量克制。** 每个字都加颤音、每个字都加滑音，会从机械变成油腻加审美疲劳。**动态比颤音重要得多**——抒情段开头几个字完全可以不加颤音，光靠动态意境就出来了。
5. **张力是动态主力，响度是辅助。** 拿响度当主力用，会变成"人声忽大忽小，像麦没拿稳"。
6. **音头下沉别画得太夸张。** 每个字都像被猛地掼下去再拽起来，攻击性过强；简单的下沉 + 转音浮动 + 小颤音这个组合就够了。
7. **呼吸音要在辅音之前结束**，中间留一点间隔，否则会吃掉下一个字的字头。

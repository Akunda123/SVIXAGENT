# 案例：电音感与音色突变 —— 参数一画就炸

> 分类：Pit / 参数 ｜ 症状：整体听着"电"、某个字抽一下像打嗝、张力一画就发哑或变尖、音色在某处突然跳变

## 问题

- 整体听着"电"，像挂了效果器，可什么都没加。
- 某个字突然"抽"了一下，像打嗝、像抽搐。
- 张力一往上画声音就变尖变电，往下一画又发哑、像卡了痰。
- 高音一上去就刺耳。
- 音头一画就炸，或者音头处有个"爆"的一下。
- 参数明明画得很小心，效果还是很突兀。

## 诊断

"电"不是一种病，**有五个互不相干的来源**。定位错了，改半天也改不掉：

| 现象 | 来源 |
|---|---|
| 整体发电、平淡 | **Pit 太平直**——最常见，也最容易被忽略的一条 |
| 某个字抽一下、像打嗝 | **Pit 拐得太陡**；或者几套密集技巧（音头浮动、转音、颤音）抢在同一小段时间里，彼此打架 |
| 高张力处发电 | 张力拉得太高，同时 Pit 又平 |
| 声音发哑、像卡痰 | **AI 库的张力压到了 0 以下**——AI 上这不是"自然变弱"，而是音色直接变哑 |
| 音色在某一处突然变脸 | **张力跨过了 0 这条线**——它是分界，跨过时音色不连续 |
| 高音刺耳 | 张力过高，或者声库共振峰本来就偏高 |
| 接缝处跳到别的音高 | 拆轨时两条轨的 Pit 没对齐 → 见 `examples/拆轨拼接处断开或跳音.md` |
| 采样库的呼吸音很电 | SV 处理采样库呼吸音的方式本身就不够好 |

## 怎么改

### ① Pit 太平直 → 给它加变化

人说话时几乎不出现完全平直的音高，大量滑音与细微浮动正是语调的来源；Pit 一旦全平，听感必然像机器。

逐字补音头（以下沉为主）、音尾、必要的转音、适量的滑音；通俗抒情歌必须加必要的转音，不加就直来直去。

**"高张力 + 平 Pit"是最电的组合**：把张力降一点，同时把 Pit 的变化补上，电味立刻退掉。反过来，如果**就是要机械感**，那就让 Pit 保持平直、把所有音高变化的幅度压小。

### ② Pit 太陡 → 收敛

- **觉得整体用力过猛时，先把 Pit 的整体程度砍到一半**——多数"抽搐"的作品到这一步就恢复正常了。
- **音头那一下的尖锐度要压住**：下拉音头确实给力度，可每个字都做成打嗝的样子就过了。
- **密集技巧区要检查趋势是否连贯往复。** 把颤音、音头浮动、转音在时间上**错开**，安排好各自的出现时机与时值——它们同时压在一小段里，就是那个"抽一下"。
- **真假声切换的陡峭度有上限**：可以做得陡，但必须保留一点斜度，完全垂直的跳变就是电音。即便是约德尔那种极端跳法，也只允许把**前一个音符**的变化时长压到 0，而**后一个音符**仍要给一个极短的非零值，否则照样电。
- **哭腔只在音头上点一下。** 时值一长、幅度一大，音高辨识就会被严重破坏（"蓝色是忧郁"会听成"烂色是有余"）。
- **音头要是向上跳了个小八度，那不是情绪，是触电。** 极短时值里跨六到八度必然不自然；普通的音头突出给到 3 个半音左右就够了。

> "Pit 直上直下只允许在三种场合出现"以及幅度 / 时长的判据见 `07 §2.6`。

### ③ 张力穿过零点 → 画成 S 形过渡

0 这个值把张力切成两半：**负侧的变化比正侧敏感得多**，而且跨过去的时候音色是不连续的。

**解法的核心是"别用直线穿过去"**——接近 0 时把曲线画成 S 形，听感会顺很多。

### ④ AI 库张力发哑 → 改用音区偏移打底

AI 库上的零点突变比采样库更明显，而且一旦压到 0 以下，拿到的不是"变弱"而是"变哑"，像喉咙里卡着痰。补救方向按优先级排三个：

1. **改用音区偏移来压低**（AI 上它比张力顺滑得多，基本没有突变点）——**首选**。
2. 换一条更软的声线。
3. 音区偏移与张力各给一点，互相配合。

⚠️ 别忘了音区偏移自己的限制：低音区反馈不明显（必须配响度）、高音区画着画着会掉进假声、会改变咬字口型、连续转音要改用响度 / 发声 / 张力、浊辅音上要画得平缓（→ `07 §3.2h`）。

**AI 上的张力坑要画得更收敛**：在转音处用张力挖坑，AI 会出类似沙哑的声音——如果想要的正是哽咽感，这反而是红利，只画张力就有很好的效果；但幅度要留小，太大声音会突然哑掉。

### ⑤ 声库敏感度不同 → 调整画法的精度

**规律：声库录得越明亮、越强硬，张力反馈就越敏感、越难控；越软、越暗、越弱，张力画起来越顺滑。** 反过来说，音色越亮，对张力越敏感。

- 明亮 / power 型声库：把参数栏拉开，画细一点，小幅度地动。这里没有捷径。
- 同一声库内部的声线也一样：明亮系（bright 与 solid 这一类组合）反馈不顺滑，换成气声系会顺一些。
- 暗系声库反过来：张力反馈不明显，要多用响度配合才做得出动态。

### ⑥ 高音刺耳 → 张力 + 性别参数

- **把张力降下来，同时把性别参数往上调一丢丢**（偏移量控制在小范围内，声线才保得住）。
- 或者用音区偏移把这一段挪到声库更舒服的音区。
- 或者后期用动态 EQ 配压缩，把鼻音最爆的那一段压下去。
- 高音开头的辅音太大声也会"炸" → 把辅音那一小段用**发声或张力**压下去。

### ⑦ 音头爆一下 → 用发声，不要用响度

某些声库的采样音头会"爆"一下。如果不想连带影响整体的辅音与气声，就**用发声去拉那一小段，别用响度**。

### ⑧ 呼吸音很电 → 换做法

- 采样库的呼吸音在 SV 里偏电。可以不在这里加，改到后期混音时在音轨上贴呼吸音频。AI 库的呼吸音就没这个问题。
- AI 库在**极短空拍**处直接写 `br` 会出难听的气泡音或卡顿 → **换成 `sil`**，呼吸音另拆一轨放。
- 做**带音高的抽气**时，**张力和气声都要拉到底、只留基频**，否则一定电。

### ⑨ 无效调参也会制造问题

- **轻辅音上画张力完全没有效果**（张力只对谐波起作用）。白干，还增加工作量。
- 呼吸音上是纯噪波、没有音高，在它上面画 Pit 毫无意义。
- 觉得已经没有效果了还硬画，只会让参数越堆越乱。

## 改后效果

- Pit 的变化连续、顺滑，既不呆平，也不抽搐。
- 张力穿过零点时音色平滑过渡，没有跳变。
- AI 库在弱段用音区偏移打底，声音是"变弱"而不是"变哑"。
- 高音不刺耳，音头不爆。
- 整体听感是人在唱，不是效果器在响。

## 可复用判断标准

1. **先查 Pit，再怪声库。** 大部分"电"只是 Pit 太平直；把电音感归咎于音质或声库之前，先看这一条。
2. **电音和机械感是一对反方向的病。** 为了消电音把所有参数拉平，就会掉进机械感。要减掉的是 Pit 的陡峭程度和张力绝对值，而不是"变化"本身。
3. **张力拉满之后继续叠张力，只会更电。** 出路要么是加 Pit 技巧，要么是挑一两个字落下去做对比。
4. **"张力穿过 0 点"是一个必须处理的边界。** 跨零点画成 S 形，AI 库干脆改用音区偏移打底。
5. **密集技巧必须错开时间。** 颤音、音头浮动、转音挤在同一瞬间，就是那个"抽一下"。
6. **强弱参数要画在有反馈的位置。** 轻辅音上没有张力反馈、呼吸音上没有音高——画了等于没画。
7. **浊辅音上要把参数画平缓。** 浊辅音带音高，参数突变会破坏咬字连贯性。
8. **捏音色只是辅助润色，幅度要适度。** 把频段推到顶或拉到底，出来的就不是人类能发出的声音了。

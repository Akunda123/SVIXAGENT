# 案例：咬字糊成一团 —— 高音糊字、口型不对、字间冒音

> 分类：咬字 / 音素 ｜ 症状：某个字听着像别的字、口型该开不开、尾韵收不住、两个字之间多出怪音

## 问题

词是照谱打进去的，可整段听下来有几处很扎耳朵：

- 副歌高音上的「繁花」，第二个字塌得只剩一口气，听着像「fa-ha」。
- 字的轮廓还在，嘴形却不对：本该张大嘴的地方闷在嘴里，该收住的地方又收不利索。
- 两个字中间凭空多出一个音，像自己长出来的儿化音。
- 长音上的尾韵拖不利索，`ai` 被唱成了「啊——诶——」两截。
- 一到高音就顶不上去，明显是被闭着嘴的字卡住了。
- 快歌里辅音集体失踪；切回慢歌，辅音又大得砸耳朵。
- 有某个音素干脆一点动静都没有。

## 诊断

### 第一轮：先把三条"其实不是咬字问题"的毛病排掉

| 现象 | 查什么 |
|---|---|
| 某个音素完全不发声 | **回去数空格。** 音素串靠空格分词，少一个空格这一段就不被识别，波形上也是空的；空格多打或拼写错了，引擎会拿相近的音素顶上，等于换成了另一个音 |
| 字从根上就读错 | **多音字。** SV 碰到多音字偏好生僻读音（「读」念 dòu、「落」念 là、「车」念 jū 这一类），逐字核一遍，用拼音把读音钉死最省事 |
| 前后鼻音串了 | **先确认是不是自己改的。** 互换前后鼻音会削弱歌词辨识度、收尾也怪，只有押韵确实需要时才动它 |

### 第二轮：剩下的才是真咬字问题，按现象定病因

- **高音处糊成另一个字** —— 口型没跟着音高走。音越高、口型越要张；音越低、口型越要收。高音一旦撞上闭口收尾的字（`u` / `i` / `n` / `ng` 这一类），力度根本上不去。
- **口型瘪** —— 用到的元音本身就是小口型（小写 `a` / `e` / `u`），或者共振峰整体位置偏低。
- **尾韵收不住或收过头** —— 韵尾长度从来没动过。闭口音的规律是：韵尾拖得越长，嘴越小；压得越短，嘴越开。
- **字缝里多一个音** —— 引擎默认的采样拼接过渡跟你要的不是一回事。
- **咬字过程太短、太"现代"** —— 复元音默认一步到位，中间那段口型变化没被拆出来。
- **辅音被吞** —— 低音区叠上快咬字时，AI 库会自动把辅音发糊。
- **辅音砸耳朵** —— 采样库的辅音默认偏长，而且辅音那一段的动态根本没人管。

## 怎么改

按成本从低到高走，**能在上一层解决就停住，别越级**。

> 📌 **口径说明（以为准）**：的成本阶梯是**五级** ——
> 换备用采样 / 音素力度 → 换近义字 → 音素替换 → 拆音 → 拆轨（见 `references/09-拆轨与拆音.md`）。
> 下面 ①~⑦ 是按**手段**排的展开写法；其中 **④ 调音素长度**与 **⑥ 性别微调**属于阶梯内部
> 随时可用的细调，**不单列成一级**。上游把这两条也排进了阶梯，不采用这个分法。

### ① 换备用采样（永远先试这一层）

音符属性里点 **DFLT** 换采样即可。这里没有可循的规律——不存在"1 号偏亮、2 号偏厚"这种说法，只能一个个试过去。

⚠️ **必须盯副作用**：采样之间是拼接起来的，换了这个字的采样，下一个字的发音会跟着变。所以常见的情况是"这个字换好了，后一个字反而被带坏"。怎么换都规避不掉时，这个位置就只剩拆轨一条路（→ `09-拆轨与拆音.md`）。

AI 库没有备用采样，改走**音素力度**：元音加大 = 嘴张开；辅音加大 = 更清晰有力，压小 = 变糊、往浊音靠。

### ② 换一个口型更大或更小的同音近义字（高低音处首选）

高音上遇到闭口字力度不够，最干脆的办法是**直接换字**。念出来别扭，唱起来力度却完全够，听众也不会听成另一个字——因为它符合高音处的咬字习惯。

- 往大口型换：`挥 hui`→`坏 huai`、`春 chun`→`穿 chuan`、`走 zou`→`早 zao`、`车 che`→`叉 cha`
- 也可以把 `死 si`→`色 se`（顺手把 `e` 压低一点）
- 反向收口型：`灿 can`→`侧 ce`

换过头了，再用音素力度（AI 库）或音素时值往回修一点。

### ③ 音素替换

口型接近的元音可以直接互换，**大小写就是口型大小**：

| 大写（口型大、立体）| 小写（口型小、扁）| 用在哪 |
|---|---|---|
| `A` | `a` | 高音、美声、情绪顶起来时用大写；低音、民族咬字用小写 |
| `E` | `e` | 同上 |
| `U` | `u` | ⚠️ AI 库不认大写 `U`，改用 `o` |
| `7` / `@` | —— | 两者口型接近，可互换 |
| `iE` / `ie`、`y{` / `yE` | —— | 复合元音的两套写法，可互换 |

辅音替换改的是气质，不是口型：

- 把 `t` 换成 `ts`、`th` 换成 `tsh` → 更洋气（要配合把响度的前半段压下去）
- `k` 换成 `h` → 送气更重、更深情
- 想要台湾腔的路子，把 `x` 换 `sh`、`q` 换 `ch`、`j` 换 `zh`

### ④ 调音素长度（最容易被跳过，收益却最大）

**这是本案例里唯一一件"不做就永远好不了"的事。** 核心原则只有一句：**辅音的长短必须逐字给，而且要成规律**——重拍上的字辅音长、弱拍上的字辅音短；一拍里塞两个字的，第二个字再短一档。整组套同一个值，咬字一定是死的。

三条最容易忽略的：

- 抒情段里 `/s/` `/x/` `/sh/` 一类摩擦音统统压短，咬字才连得起来。
- 尾韵该收的收：`ai` 的 `i` 只在最末尾点一下；以 `ang` / `eng` 收尾的 `ng`、以 `an` 收尾的 `n` 都要缩，否则口型瘪、听着咬牙切齿。但**要给辨字留够长度**——缩过头字会变形（「天外边」缩狠了会听成「贴外边」）。
- 高音处鼻音的落点往后放，落早了咬字和旋律就对不上。

辅音砸耳朵的问题，张力管不了（轻辅音对张力没有反馈），只能用**响度或发声**把那一小段压下去；做渐强时辅音得跟着一起弱。AI 库吞辅音则相反：手动把该出来的辅音音素力度拉大、时长给够。

> 逐条落到字段（`dur[]` / `strength` / `position`）的完整规则集见 `references/03-phonemes.md`。

### ⑤ 拆音（仍在同一轨内，引擎的拼接规则照旧生效）

拆音要解决的是**口型的变化过程**——把一步到位的复元音拆成两段，让中间那段过渡露出来。典型做法是把一个音节的音素串重新排一遍，例如 `chang` 拆成 `che` 接 `ang`（先给一个收一点的口型，再撑开），`tian` 拆成 `tie` 接 `en`，`chun` 拆成 `chu` 接 `en` 或者 `ch` 接 `uo` 接 `n`。

尾韵落不准时，**半元音是最好用的工具**：尾韵是 `i`，就在它前面补一个 `/y/`；尾韵是 `u`，就在它后面补一个 `/w/`。道理是这两个半元音会被算作后一个音的辅音，所以能顺顺当当地滑进来；反过来，两个各自独立的元音相接，中间必然出现音量或力度的起伏。**要连贯就用半元音，要停顿感就用独立元音。**

字缝里冒出儿化音，也是同一招：在中间插一个 `/w/`，衔接处的音量变化再用张力抹平。句首某个字发音不明确时，可以在它前面带一个目标口型（元音），再用响度把这一段压掉切走。

⚠️ 拆完过渡突兀，**第一反应是在张力上画一笔把它柔化**。拆音会改变原有的采样链接过渡，出现不连贯是正常的，需要多试几次。**有些位置就是拆不动**——同一个字采样库拆不出效果而 AI 库能拆动（反过来也有）。拆不动就换别的手段。

> 拆音节对照表与更多实战拆法见 `references/03-phonemes.md`。

### ⑥ 微调性别参数

共振峰在小范围内会影响口型，但**偏移量必须控制得很小，不然声线就保不住了**（方向口径以 `07 §3.2g` 为准）。

### ⑦ 拆轨（万不得已）

前六步都不行才做。触发条件只有两个：高音咬字糊，而拆音和换采样都不自然；或者换采样把下一个字带坏了且无法规避。

## 改后效果

- 高音处口型跟着音高张开，力度上得去。
- 尾韵该收的收住、该开的开，口型不瘪也不拖。
- 字与字之间没有多余的音，衔接自然。
- 辅音长短错落：快歌有律动，慢歌连得住。

## 可复用判断标准

1. **先排低级问题再谈咬字。** "音素不发声 / 字念错 / 前后鼻音串"这三条占了相当比例，修复成本接近零；跳过它们直接拆音换采样是白费力气。
2. **高音糊字先看口型，不要先怪声库。** 口型大不大、闭不闭口，直接决定高音上能给多少力度。
3. **成本阶梯不能越级**（口径 = **五级**：换采样 / 音素力度 → 换近义字 → 音素替换 → 拆音 → 拆轨，见 `09`）。**调音素长度**是贯穿整条阶梯的细调手段，**性别**是收尾的微调，两者都不算独立一级；能在上一层解决就停住。
4. **换采样一定要听下一个字。** 采样是拼接的，"这个字好了、下个字坏了"是它的固有代价。
5. **调音素长度是投入产出比最高的一步**，也最常被跳过——辅音长短有没有规律，直接决定咬字是死的还是活的。
6. **别为了拆而拆。** 本来没问题的字硬拆一遍只会更差。
7. **快歌必须取舍时保辅音。** 真人唱快嘴时本来就会丢掉一部分清晰度，太清晰反而假；但歌词辨识度靠辅音撑着，所以砍时长只砍元音和韵尾。
8. **拉长元音不会改变发音。** 音符时值固定时，单元音拉长还是那个音，所以"想让口型变大"没法靠拉长元音实现。

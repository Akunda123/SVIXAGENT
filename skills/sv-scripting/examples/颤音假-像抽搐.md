# 案例：颤音假 —— 像抽搐，加了反而更难听

> 分类：颤音 ｜ 症状：颤得太快太密像触电、幅度大得像在唱戏、一起来音准就飘、进出没有过渡

## 问题

加颤音本来是想让它更有味道，结果六种典型听感全都指向不同的病因：

- **抽搐、鬼畜**：颤得又快又密，像摸了电门。
- **像在唱戏**：明明是首流行歌，颤动的幅度大得离谱。
- **像跑调**：颤音一起来，音准就飘了。
- **突兀**：卡一下冒出来、卡一下掉下去，进出完全没有过渡。
- **听着冷**：每个字都挂着颤音，审美疲劳。
- **该有味道的地方没味道**：古风、戏曲、长调都用上了颤音，可就是差那口气。

## 诊断

| 听到的 | 病因 |
|---|---|
| 抽搐、鬼畜 | 频率开到了 8、9，甚至直接顶到上限 |
| 像在唱戏 | 幅度用了极端档。**真人唱出来的幅度区间，比参数能调的区间窄得多** |
| 像跑调 | 两个可能：一是音符属性里的颤音"深度"没归零，采样自带的音准漂移和你的颤音叠在了一起；二是做了下颤却忘了在音尾把音高拉回标准值 |
| 突兀 | 缺淡入淡出 |
| 听着冷 | 加得太普遍。这个技巧的价值在"强调这个字 / 带出情绪变化 / 带出力度变化"，三条里至少碰上一条才值得加 |
| 个数对上了还是不像 | **数量对了，分布没对。** 原唱把 4 个颤音平铺在整个音上，你却把它们全挤在后半段，听起来的频率自然就偏快 |
| 唱古风 / 戏曲 / 长调时味道总差一层 | 面板默认给的是上下对称的摆动，少了**下颤**（中心音高整体往下压）这一层 |
| 情绪起来了颤音却跟不上 | 面板给的是恒定值，做不出渐变，只能手画或者往上叠 |

## 怎么改

### 第一步：先做清零

全选音符，把音符属性里的颤音**深度归零**。这个"深度"控制的是采样录音自带的音准漂移，跟颤音是两回事；不归零，你画的任何东西都会被它带着跑。接着到歌手属性栏里把颤音起始位置拉满，关掉自动颤音。

### 第二步：按场景取频率

| 场景 | 频率取值 |
|---|---|
| 轻快舒缓的抒情 | 6 |
| 利落的小颤（要有劲，但不能夸张）| 7 ~ 7.2，上限压到 8 |
| 句尾那一下短促的 | 7.5 |
| 抒情歌收尾的慢颤 | 5.4 |
| 京剧、美声的大颤 | 5.5 上下 |

幅度通常给 **0.5 ~ 2.0**。**戏曲与美声属于例外：它们没有"小颤"这一档，要么完全不颤，要么就是大颤。** 音符属性里深度拉到顶仍嫌不够，就到**颤音包络**上继续加（美声大约再加一半）。

### 第三步：按情绪选组合

把幅度和频率当作两个独立旋钮，四种搭配各有各的语气：

- **幅度大 + 频率高** —— 情绪饱满。用在重拍，或者大跳转音落到后一个音时，以及中高音区的短音上。
- **幅度小 + 频率高** —— 紧张、诉说感。多用在偏中低音区的短音上。
- **幅度大 + 频率低** —— 气势感、情绪递进。长音与尾音用。
- **幅度小 + 频率低** —— 放松。渐弱的长音上最合适。

至于**落在哪里**：小节层面常压在强拍与次强拍；乐句层面常落在最高音和句末那个音。起止多半跟着演唱力度或音程变化走——**变化越明显，颤音就越显眼**。

### 第四步：什么时候必须离开面板去手画 Pit

音符属性里的颤音面板胜在平滑、稳定，一般的颤音优先交给它。但有三件事它办不到：

**① 中心音高没法整体偏移。** 面板给的摆动是以本音符标准音高为轴、上下对称的；而真人唱的时候，颤音的中心会整体偏高或偏低：

- 中心**压低**（下颤）→ 中国戏曲、古风、蒙古长调、新民族的味道，沉稳、有韵味
- 中心**抬高**（上颤）→ 欧美唱法与美声的习惯，也能做出轻佻感

做法是在 Pit 上把整段音高先往下拉一点做出偏移，再叠颤音。**铁律：下颤走到音尾时，必须把音高拉回标准位置**，否则耳朵听到的就是跑调。做上颤时，张力要跟着往下画。

**② 频率与幅度没法渐变。** 真人的颤音会一点点加快、幅度一点点变大或变小。想要"颤着颤着越来越快""幅度越来越大再收回来"，只能手画。这两种用法可以命名：**蓄力颤音**（长音上力度往上推时用，幅度随推进一点点变大）、**弛颤音**（句尾力度松弛下去时用，幅度小一点、频率稍高）。

**③ 够不到前面的辅音。** 面板的作用范围只到本音符之内。想在辅音段做音高动作，只能**把辅音单独拆成一个音符**，这样才能单独编辑辅音段的音高。

### 第五步：做"向上飞的颤音"

不要硬手画整段（画不稳，很容易画成抽搐）。分两步走：先用面板调出一个规规矩矩的颤音（频率 7.5 上下、幅度偏大），再回到 Pit 上，叠一道**朝上的缓坡**。向下滑的颤音同理。

这一手的辨识度极高，但极少用——一首歌里出现一两次就够，用滥了会很怪。

### 第六步：收尾

- **淡入淡出少不了。** 收的时候要淡出、起的时候要淡入，卡着来卡着走非常突兀——任何技巧的进出都得有过渡。
- **动态要跟上。** 音高在颤，动态就会跟着周期性起伏，颤音幅度越大起伏越明显；要是只画 Pit 不管动态，颤音就会像"贴"在声音表面。

## 改后效果

- 颤音只出现在站得住脚的位置（强调、情绪变化、力度变化），不是每个字都挂。
- 频率落在 5 ~ 8 的合理区间，不再抽搐。
- 古风 / 戏曲的下颤有韵味，音尾能干净地收回标准音高。
- 长音上的颤音幅度有变化，不是一条恒定的正弦波。
- 颤音的进出有过渡，听起来是唱出来的，不是加上去的。

## 可复用判断标准

1. **加颤音之前先问"为什么加"。** 强调这个字、带出情绪变化、带出力度变化——三条里至少站住一条；否则只是在制造审美疲劳。
2. **先清零再画。** 采样自身的音准漂移不清掉，你画的一切都会被它带跑。
3. **频率落在 5 ~ 8，幅度落在 0.5 ~ 2.0。** 超出这个范围多半就是"抽搐"或"唱戏"，而不是"更有味道"。
4. **数量对不等于像。** 对照原唱时，除了数几个颤音，还要看它们在音上怎么分布。
5. **下颤必须收回标准音高**，否则会被听成跑调。
6. **颤音进出必须淡入淡出。** 卡着出现、卡着消失，比不加还难听。
7. **怒音处不加颤音。** 怒音是气息高度集中往前顶的状态，没有余力再颤。
8. **抒情段开头几个字先不加。** 光靠动态意境就出来了——**动态比颤音重要得多**。
9. **句尾不要用平直音收。** 美声、京剧的句尾基本都要以颤音结束，平着收就是没力度。
10. **极短的音不要硬颤。** 特别短的音至少要能颤两下；颤不了两下，就换成别的方式强调这个字。
11. **同一句在两段主歌不要用同一套颤音处理。** 情绪可以一样，手法要换。

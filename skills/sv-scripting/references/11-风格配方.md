### A.1 字段口径（先读这 5 条，否则会填错）

| 三件套 | 字段 | 单位 | 范围（UI 滑杆）| 现行默认 |
|---|---|---|---|---|
| **① 音头** | `tF0Left` | 秒 | 0.01 ~ 0.5 | 0.07 |
| | `dF0Left` | 半音 | −6 ~ 6 | 0.15 |
| | `tF0Offset` | 秒 | −0.5 ~ 0.5（**实务只用 0 ~ −0.1**）| 0 |
| **② 音尾** | `tF0Right` | 秒 | 0.01 ~ 0.5 | 0.07 |
| | `dF0Right` | 半音 | −6 ~ 6 | 0.15 |
| **③ 颤音** | `tF0VbrStart` | 秒（0 ~ 1）| — | 0.25 |
| | `tF0VbrLeft` / `tF0VbrRight` | 秒 | 0.02 ~ 0.5 | 0.2 / 0.2 |
| | `dF0Vbr` | 半音（峰峰）| 0 ~ 2 | 1 |
| | `fF0Vbr` | Hz | 1 ~ 10（**实测可超，实务不加 clamp**）| 5.5 |
| | `pF0Vbr` | 弧度（UI −1~1）| −π ~ π | 0 |

**① `dF0Left` 的符号在两代里相反**（`08 §2.1c`，文件层实测）：
- **SV1**：**正 = 走"旋律方向"**（§4 表；上行→上音头，下行/同音→下音头），负 = 反向；
- **SV2 / 脚本直写**：**正 = 上，负 = 下**（忽略相邻音）。
⇒ 下表按 **SV2 口径**给值（**正 = 上**）；**表中"下音头"在 SV1 上要写正值 + 交给方向层**，别照抄符号。

**①b 音高属性（`dF0Left` / `dF0Right`）的硬上限 = 6 个半音**—— 也就是上面表里那个 `−6 ~ 6` 的滑杆范围**就是真上限**。
⇒ **任何风格的幅度都不要超过 6**；**通用档写的"最大约 4"只是保底档的常见上限、不是硬上限** —— **抒情等风格可以比通用更大**（如 `1.1` 到 **5**）。

**①c "先沉再抬"这类双段音尾：SV2 能画，SV1 画不出来**——
SV1 的音尾**只有单个属性值**，做不了"先下后上"两段 ⇒ **在 SV1 上退化成"上音尾"**（只取抬的那一半）；**SV2 直接画曲线**，按原样做。
（首个用到的是 `1.4` 哭腔的"**先沉再抬＝委屈**"，见 `§A.5 · 1.4`。）

**①d 装饰音（前倚音一类）落地 = "拆分音符"，两代一致、都不是画曲线**：
- **SV2 也是拆音符，不画曲线**（别拿 `PitchControlCurve` 去凑装饰音）；**SV1** 走音符属性。
- ⚠️ **拆出来的新音符默认是"自动音高"**（`getPitchAutoMode() == true`；2026-09-23 实测：拆音后新音符 `true`、原有音符 `false`）—— **一般够用**；
- ⚠️ **用户要求切分出来的音符走"手动音高"时，要显式 `Note#setPitchAutoMode(false)`**（否则画了音高参数也可能被自动音高盖住）。

**② `tF0Offset` 一般取 −0.035**（实测：`gaiya.svp` 只有 `0 / −0.035 / −0.04` 三档；SV1 工程同样只有 0 与负值）—— 作用是**把音头峰点挪到两个音符之间**，别让下沉画在本字的元音上（`08 §6.5` 的"位置判据"）。

**③ `tF0VbrStart` 表里写成 `k`（= 占时值比例），不是秒**：`tF0VbrStart = min(k × 时值秒数, 1)`；**短音符一律 `k=0`（从头颤）**（`08 §6.3①` + 重音路径同口径）。

**④ 上颤 / 下颤不靠 `pF0Vbr`**：参数面板**调不了颤音的整体上下偏移**（`08 §6.5`），而 SV2 自绘曲线路径下 `pF0Vbr` 又被"曲线平滑"取代（`08 §6.3⑤`）。
⇒ 表里第 5 列「**中心偏移**」= **把整段颤音曲线整体上下移**（半音，负 = 下颤）。
⚠️ **`sv_write_pit` 目前没有这个参数** ⇒ 需要"整段偏置"另做一道（**已记为工具侧待补**）；先跑时中心偏移按 0，听感要下颤再手补。

**⑤ `tF0VbrLeft` / `tF0VbrRight` 会"吃掉"实际振幅**—— 调颤音必读：

- **两者的重叠会减弱实际的 `dF0Vbr`**（写进去的幅度 ≠ 听到的幅度）⇒ 调整时**必须同时看"音符长度"与 `tF0VbrLeft/Right` 的关系**。
- **短音符**：先检查 `tF0VbrLeft/Right` 有没有**交叉重叠**、或者**把整个音符覆盖掉** —— 那会让**实际振幅变小**；⇒ 可**按时长适当减小 `tF0VbrLeft/Right`**。
- **短音符的取值**：`dF0Vbr` 一般**在 1 以内**（约半个半音的量级）；**频率 `fF0Vbr` 随力度走** —— **5.5 ~ 6 是大部分情况**，**力度大的地方最高可到 6.5、偶尔到 7**（**短颤音同样适用**）。
- 想**减弱 `tF0VbrLeft` 的影响** ⇒ 可以**适当增大 `dF0Vbr`**（把被吃掉的那部分补回来）。
- **起颤位置**：加颤音时 **`tF0VbrStart` 必须设 0** —— 否则**颤音显示不出来**。
- **想让颤音"一开始就大"** ⇒ **把 `tF0VbrLeft` 降低**（渐入短 = 更快进满幅），**但别降到 0**（留一点渐入，否则起振太硬）。✅ 用户 2026-09-23。
- ⚠️ **`tF0VbrStart` 的上限是 1（秒）**（先前口述的"2"是把**音符时长 2 s** 记混了）—— **超长音符要"先平后颤"就拉到 1 s**。

**⑥ `vibratoEnv`（颤音幅度包络）= 给颤音加浮动、免得听着一成不变**：

- **它的意义是"提供浮动、显得不单调"**（不是拿来放大/缩小的）；
- **数值稍微给个 ±40 % 左右的浮动就差不多了**（默认 1 = 不浮动 ⇒ 大致在 0.6 ~ 1.4 之间起伏）。

**三条横向规律（`08§6.5`，比单行取值更重要）**
- **音头以下沉为主、上扬只作点缀**（用量差"好几倍"）；普通音头幅度 **≈3 半音**，极端接近破音时才更大；**极短时值内跨六度以上必然"触电"**。
- **颤音：幅度与频率四象限** —— 大+高=情绪饱满（重拍/大跳后/中高音短音）· 小+高=紧张诉说（中低音短音）· 大+低=气势递进（长音/尾音）· 小+低=放松（渐弱长音）。
- **两条硬规则**：① **下颤走到音尾必须把音高收回标准位置**（否则=跑调）；② **颤音必须做淡入淡出**（一下卡住掉下去很生硬）。

### A.3 怎么用（写进工程）

1. **别整首套一组** —— `sv_write_pit` 的 `params` 是**整批统一覆盖**。按**风格段 / 乐句**分组，用 `indices` 点名或 `plan:"explicit"` 先选好音符，再套该风格那一行。
2. **先 dryRun 看曲线**：`sv_write_pit { text:"藏腔", params:{…}, indices:[…], dryRun:true }` ⇒ 看**点数 / 跨度 / y 范围 / onset 处取值**是否落在表里写的幅度上。
3. **再真机写入 + 听感验收**（**听感一律由用户判**）；`推` 档先当起点，用户说"太夸张/听不出"再按 **"整体降到 50%"** 这条通用标尺回调（`08§6.5`）。
4. **彩蛋保留**：`text` 含 `C47 / C047 / 震撼哭腔` ⇒ 全音符颤音 **`dF0Vbr 2` + `fF0Vbr 10` + `tF0VbrStart 0`**（`08§6.3⑥`），**优先于本表**。

（`tF0Offset 0 · tF0Left/Right 0.07 · dF0Left/Right 0.15 · tF0VbrStart 0.25 · tF0VbrLeft/Right 0.2 · dF0Vbr 1 · fF0Vbr 5.5 · pF0Vbr 0`）；
**重音路径**（`plan:"accent"`）另有一组：`midAmp 1.5 / strongAmp 2.5 / tailAmp 2 / dF0Vbr 1.2 / fF0Vbr 5.8`，
`tF0VbrStart` 按 `k` 算（基准 0.5 · 句尾 +0.15 · 强重音 −0.15 · 超长 +0.1 · 封顶 1 s · 短音 0）。
⇒ **本表 = 在默认之上按风格覆盖**；只有 **§2.3 藏腔**是"**默认值本身就错**"的一档（默认 `dF0Vbr 1 + fF0Vbr 5.5` 恰好落在它明令禁止的"慢速大颤"附近）。

### A.5 逐风格「怎么唱」（**行为描述** · 按确认进度补）

> 🆕 **2026-09-23 起逐风格过**（"我说到哪，你把 skill 改到哪"）：**一小节一个风格**，写 **音头 / 音尾 / 颤音·短 / 颤音·中 / 颤音·长** 的**行为描述**。
> **只写"怎么唱"** —— **① 哪个方向多（比例）② 什么时候上、什么时候下 ③ 到什么程度 ④ 禁例**；数字只作旁注。
> 🔢 **程度一律相对 `0 通用` 说个大概**：写「**幅度比通用小 / 频率比通用略快 / 起得更晚**」这类**相对话**，
> **不逐项标具体数值**（如"约 1 半音""频率 6.2"）—— 要精度去查 **`§A.2` 的数值表**；本节只保证"听起来是什么样"。
> 例外：**用户口述给出的绝对值照记**。
> ➕➖ **数值只记量级、不记符号**：同一风格的音头／音尾**不一定只往上或只往下**，
> 所以**方向不写死在数值里** —— 写成"**约 2 ~ 5 个半音**"这种**不带向的量**；**方向由方向层按上下文决定**
> （口径见 `§A.1①`：SV2 **正 = 上、负 = 下**，落到代码时按实际方向取号）。
> 真要**锁死方向**的风格（如美声"**绝不上扬**"），就在**文字**里说清，不靠符号。
> 🎚 **参数层（张力 / 气声 / 发声 / 性别 / 响度 / 颤音包络）默认"不另给值"** —— 以**本文件正文各风格小节的「参数」条目**为准；
> **除非用户主动提出要量化或修改**，本节不自己给参数值、也不自己发明规则。
> 🔧 流程：**用户口述 ⇒ 只改对应小节**（一次一个风格，不整块重写）。

#### 0 通用（流行歌）—— 保底档

- **音头**：以**下沉为主**（十次里约七次），落点在**辅音起点稍前**；**上扬是点缀** —— 但**主歌部分可以适当增加上扬的比例**。**幅度跟着力度走**：**力度越大、幅度越大，最大约 4 个半音**。
  - ⚠️ **"约 4"是通用（保底档）的常见上限，不是全局硬上限**—— **音高属性（`dF0Left` / `dF0Right`）的硬上限 = 6 个半音**；
    **抒情一类可以比通用更大**（如 `1.1` 能到 **5**），只要不撞 6 的顶。
- **音尾**：**极少用** —— **句中几乎不出现**；只有**句中出现明显分隔**时（凭**语义或音高**判断）**可以加一下**；**句尾也只是偶尔点**一下。**上音尾的频率与实际效果都明显大于下音尾**（要加优先走上音尾）。**幅度约 3 ~ 4 个半音**（用得少，但一用就明显；**以上音尾为主**）。
- **颤音·短**：**从头就颤**（**`tF0VbrStart = 0`**，否则颤音显示不出来），轻而快：**`dF0Vbr` 一般在 1 以内**（约半个半音的量级）；**频率 `fF0Vbr` 随力度走** —— **5.5 ~ 6 是大部分情况**，**力度大处最高可到 6.5、偶尔到 7**。⚠️ **短音符要先查 `tF0VbrLeft/Right` 有没有交叉重叠、或把音符覆盖掉**（会**减弱实际振幅**）⇒ **按时长适当减小**；想保住振幅也可以**适当增大 `dF0Vbr`**（细则见 `§A.1⑤`）。
- **颤音·中**：**看"音符相对长度 + 前后音符力度"分三种**：
  1. **主要做法**（音符**相对较长**）：**`tF0VbrStart` 归零**（从头起颤）、**`tF0VbrLeft` / `tF0VbrRight` 拉满**、**左右都渐变** ⇒ 过渡最自然。**这是主要做法**。
  2. **一侧拉满、另一侧默认或减小**（用"能量放哪边"来突出）：
     - **当前音符强** ⇒ **左默认、右拉满**（能量集中在前半部分）；
     - **后一个音符力度比当前强** ⇒ **左拉满、右按实际调整** ⇒ 能量**递增**，**把后一个音符托出来**；
     - **振幅与频率沿用前面那套**（`dF0Vbr` ≤ 1；`fF0Vbr` **5.5 ~ 6 为主，力度大处最高 6.5、偶尔 7**）。
  3. **小部分情况**（**前后力度都很强、当前相对较弱**）：把 **`tF0VbrStart` 往后调**，让**颤音落在后半、前半保持平** ⇒ 突出前后的音高；⚠️ **同时改 `tF0VbrLeft` 让过渡自然**。
  > 🔗 **相位（`pF0Vbr`）** 见 `§A.1④`：**上颤/下颤不靠它**（面板也调不了整体偏移）—— 这里不重复。
- **颤音·长**：**一律"先平后颤"** —— 颤音的**时长一般超过一半**，**大多数覆盖后 50 % ~ 75 % 的时值**；**`tF0VbrLeft` / `tF0VbrRight` 拉满**（两端都拉满）。**不用大颤**：`dF0Vbr` 一般 **0.7 ~ 1**（**不超 1**）、`fF0Vbr` **一般不超 6.5**（**不会出现比较高的情况**）。
  - **超长音符**：**`tF0VbrStart` 直接拉满到上限（= 1 秒）**（"先平后颤" ⇒ 颤音尽量晚起），并**用 `vibratoEnv` 给颤音画一点浮动包络**（**±40 % 左右**即可，见 `§A.1⑥`）。
- **参数**（张力 / 气声 / 发声 / 性别 / 响度）：**本节不另给值** —— 保底档不另立规矩，按**本文件正文各风格小节的「参数」条目**办（参数格一律"按 skill 里原有内容"）。

#### 1.1 抒情·喜 舒缓

- **音头**：**几乎全是下沉**（十次里九次），而且是**平滑的弱化下沉、不做棱角**；**幅度约 2 ~ 5 个半音**。
- **音尾**：**多数不画**（保持平稳）；只在**乐句起伏处**轻轻挑一下。**幅度约 1 ~ 3 个半音**（**上音尾为主**，下音尾少而小）。
- **颤音**：**同 `0 通用`**（短 / 中 / 长三种做法照上，不另立规矩）。
- **参数**：**不另给值**（同 `0 通用`）—— 按正文 **§1.1** 的「参数」条目：**张力整体压低**（唱到高音也别绷起来）、**重音感交给颤音 + 响度**，在"柔中找硬"。

#### 1.2 抒情·喜 元气

- **音头**：**上下都有，但以上冲为主** —— 字**从低处上冲、略微冲过头再落回**（就是要"蹦起来"）；**只有下行或同音的字才沉**；**上冲的幅度大于下沉**。
  - 🔧 **落地**：**`tF0Offset` 取在"居中位置"与"初始位置"之间** —— 也就是**比 0 更靠前、但还没到"峰点落在两个音符之间"那个居中值**（居中值见 `§A.1②`，实测为 −0.035）；这样音头才会**略过冲、再落回本音**。
- **音尾**：**向上挑 = 撒娇**，**句尾常用**（跟通用的"极少用"正好相反）。
- **颤音·短**：**从头颤**，但**比 `0 通用` 更轻快** —— **幅度更小、频率更快**。
- **颤音·中**：**起的位置同 `0 通用`**（照它那三种做法起）；**幅度与频率照通用那套、略偏快**。
- **颤音·长**：**起的位置同 `0 通用`**（先平后颤、覆盖后段）；**幅度比"中"略增、频率略降**（都在通用附近浮动）。
- **参数**：**不另给值**（同 `0 通用`）—— 按正文 **§1.2** 的「参数」条目：**张力整体抬上去**、**响度把音头补足**。
- ⛔ **禁例**：**别把上扬画成大起大落、别直接蹦小八度** —— 那是"**触电**"，不是"乐"；**时值本来就极短还要跳六七度／八度，必然不自然**。

#### 1.3 抒情·怒 摇滚（power 型）

- **音头**：**几乎每个字都沉**（十次里九次以上）—— 走的是"**辅音还没出声就先沉下去 → 换到下一个字时音头再抬上来**"；**下沉的落点一定要卡在浊辅音的起点上**，而且**浊辅音本身得够长**；**幅度比常规明显重**（约 **3** 个半音）。
  - **单元音字**：用**拆音**拆开，下沉感天然就有，**不用再手画**（→ `09-拆轨与拆音`）。
  - ⚡ **转音的音高浮动要给足** —— 哪怕略"不准"反倒更有怒感；Pit 画得四平八稳，味道就淡了。
- **音尾**：**跟着沉**（跟音头同向，**不反着往上挑**）；**幅度约 3 ~ 5 个半音**。
  - **句尾另说**：改成**吐息** —— 末字接"呵/呀/哈/呐"一类音素，把**元音段压下去**、**多余的气声用响度切掉** ⇒ 相当于先喘口气卸掉力道，缓过来接着凶。
- **颤音·短**：**从头就颤**，而且**一开始就要大**（**幅度拉满**）、**频率偏低**。
  - 🔧 **实现**：**把 `tF0VbrLeft` 降低**（渐入短 ⇒ 一上来就进入满幅），**但别降到 0** —— 留一点渐入，否则起振太硬。
- **颤音·中**：**起得很早**（约 1/4 处，比 `0 通用` 早得多）、**幅度拉满**；仍嫌不够就再用**颤音包络**往上叠。
- **颤音·长**：约 0.4 处起，**其余同"中"**（幅度拉满、可叠包络）。
- **参数**：**不另给值**（同 `0 通用`）—— 按正文 **§1.3** 的「参数」条目：**元音段把气声压低**（听感更扎实）、**音头靠响度补**。
- ⚠️ **进阶**：**怒音 / 咆哮 / 嘶吼**都算**特殊音头**，具体画法见 `08 §6.2b`。

#### 1.4 抒情·哀 哭腔

- **音头**：**只往上点一下**（**上音头**）—— **幅度大**，但**极短、点完立刻回本音**；**绝不下沉**（沉了就从"**委屈**"变"**生气**"）。
  - 🔢 **数据**：**`dF0Left` 4 ~ 6 个半音**、**`tF0Left` 比常规减小约 20 %**（更短、更像"点"）。（上限 6，见 `§A.1①b`。）
- **音尾**：**先沉再抬 = 委屈**（先下再上）；**整首偶尔一次就够，多了发腻**。
  - ⚠️ **宿主差异**：**SV2 能直接画**（曲线两段）；**SV1 做不出来** ⇒ **退化成"上音尾"**（只取抬的那半，详见 `§A.1①c`）。
- **颤音（整体）**：**频率统一在 6.5 ~ 8 Hz**—— 短 / 中 / 长都用这一档。
- **颤音·短**：**从头颤**；**幅度中大**；频率见上（6.5 ~ 8）。
- **颤音·中**：**起的位置同 `0 通用`**（照它那三种做法起）；**幅度与频率同"短"**（中大；6.5 ~ 8）。
- **颤音·长**：**起的位置同 `0 通用`**（先平后颤、覆盖后段）；幅度频率同"短"（6.5 ~ 8）。⚠️ **见好就收** —— **拖长或加大就毁音高辨识**。
- **参数**：**不另给值**（同 `0 通用`）—— 按正文 **§1.4** 的「参数」条目：**张力与响度配合更松缓**（凭这点跟"乐"分开）；**半元音处张力压低**、走进元音再恢复；**想哽咽用「发声」**比用响度更对味。

#### 1.5 抒情·哀 颓废 / 唱到失声

- **音头**：**气泡音**（AI 型声库可直接调 **`cl` 音素**；采样型声库没这个音素，只能用**响度切成梳状**去逼近）＋**轻微下沉**；**靠气声把音高辨识压下去**。
- **音尾**：**字尾做成近乎纯气声**、**突然放松** —— 是"**塌下来**"，**不是慢慢收**。
- **颤音·短**：**从头颤**；**幅度中小**、**频率偏慢**，带一点**下颤**。
- **颤音·中**：**起的位置同 `0 通用`**；**幅度中等**、**频率更慢**，**下颤**。
- **颤音·长**：**同"中"**（起的位置也同 `0 通用`）；**音尾要把音高收回标准位置**。
- **参数**：**不另给值**（同 `0 通用`）—— 按正文 **§1.5** 的「参数」条目：要做纯气声＝**张力拉到底 + 发声压下来 + 气声抬上去**；
  ⚡ **动态与"重音型"相反** —— 元音段**渐强**，**响度与张力一档一档往上顶**。
- ⚠️ **伴生注意**：**一旦接近纯气声，后一个字的辅音要切得小一些**，否则它会从满耳朵的气声里硬生生蹦出来。

#### 1.6 R&B

- **音头（招牌）**：**先给前倚音，再做一个极短的向上"尖尖"，立刻落回本音、不留平台** —— 这就是 R&B 的签名动作（装饰音程口径见 `07 §1.7`：**通俗系用 `graceInterval 1.5`**，略小于全音）。
  - 🔧 **实现**：**前倚音靠"拆分音符"做出来**（→ `09-拆轨与拆音`；**SV2 同样是拆音符、不画曲线**，见 `§A.1①d`），
    并在**两个音符的过渡处**用**一小点向上的 `dF0Left`** 来表达（**小量**即可，别做成大跳）。
    具体：原音符后半段留原音高（歌词改 `-`）、前半段切出来做前倚音（**下方小二度**，承接原歌词）。
    ⚠️ **拆出来的新音符默认是"自动音高"**（一般够用）；**用户要求手动音高时显式 `setPitchAutoMode(false)`**（详见 `§A.1①d`）。
  - 🛠 **已工具化**：**`sv_apply_ornaments`**（八型装饰音一套：前倚音 / 后倚音 / 向上尖尖 / 波音 / 回音 / 音尾音阶行进 / 反向预备 / 滑音）。
    默认 `dryRun`；`manual:true` 才转手动音高；`dyn:true` 可**顺带配配套动态**（`07 §2.5` 的那三种）。
- **音尾**：**向上短转音**，正好**指向下一小节的和弦**（吃乐理经验）；**长音**的音头可加一点**小上浮**来发力，这时**前一音的音尾原样不动**（再往下压就过了）。
- **颤音·短**：**从头颤**；**轻**、**频率快**。
- **颤音·中**：**起的位置同 `0 通用`**；**幅度中等**、**频率偏快**。
- **颤音·长**：**起的位置同 `0 通用`**；**幅度中等**、**频率略降**。
- **参数 / 挂得上的手法**：**正文 §1.6 没有独立的"参数"条** ⇒ 按它已有的两条办：
  - **咬字**：**重拍上的字把辅音拖长、弱拍上的字辅音压到极短**（弱拍虚词甚至可以拆一个音出来、把响度抹掉）；
  - **动态**：**转音之间要画出动态差**，音的边界才清楚 —— **画得比听感更夸张也无妨**（混音一挂压缩就被抹平）。
- ⛔ **边界**：**转音落在五声音阶里 ≠ R&B** —— 古风转音讲"有力道"，R&B 要的是**自由、丝滑、又快又密**。

#### 2.3 藏腔 ⚡

> ✅ **用户 2026-09-24 口述（＋音高线截图）—— 原写的"基本不加颤音"作废**：

- **颤音·短 / 中 / 长：三档都"从头颤到尾"**（`tF0VbrStart = 0`，一路颤到音尾）。
- **两种性格，二选一**：**小幅 + 高频** 或 **小频（慢）+ 高幅**（`§A.2` 那两档数：小幅档 `dF0Vbr ≤1` · `fF0Vbr 6.5~7`；高幅档 `1.8~2.0` · `5.0~5.5`，标 `推` 待听感验收）。
- **中 / 长音**：`tF0VbrLeft` / `tF0VbrRight` **左右拉满**（短音不必拉满，短音拉满会吃掉实际振幅，见 `§A.1⑤`）。
- **SV2 专属 · 只给长音符**：**长音**里约 **5 ~ 10 %** 的颤音，把**向上的振幅放大 2 ~ 3 倍**（**短音 / 中音一律不加**）—— 是"偶尔挑几个往上多甩一下"，不是每个颤音都放大（截图里那两根高尖就是它）。
- ⚠️ **旧的"禁慢速大颤"不再成立**（那是照着错的理解写的）；**慢 + 大**现在是允许的**两档之一**。

> 📌 **本轮只改了颤音**：**音头**（二度/三度上跳的"小尖尖"、短促带斜度、跳完立刻回本音、长音连做 2~3 个）与**音尾**（长音靠下滑补音程变化）**未改**，仍按 `§A.2` 那一行的原写法。

| 通俗 | 抒情·哀（颓废失声）| 音头气泡音 + 字尾近纯气声；**动态取向与重音型相反**（元音渐强）|
| 通俗 | **R&B** | **五声转音 + 句尾落 la** + 大量前/后倚音 + 真假声转换 |
| 通俗 | 说唱 | 分「固定音高 / 无固定音高（跟声调）/ 语调校」三类 |
| 民族 | 京剧（旦角）| 珠圆玉润 + **大颤频率≈5.5** + 下颤 + 大开大合的咬字 |
| 民族 | 黄梅戏 | **几乎每个词音头都有装饰音**；真声音域；句尾仍大颤 |
| 民族 | 藏腔 | **3 半音小尖尖，上跳必须把张力画低** |
| 民族 | 蒙古长调 | **转音落在五声音阶内**；音头下沉比藏腔多得多；下颤收标准音高 |
| 民族 | 岛呗 | **音头一个「要破不破」的二度上跳**就是全部灵魂；真假声极多 |
| 民族 | 约德尔 | **真假声转换要有棱有角**（八度跳 + 变化时长 0 / 极短非零）|
| 民族 | 呼麦 | ❌ **做不到，如实告知用户**（需要改共振峰，声库不支持）|
| 古典 | 美声 | **要么不颤要么大颤** + **连续转音＝梭子形** + 音头一律从本音高或之下进入 |
| 跨界 | 新民族 | 美声的骨架 + **允许**哭腔式上扬/加花/藏腔小跳 |

## 1. 通俗 / 流行

### 1.1 抒情·喜（轻松舒缓型）

> 适用曲风：爵士 / Bossa Nova / 儿歌 / 轻快小品。

- **咬字**：元音砍到极短、辅音反过来拖长（小孩唱歌正是这个比例）。
- **Pit**：整体走平滑路线，音头弱化处理；**上行的字大量用滑音**，把"诉说感"做出来；句尾偶尔滑一下，添点俏皮。
- **颤音**：频率 **≈6**，音头位置点一下即可；收尾常用一个短音配偏高频率的颤音。
- **参数**：张力从整体上压低，唱到高音也别绷起来；重音感交给**颤音 + 响度**去做，在"柔中找硬"，免得张力一低整体就塌成消沉。
- **反例**：张力画高会跟舒缓的基调互相打架；辅音切得太短、连得太死，听感一路沉稳下去，活泼劲儿就没了。

### 1.2 抒情·喜（元气活泼型）

- **咬字**：拆音用得很多（目的是让口型变化看得出来），辅音一样要拉长。
- **Pit**：上扬动作密集，浮动幅度远大于舒缓型；辅音前后各贴一个动作（前一字的音尾先升、本字音头再压下来）；
  音头"从低处上来、略微冲过头再回落"能让字蹦起来；**音尾往上挑 = 撒娇**；音头由高到低短促滑一下 = 撒娇。
- **参数**：张力整体抬上去，响度把音头补足。
- ⚠️ **两者手法近乎同源**：本型和哭腔的差别只在张力怎么走、以及整体情绪怎么搭（别混为一谈，动作可以照搬）。
- **反例**：把上扬画成大起大落、直接蹦个小八度 —— 那听着不是"乐"，是**触电**；时值本来极短还要跳六七度、八度，必然不自然。

### 1.3 抒情·怒（摇滚 / power 型）

- **咬字**：字前面补一个**半元音**，音头力道就上来了；辅音必须清楚。
- **Pit（核心）**：音头下沉大面积使用，几乎每个字都走"辅音还没出声就先沉下去 → 换到下一个字时音头再抬上来"。
  - 下沉的落点**一定要卡在浊辅音的起点上**，同时**浊辅音本身得够长**。
  - **单元音字**只要用拆音拆开，下沉感天然就有，不用再手画（→ `09-拆轨与拆音`）。
  - 转音的音高浮动要给足，**哪怕略"不准"反倒更有怒感**；Pit 画得四平八稳，味道就淡了。
- **颤音**：深度直接拉满（2），仍嫌不够就再用**颤音包络**往上叠；情绪起伏多大，Pit 的起伏就跟着多大。
- **参数**：元音段把**气声压低**（听感更扎实）；音头靠**响度**补。
- **句尾**：音头式下沉 + **吐息音**（末字改接"呵/呀/哈/呐"一类音素，把元音段压下去，多余的气声用响度切掉）→ 相当于先喘口气卸掉力道，缓过来接着凶。
- 进阶：怒音 / 咆哮音 / 嘶吼音都算**特殊音头**，具体画法见 `08 §6.2b`。

### 1.4 抒情·哀（高亢哭腔型）

- **Pit**：上扬照做，差异在于**张力与响度的配合更松缓**，凭这一点跟"乐"分开。原理：悲到极处时旋律高亢、声带紧，字与字交接那一瞬声带会"滋"一下。
- **半元音那里张力要压低**，走进元音再恢复 —— 不这么做就显得夸张、突兀。
- **音尾先沉再抬 = 委屈感**，整首歌里偶尔来一次就够，多了发腻。
- **转音段把动态多画一点 → 哽咽感**；做"挖坑"时，用**响度**像是"使劲把嗓子收住"，用**发声**像是"嗓子忽然哑了一下"—— 想要哽咽，**后者更对味**。

### 1.5 抒情·哀（颓废 / 唱到失声型）

- **音头气泡音**（AI 型声库可以直接调 **`cl` 音素**；采样型声库没这个音素，只能用**响度切成梳状**去逼近）。
- **字尾做到近乎纯气声** → 就有唱到失声的效果（**张力拉到底、发声压下来、气声抬上去**）。
- 动态要跟**颤音**绑在一起画，画得明显些。
- **噎音**：辅音先出来，元音隔一小会儿再补上。
- ⚡ **动态思路跟重音型正好反过来**：元音段做**渐强**，响度与张力一档一档往上顶，每个字都像被单独送出去。
- ⚠️ 一旦接近纯气声，**后一个字的辅音要切得小一些**，否则它会从满耳朵的气声里硬生生蹦出来。

### 1.6 R&B

> 可参照的歌手：欧美的 Mariah Carey；华语的陶喆、王力宏、周杰伦、方大同。

**三个标志性特征**：律动（groove）、密集的转音加花、真假声来回切换 —— 全程只用真声或只用假声，听起来呆板，缺的就是那股灵动。

**Pit**

- 前倚音与后倚音成堆地用，旋律才接得顺；**省掉就显得呆板**（→ 生成器见 `07 §1.7` / `§1.8`）。
- **最经典的一手**：先给前倚音，再挑一个**极短的向上装饰"尖尖"**，最后落回本来的音高。
- ⚠️ **已按风格分档**：上游这里写"向上装饰的音程量取**比半音多一点、又不到一个全音**"（理由：刚好半音力道不够、接近全音就过头）——
  **现采纳该口径，但只给"通俗系"用**：**R&B / 流行 / 说唱 ⇒ `graceInterval: 1.5`**（略小于全音，听感就是那个"尖尖"）；
  **民族 / 戏曲 / 美声 / 通用 ⇒ 仍用 `+2`（大二度）**，装饰要清晰有棱角。分档表见 **`07 §1.7`**。
  ⇒ 早前"一律默认 +2、上游说法剔除"的处置**作废**；此处与 `07 §1.7` 保持一致，不再需要用户另行拍板。
- **装饰必须是极短的尖尖**：碰到那个音高就走，**不留平台**。
- 音尾再添一个向上的短转音，正好指向下一小节的和弦（吃乐理经验）。
- 长音的音头补一点小小的向上浮动来发力，这时前一音的音尾**原样不动**（再往下压就过了）。
- 高音往低音走的时候，音头顺手带一个下滑。
- ⚡ **R&B 的魂在五声音阶转音**：R&B 从 Blues 来的，而 Blues 音阶里没有 `fa` 与 `si`，把这两个音拿掉，**剩下的正好就是中国五声音阶**；
  **句尾常见一串连续四个下行转音，最后落到 `la`**（若落到常规大调的 **si** 就没那个味道）。
  半音级（都-西、咪-发）**转出来是不清楚的**，至少得是**全音或小三度**。
- 一串连续转音之间，每个接缝都要用明显的音高浮动断开 —— 浮动一省，整串就**糊成一条滑音**。

**咬字**：辅音的长短本身就是节奏，这一点极讲究 —— **重拍上的字把辅音拖长、弱拍上的字辅音压到极短**（弱拍虚词甚至可以拆一个音出来、把响度抹掉，让它短到底）。

**动态**：两个转音的中间要画出动态差，音的边界才清楚；**画得比听感需求更夸张也无妨**（混音阶段压缩一挂上去，动态会被抹平）。

**结构提示**：进入 Bridge 以后**加花密度陡增**，这时候 R&B 的味道最浓。

**边界**：转音落在五声音阶里并**不等于 R&B** —— 古风转音讲"有力道"，R&B 追求的是**自由、丝滑、又快又密**。

### 1.7 说唱（三型）

> ⚠️ **2026-09-18 用户订正（先读这条）**：**说唱本来就没有"固定音高"这一型** —— SV 里的 rap 音符**不按固定音高唱**，
> 音高由**字的声调 / 语调**决定（API 侧就是 `musicalType="rap"` + **`rapAccent` 1-5 = 五个声调**（5 = 轻声）+ 计算出的 `rapTone`/`rapIntonation`）。
> ⇒ **下面的「类型一 · 固定音高」不成立**（原文保留作历史）；实际只按**「跟声调走」**与**「语调校」**两种做法理解。
> ⛔ 另外别把 `setPitchAutoMode`（手动/自动音高）当成说唱开关：**rap 没有固定音高，这个开关不是这条路的入口**。
> 说唱词流与声调标记见 `sv-lyricist/references/说唱词流.md`；说唱相关 op/工具见 `akdagent-playbook`。

**类型一 · 固定音高** —— 直接当成音高全程不变的一段旋律来调。

- 力度落在音尾：靠 Pit 下沉来体现；音头补一点小浮动；遇到**需要体现字调的字**，再做一次类似转音的小处理。
- **咬字得清楚**：**AI 声库唱快歌时容易把辅音吞掉** → 该出来的辅音要手动调出来；**采样声库正相反**，它默认辅音就长 → 得往短了收，把时间让给元音。
- **押韵异化**：如果一整段的韵尾都是**前鼻音**，就把夹在中间的某个**后鼻音**字改成前鼻音，押韵才能保持住。
- **强弱拍**：重拍上的字把辅音拉长，同时**把它的前一个字元音再收短**；时值本来就短的字，辅音压掉、元音收到极短（**单音节字干脆牺牲元音**）；三连音扎堆的地方要专门回头查清晰度。

**类型二 · 无固定音高**（更常见，也更难）—— 多数情况跟着汉字的**声调走向**走，少数做**声调异化**，怎么定要看编曲、段落、情绪和轻重音。

- **三声字按接近四声来处理** → 力度更足。
- **处在小节第一个音、歌词又要强调** → 整体音高往上抬。
- **句子之间是递进关系** → 后一句的整体音高压过前一句。
- **力度点**：挑某个字，在**它的音头之前做一次 Pit 下沉**。
- **`zi`/`ci`/`shi` 这类字**：辅音和元音的口型本来就一样，**听辅音就够辨字** → 用**发声把元音段拉掉**；不拉掉的话，那个极短的元音点听起来很鬼畜。
- 咬字的准确性可以放宽，**调得过准反而怪**。

**类型三 · 语调校** —— 比"无固定音高"那一型更难（**连时长都不固定**），只能**念一句、再调一句**。
⚠️ **口语里的声调并不遵循标准调值**（"你好"念出来其实是二声 + 四声，而非三声 + 三声）。

## 2. 民族

### 2.1 京剧（旦角）

- **音色要前置**：旦角追求的是**珠圆玉润** —— 碰上偏尖锐的声库，就在后期把 **2–3 kHz** 这一段圆润区抬一些，超高频的金属泛音削一点（→ `混音与母带.md`）。
- **最显眼的特征就是颤音**：频率约 **5.5**（属于低频）、**幅度极大**；音符属性里把深度拉满还嫌不够，就接着在**颤音包络**上给长音继续加。
  **戏曲里基本没有微微的小颤，全是大颤**；快板唱段的频率会加快，幅度照样大。
- **下颤**：长音把**整体音高往下偏**，就有了下颤 → 古韵、沉稳；**上颤**则是现代、轻佻的味道。
  ⚠️ **下颤唱到音尾时，必须把音高收回到标准音高**，不然听感上就是跑调。
- **靠大量滑音把语气揉软**：直接硬碰硬太铿锵，滑过去才婉转，跟"珠圆玉润"的审美对得上。
- **音头的音高浮动要夸张**（比常规大出一大截）；万一幅度过大反显铿锵，**就把浮动的时长拉长来软化**。
- **大滑音**：原旋律本身没那么大起伏，需要**先猛地往上冲一截、再滑下来** → 办法是**加大滑音 + 拆音**，把它做成二度浮动。
  **浮动时间短的，落点不必准；浮动时间长的，落点必须准**，不然会像跑调。
- **像不像全看咬字**：讲究**大开大合、慢开慢合**，收尾**周正圆满**，**尾韵要往很后面放**，好让口型变化的过程足够长。
  常用拆法：`水→shu+ei`、`春→chu+en`、`圆→ye+an`、`状→zhuo+ang`、`入→ri`。
- **尖团音**：把 `ji`/`qi`/`xi` 读作 `zi`/`ci`/`si`（通俗向的作品，知道有这么回事就行）。
- **咬字断开**：音程跨度大、又拖得长的音，**要断成两截来唱**，力度一下就上来，长音也显得紧凑；
  **断口处的 Pit 必须先沉下去再起来**，音尾靠响度果断切断（要抢在采样尾巴自带的下滑音之前），同时把张力画下去。
- **京剧的动态基本都体现在颤音里**，动态本身画得糙一点没关系，**细腻那一路留给通俗抒情**。
- **反例**：拿现代咬字去唱戏腔，味道先丢一半；长音一路连到底、不肯断开，拖沓而且没韵味；**京剧的咬字只挑几个字调（要调就全调，要不就都别动）**。
- **声库**：偏尖亮的那些能用；**假声音阶更贴旦角**（不过假声气声重，元音段要把气声压下去）；**假声音阶 + 把性别参数调低**，这样味道最正。但戏腔并不是随便哪个声库都撑得住。

### 2.2 黄梅戏

- 圆润的追求是一样的，但它**主要落在真声音域**（旦角则偏混声 / 假声）⇒ 用**真声音阶**就够，音色往圆润捏、把尖亮压掉。
- **装饰音明显更多**：**几乎每个词都在音头挂装饰音**（就是小的**二度上 / 下装饰组合**），旋律因此更丰富。
- **颤音**：唱段偏快，频率相对高，**不用大颤**；但**句尾还是要大颤**。
- 咬字一样求圆润，拆法跟京剧接近；拆完之后把过渡修细一点，口型变化才丝滑。

### 2.3 藏腔

> 🔢 **三件套取值**（2026-09-19 落成，全表见 **§A**）：**音头** `0.03 · +3.0（上跳小尖尖，短促带斜度）· −0.035` · **音尾** `0.07 · −2.0`（长音音程变化补下滑）· **颤音基本不加**（`dF0Vbr 0`）；吟唱段真要加，只给**高频、存在感弱**的 `k0.5 · 0.2/0.2 · dF0Vbr 0.4 · fF0Vbr 7.0`。
> ❌ **本节禁用"慢速大颤"** —— `dF0Vbr > 1.5` 且 `fF0Vbr < 5.5` 的组合（本节反例）。⚠️ 上跳段要**同时把张力（连带发声）压下去**，那是 automation 侧的事（`07 §3.2j` 藏腔行）。

- **声线的来由**：高原上空气稀薄，声带也就偏薄、偏脆 → 出来的音色是**薄、尖、亮**。所以挑本身就尖亮的声库，音色几乎不用捏；
  偏成熟厚重的声线就不像了，除非能把它捏得又薄又细。**藏腔要的是"亮而实"，元音那里必须把气声压下来。**
- **灵魂在 Pit**：音与音之间、以及转音的地方，安排一个**极短促的向上小尖尖**，去模仿那种"要破不破"的破音边缘（真声一瞬跳进假声、再折回真声）。
  - 幅度约 **3 个半音**。
  - ⚡ **凡是上跳的段落，张力（连同发声）都要画低**，不然既不像又刺耳 —— 张力没降的上跳，听上去像**被外力顶了一把**，而不是自己甩上去的。
  - 时值要短，**带一点斜度**（画成直上直下会变电音），动作还得干净利落（上去慢、下来也慢，听着别扭）。
  - **一个长音上连着来两三个小尖尖**，丰富度就上去了。
- 其余 Pit 手法：**音高甩动加花**走二度 / 小三度；长音上出现音程变化时补一个**下滑**；音头处塞**极短的滑音**（一路平直就没韵味）。
- **吟唱段**（"诶嘿"这类）：
  - **基本保持直音**；要加就用**高频率、存在感弱的**。
  - **口型要稳**：从始至终只用一个音素（例如全程 `a`），其余成分要么弱化要么去掉，让口型大小始终不变（换成 a-i-r 这类组合，口型就会忽大忽小）。
  - **尖尖交给 Pit 本身去画，元音保持不动** —— 一旦用 `h`（呵）这类辅音，口型会收拢、连贯性就被破坏；非用不可的话要压到极短，并且**让它跟 Pit 上下的位置严丝合缝**，否则耳朵里会多出一个喉音，或者听成"先送一口气、再被顶上去"的两截。
- **反例**：只动 Pit、不管张力 → 又尖又刺耳；再叠上慢速大颤音与细碎的动态起伏 → 那份辽阔潇洒、直来直去的劲儿就毁了。

### 2.4 蒙古长调 / 内蒙民歌

> 🔢 **三件套**（全表见 **§A**）：**音头** `0.07（滑音拖久）· −2.5~−3.0 · −0.035` · **音尾** `0.07 · −2.5`（自上而下下滑）· **颤音** `k0.5 · 0.4/0.5 · dF0Vbr 1.8~2.0 · fF0Vbr 5.0~5.2 · 中心 −0.4（下颤）` —— **音尾必须把音高收回标准音高**。

- **声线**：厚重、醇厚、宽厚、霸气 —— 声库要挑厚实的，**正好跟藏腔的薄、尖、亮相反**。
- **Pit**：
  - **滑音用得多**：音头滑音做得夸张、拖得久一点（更显沉稳悠扬）；**音尾走一条自上而下的下滑**，做出"草原上的风声"。
  - 音头挂**二度 / 小三度装饰音**。
  - **转音一律落在五声音阶里**，并且有一套**固定的连续转音模式会反复出现**。
  - 那种"要破不破"的 Pit 上跳这里也有，只是**出现得比藏腔少**。
  - ⚡ **跟藏腔最要紧的区别：长调里该做音头 Pit 下沉的位置远多于藏腔**（蒙古的沉稳＝草原大地；藏腔的往上跳＝高原的飘渺高亢）。
- **颤音**：走**大颤**，长音上**幅度再大些、频率再低些**，做法是**把整体音高往下偏**形成下颤，**唱到音尾一定要收回标准音高**。
- 更正宗的长调会在**同一个长音里把二度音程来回跳好几遍**，甚至掺进真假声切换；通俗化的作品**点到即止**就行。
- **张力**：整体舒缓悠扬，**"由弱到强"的处理用得很多**。

### 2.5 岛呗

> 🔢 **三件套**（全表见 **§A**）：**音头** `0.035 · +2.0 · −0.035`（二度上跳"要破不破"后立即回本音 = 灵魂）· **音尾** `0.07 · −2.0` · **颤音** `k0.4 · 0.25/0.35 · dF0Vbr 1.5~1.8 · fF0Vbr 5.5~6.0`，中心**长音 −0.3（下颤）/ 情绪上行处 +0.2（上颤）** —— 交替且**无规律**正是它难调的地方。

> 参照对象：中孝介（日本冲绳 / 奄美一带唱法的典型）；周杰伦《花海》里"思念变成海"那个"海"字的音头，走的正是这个唱法。

- **灵魂落在音头上**：画一个**二度上跳的"要破不破"小 Pit，然后回到本音**。**这一个技巧抓住，味道立刻出来。**
- **颤音**：用大颤；长音走**下颤**；情绪一往上走也会改用**上颤**，而且**毫无规律** —— 这正是岛呗**难调的地方**（Pit 变化太多，旋律线抓不住）。
- 滑音、二度 / 小三度加花同样会用。
- **真假声转换用得极多**（岛呗本是唱给当地女神的，要的是柔美唱法）；藏腔 / 长调是"用真声把整条旋律唱完"，两者正好形成对照，
  高音该转假声就转，**张力也得跟上**。
- **边界**：岛呗**燃不起来**（它要的是柔和声线 + 真假声转换）—— 留给走柔美路线的歌。

### 2.6 约德尔

说到底只有一条：**真假声之间要转得有棱有角。**

- **八度跳**。
- **变化时长**：把前一个音符的变化时长归 **0**，后一个音符设成**很短但非零的数值**（**一旦也是 0 就成电音了**）。
- **跳下时加一个很小的音高浮动**。
- **张力与发声都画成陡峭的变化，并且跟 Pit 对齐**，往上跳的那一瞬间**把张力拉到底 → 立刻从真转假**。
- 气声略微抬一点能增强假声的辨识度，**但幅度要留小** —— 约德尔的假声本身有强度，抬过了会把假声的音高盖住。
- **短促的跳音**（就是"嘿呼"那种）：**颤音频率拉到极快 + 幅度拉到极大**。

### 2.7 呼麦 —— ❌ **超出当前工具能力，如实告知用户**

呼麦真正的门道**并不在于唱出两个音高**，而是**让基频保持不变、去改变共振峰（大致在 2 kHz 附近）**，在一列密集的泛音上做出飘起来的高音。
**声库没法自由地改共振峰**，加上 **AI 在低音区也发不出足够饱满的泛音列**，所以基本调不动。真想试的话，只能在编辑器里**一层层手动叠泛音轨**。

### 2.8 民族的通用注意

- 在民族唱法里**掺别的民族 / 民歌技巧，是允许的**；**流行技巧则留给"民通"这类跨界** —— 本来就是混着来的场合。
- **民歌的动态画得糙一点就行，抠细了反倒扭捏。**
- **尾韵**（`i`、`n`、`ng`）该收的时候要收，不收口型就展不开。

## 3. 古典（美声）

> 美声讲究把共鸣腔打开，出来的声音洪亮、有穿透力，圆润、立体、厚实。跟流行 / 民族那种"千人千面"不同，
> **美声在发声、技巧、咬字上都有一套严格统一的标准**，谁唱音色都差不离 —— 所以下面这些条条**近乎硬性约束**，不像流行那样能自己挑着用。

> 📎 **术语提醒**：**花腔**指**唱法类别**（只有花腔女高音这一说）；**华彩**指的是**整首歌里最出彩、旋律也最丰富的那一段**。用户说起时**别把两者混着讲**。

### 3.1 颤音

> 🔢 **三件套·颤音**（全表见 **§A**）：`k0.5`（弱唱 `0.6~0.7`，渐入拉更长）· `Left 0.4 / Right 0.05`（**淡出极快 = 不淡出，直接接下一个音**）· `dF0Vbr 1.5~2.0` ＋ **包络再叠 ×1.5** · `fF0Vbr 5.5~6.0` · 中心 **+0.3（上颤）**；**收尾不落回标准音高**（颤到某处直接停，再用响度切掉）。**音头/音尾见 §3.2 行的硬边界。**

- **这里没有小颤音：不颤，或者就大颤。** 音符属性里深度拉到顶还差意思，就在**颤音包络**上整体再加约**一半**。
- **颤音多半偏上（上颤）** —— 这是欧美唱法养成的习惯，**跟中国古典 / 古风爱用的下颤正相反**。
- **收尾时的颤音不需要落回标准音高**（这点跟流行的要求相反）：**颤到某个位置直接停**，再用响度把音尾利落地切掉。
- ⚡ **颤音能直接接进转音**（美声里最巧的一手）：做法不是"把颤音弱下来再重新起"，而是**让颤音的相位顺下去、接到后一个音高** ——
  颤着颤着，音高自己就落下来了。Pit 曲线看上去是**一条不断的颤音**，只不过颤的音高换了；音尾的滑音同理（一边颤一边就滑去了下一个音）。
- **力度弱**时 → 颤音能从无到有**渐入**，而且渐入的过程拉得更长；**力度强**时 → 颤音给得更多、更夸张。
  **美声里颤音出现的频率比民族唱法高得多**，就算弱唱也照样可以带颤音。
- **张力稳住就行**（颤音幅度一大，波形自己就带动态了）；**花腔里 Pit 的高低跟张力不成正比**，要看乐句的情绪往哪走。

### 3.2 Pit / 音头（含硬性边界）

**音头总共就三类**：① 平的（用在渐强、弱起的地方）② 滑音的（自下而上滑，多出现在第一句的头一个字，为的是加力度、添戏剧性）③ Pit 下沉的（要发力的时候用）。

- ⚠️ **硬边界：美声唱法的音头，只能从本音高或更低的音高进入** —— 像哭腔那样往上蹦一小下，那属于**声带边缘化**，跟美声要的"集中、厚重、圆润"完全拧着。
  同样的道理，**音尾也只收到本音高或更低**。
  有些地方听着像"音头上扬"，实际上是**音头 Pit 下沉，再叠上一个幅度不小的音头音高浮动** ⇒ 要判断，**就看音符起点那一处 Pit 落在本音高上方还是下方**。
- ⚡ **连续转音怎么画**：每个转音的音头都让 **Pit 先往下走一段（走得多一点）再折回来**，整条曲线看上去就是一串**梭子**；
  **张力与响度都跟 Pit 一起上下**（Pit 往上→张力和响度也往上，Pit 往下→两者跟着往下）。
  这么画最自然，也最接近美声（听着**有点像小提琴**）；往下走多少，**取决于需要多大的力度**。
- **跳音（花腔）**：音头**从稍低处往上画，略微越过目标音高、鼓出一个小山坡**，音尾再掉下来接住下一个音（人声的跳音落点做不到又准又平）；
  **音头和音尾都用响度切成陡坡**，跳音那种顿感才立得住 —— **不切，音符就会黏成一串梭子**。
- **"小爆破"式的音头起音**：除了单纯的由弱到强，另有一种是**先在音头点一下力度 → 立刻收回去 → 再走由弱到强**；
  **这一手必须配 Pit**：先沉下去，上来之后再加一点**小幅度的音高浮动**。Pit 要是平的，那就只剩普通渐强了。
- **歌剧选段的动态比艺术歌曲更大**：张力的幅度更大（甚至可以画到很低），音头 Pit 下沉以及音高浮动都做得**特别夸张**。
- **弹舌**（德语 / 意大利语 / 俄语）：把 `le/lu/li/la` 这类音素一串串地像机关枪扫射般硬拼上 —— **谈不上感情，全是技巧**。

### 3.3 咬字与参数

- 要点：**口型要竖、要立体、要饱满**，凡是"瘪"的口型都得撑开。
- **换音素**：把**大写 `A`** 拿来替掉小写 `a`（口型收拢、竖起、立体；小写 `a` 看着瘪，接近民族咬字的味道）。
  如果换完音素听着不自然，就把**性别参数往上拉一拉**。
- **书面化咬字**：把 `的` 读成 `di`、`了` 读成 `le`。
- **改写词面**同样有效：把某个词换成**口型更饱满的近音字组合**，声音就能亮起来。
- **气声**：按严格美声的标准，**元音段的气声一律要压低**（集中发声和散开的气声本就互相矛盾）；弱唱时也一样，把气声压到耳朵听不出来。
- **张力大体保持在一半以上**；要唱弱的时候，用**张力稍微降一点 + 靠响度画弱**（张力一旦拉到底，声音会软得过分，那就不是美声了）。
- **音头下沉要少** —— 多了显得笨重沉重，失去轻巧灵活；**不加颤音的音往往做动态向上**。

### 3.4 声库与 EQ

- 选声库时优先挑**底子明亮、各频段饱满均衡**的，后期捏音色的余地更大。
- **采样音阶**：挑**中高音阶**（也就是发声状态比较紧绷的那一档），它离美声的发声方式最近。
- **把性别参数往上拉**（口型更立体、声音更厚重）。
- **女声美声的 EQ**（先把气声**分离出去**，只处理干声，最后再叠回气声 → 具体操作见 `混音与母带.md`）：
  - 把 **10 kHz** 附近那股金属质感削掉（美声用不上这一段超高频）
  - 美声身上有**两处缺频**：一处是人声本来就有的那段，另一处是 **2 kHz**（美声专有）；缺频的位置甚至能下移到 4 kHz。
    ⚠️ **2 kHz 这一处必须始终缺着** —— 2 kHz 一多，听感发黏发腻，美声不该有这种质感。
  - 提 **3 kHz** → 明亮
  - 抬 **1 kHz** → 得到胸腔 / 口腔共鸣，声音更厚重（抬完把鼻腔那部分控制在小幅度）
- **男声美声**：上面这些频点整体往低处挪；**700–800 Hz** 这一段抬胸声比例（女声对应的是 1 kHz）；共振峰大约在 **2.5 kHz**。
- **能量分布上的特点**：主要落在**两段** —— **1.5 kHz 以下**（胸腔、口腔）与 **2.5 kHz 以上**；**2 kHz 附近偏弱**，4 kHz 往上共鸣就不多了。
- **合唱**：多个声部压在**同一个音高**上时，各自的 **Pit 得彼此错开**；每个人都要把**轻辅音弱化掉，或者整体压低气声**，不然叠在一起轻辅音会炸。

## 4. 新民族唱法

> 中国歌唱家把传统民歌的唱法和西方美声揉在一起，形成了这种新唱法，**技法上更贴近美声**。

**和美声一样的地方**：都要求明亮、有穿透力、饱满；都用**大颤音**；都讲究**转音接上颤音**；**连续转音的音头同样让 Pit 下沉**。

**和美声根本上的不同**：美声要的是**立体、厚重**；新民族要的是**饱满、开阔、宽敞、明亮，甚至可以偏薄，低位置共鸣大部分都放掉**。

**与美声的分界（很重要）** —— 下面这些**美声禁止、新民族允许**：

| 项 | 新民族 | 美声 |
|---|---|---|
| 音头小 Pit **上扬**（小哭腔）凸显情绪 | ✅ 允许 | ❌ **硬边界** |
| 转音中间音头 Pit **往上甩**体现力度 | ✅ 允许 | ❌ 只能靠 Pit **往下走**体现力度 |
| **音头装饰加花**（民歌特色）| ✅ 允许 | ❌ 纯西方美声几乎没有 |
| **藏腔式 Pit 小跳跃**（草原 / 高原题材里尤其常见）| ✅ 允许 | ❌ |
| **滑音**用量 | 比美声**多** | 少 |

**颤音上的差别**：民族的颤音常**在音尾提前淡出、收掉**；美声则是**一边颤一边直接接到后一个音**。**民族以下颤居多。**

**两条最典型的民歌程式化技巧**

1. **音头**：**先在本音高上往下掉一点点，随后回到正常音高**（先使一下劲 → 力道收回去 → 再放出来），由 Pit 配合完成。
2. **句尾长音**：**先滑音滑下来，紧接着回头接上一串颤音**。

**分型**

- **抒情型**：音头基本走**弱起**、Pit 也基本是**平的**，装饰加得极少；长音要让位、给下一个字留力的时候，**先让颤音淡出，张力同时往下画**。
- **喜庆型**：音头与音尾的 Pit 都**往上扬，而且幅度相当夸张**；**高音区的颤音包络要画得格外大**。

**咬字**：追求**开口过程更慢、更开阔**（比默认咬字慢）。常用拆法：`腿→tu+ei`、`回→u+o`、`春→ch+uo+n`、`风→f+o+ng`；
也用源自京剧的**咬字断开**，卡在伴奏的停顿上。

**声库与 EQ**：中文声库的共振峰本来就离新民族很近，**性别参数通常不用动**，后期把音色捏亮就行。
- 高频**再多拉一些**；特别高位置那点**金属质感**要**留住**（美声则要削掉）
- **2 kHz 要维持饱满**（一拉低，宽敞感就没了）
- **把共振峰的位置抬上去**（女声能到 **4 kHz**、男声 **3.2 kHz**，高于美声男声的 2.5 kHz）
- **低频削一点**（放弃胸声）；元音处气声比例太高要拉下去

**动态**：几个风格里数民族抒情对动态最讲究 —— 要**一个字一个字往上推**。
固定套路 = "每个字都**弱起 → 再推上去**；**遇到带转音的字，就在转音那里先弱、再推**"。

**段落上的策略**：**开头几段先别用哭腔、也别用急促的音头下沉**（一出现，柔美的意境就破了）；
**等情绪真正起来，再把音头下沉、颤音幅度和夸张滑音放出来**。

## 5. 通用注意（跨风格）

- **唱法 = 若干小技巧的组合** —— 不同唱法之间技巧大量相通
  （**音头上的二度装饰音**在**藏腔、岛呗、戏曲、蒙古长调、新民族**里都能见到）。
- **风格内容默认不用**：按既定约定，**用户提出才用**；不要主动替用户套风格。
- **术语别混**：花腔（唱法类别）≠ 华彩（歌曲里最丰富的那一段）。
- **先看声库**：民族/美声/戏腔这三类对**音色**最挑（不是"像不像"的问题，是**整个发声体系**对不上）→ `10-声库与声线.md`。
- **不要用错工具**：呼麦、弹舌这类**超出当前工具能力**的，**如实告知用户**，别硬做。

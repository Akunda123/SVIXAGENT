# 案例：旋律与和弦打架（高小二度是硬伤）

> 分类：和声/旋律 ｜ 症状：明明和弦配对了，旋律唱上去就是"别扭""刺耳"，但说不出哪里错

## 问题

一段旋律配上 `C → Am → F → G` 进行，和弦本身标准。但唱出来某个字**特别刺耳**，像走音又不是走音。

## 诊断

**逐音查"避免音"**（旋律音与和弦内音的音程关系）：

| 位置 | 旋律音 | 当小节和弦 | 关系 | 判定 |
|---|---|---|---|---|
| 第 3 拍（强拍）| F4 | C (C-E-G) | F 是高**纯四度**（11 音）| ⚠️ 色彩最不明确，强拍上不该用它 |
| 第 2 小节强拍 | C#5 | Am (A-C-E) | 相对 C 是**高小二度** | ❌ **硬伤** |
| 第 4 小节 | G4→A4 | G (G-B-D) | 经过音，落在弱拍 | ✅ 没问题 |

**根因两条**：
1. **高小二度**：旋律音比和弦内音**高一个小二度**（C#5 vs C5）——这是硬伤，最刺耳。
2. **11 音（纯四度）落在强拍**：F 在 C 和弦里是 11 音，色彩最不明确，**重音位置必须留给其他和弦音**。

## 怎么改

**避免音铁律**（口诀）：
> 旋律音要么**压在**和弦内音**下方**（低小二度也无妨），要么**往上高过大二度**。**高小二度属于硬伤。**

具体改法：
- **C#5 → C5**（改成和弦内音），或把和弦换成 `A7`（C# 成为 3 音）。
- **强拍上的 F4**：换掉，或把该拍的和弦换成 `F` / `Dm`（F 成为根音/3 音）。11 音挪到**弱拍**当经过音。

## 改后效果

```
改前: C#5 落在 Am 的强拍上         → 刺耳
改后: C5（和弦内音）或换 A7 和弦   → 顺
改前: F4 强拍（C 和弦的 11 音）     → 发闷
改后: F4 挪到弱拍 / 强拍换和弦      → 色彩明确
```

## 可复用判断标准

1. **强拍音必须是和弦内音**——和弦代表这一小节**所有乐器音高之和**，不只是人声伴奏。
2. **高小二度是硬伤**（旋律高于和弦内音小二度）：低小二度可以，高大二度以上可以。
3. **11 音（纯四度）的色彩感最模糊**：重音位要留给别的和弦音；**13 音压在重音上同样是硬伤**。
4. 诊断动作：**逐音列"旋律音 vs 当小节和弦内音"的音程表**，标出小二度/11 音/13 音。
5. 改的方向有两条：**改旋律音**（靠向和弦内音）或**改和弦**（让该音变成和弦音）——后者更自由。
6. 交付前自查：**全选 MIDI 一起看，查大二度/小二度撞音**（5 分钟，导出前必做）。

# 案例：段落安排不够好、整首没有推进感

> 分类：段落结构/推进 ｜ 症状：听着不难听，但听完没有印象；副歌也不炸

## 问题

一首 3 分半的华语流行。配器齐全（架子鼓、贝斯、钢琴、木吉他、弦乐），旋律也已经唱过。反馈是「不难听，但听完没印象，副歌也不炸」。

工程实际情况：

- 前奏 8 小节，所有乐器一上来就全进。
- 主歌 A：全套继续，只比副歌小 2 dB。
- Pre-chorus：配器与主歌完全相同，和声则是 VI-V-VI-V。
- 进副歌前最后一个和弦落在 I 级。
- 副歌：全套乐器，外加一层弦乐。
- 第二段：主歌 A' 的配器与 A 完全不一样，Pre-chorus 推倒重写，副歌再叠第二把吉他和一个 Pad。
- 尾声：直接淡出。

## 诊断

**① 前奏就把牌打光了。** 一开场所有乐器齐鸣，后面再没东西可加。剩下来能用的手段只有推音量——结果副歌只比主歌响了 2 dB，听感上等于没动。

**② Pre-chorus 在原地兜圈子。** VI-V-VI-V 不管看大处还是看小处都在打转，没有方向。这一段本该把情绪垫上去，实际什么也没干。

**③ 进副歌前回到了主和弦。** 主和弦的意思是「准备回家了」。在最需要绷紧的地方松了手，情绪泄掉，出现脱力感。

**④ 第二段动得太多。** 主歌换了配器、Pre-chorus 推倒重来、副歌又叠两层——**流行的变奏一多就用力过猛**：情绪一路起伏，听众找不着北；第二段主歌与第一段的关系也断了，什么也记不住。

**⑤ 结尾淡出。** 等于放弃终止式。

**根子**：它把推进理解成了「越弹越响」和「花样越加越多」，而没有靠配器加减、和声色彩与留白。

## 怎么改

### 第一步：给每个段落定能量档位，用配器加减来实现

| 段落 | 谁在响 | 说明 |
| --- | --- | --- |
| 前奏 8 小节 | 钢琴与木吉他分解，鼓和贝斯不进 | 先留牌 |
| 主歌 A | 加进贝斯，军鼓改 Side Stick | 节奏散成附点八分 |
| Pre-chorus | 架子鼓撤走，木吉他扫弦接管律动，弦乐进来 | 见第三步 |
| 副歌 | 全体进场，弦乐加厚，Crash 压第一拍 | 能量最高点 |
| 第二段 A' | 与 A 一致，只多一层高声部 Pad | 见第四步 |
| 第二段 Pre / 副歌 | 与第一段逐音相同 | 照抄 |
| C 段或间奏 | 停一小节 → 只留钢琴与人声 | 第二次落差 |
| 末次副歌 | 先鼓边渐进，再全体涌入 | |
| 尾声 | 钢琴铺底加人声哼唱，落在 V→I | 终止感 |

**要点**：段落的能量高低由「谁进、谁不进」决定，推子只负责平衡。

### 第二步：把 Pre-chorus 的和声改成有方向的

Pre-chorus 的和声换成 VI-V-IV（把原来那条 VI-V-VI-V 替掉）；或者更干脆一点：在 IV 级上 hold 两小节，再转 V 级。

- 用山的比喻：I 级站在山脚，IV 级是一步步往上垫，V 级站在山顶准备跳。
- 副歌前那一个收尾和弦必须是属和弦（日系摇滚里约 99% 如此）。
- 副歌开头用终止式接进去（V→I），副歌才炸得起来。
- 注意：音往下走情绪照样能上去——这跟音高走向关系不大，是换和弦之后色彩变了。

### 第三步：Pre-chorus 值得比主歌副歌投更多心思

做法是：**打击乐全撤，让另一件乐器弹出节奏性律动来支撑**（木吉他扫弦、钢琴柱式切分、古筝都行）。

理由很实际：主歌副歌的旋律本来就偏洗脑，靠这种不起眼的位置把整体质感抬起来，傻旋律才不那么傻；而且副歌鼓组全体回来的那一刻，冲击力会成倍放大。

### 第四步：第二段大面积照抄

**流行的快感来源就是重复与熟悉。** 第二段的 Pre-chorus 与副歌整段照抄第一段，不改一个音。

只在主歌 A' 留一处变化，而且挑省心的位置：木吉他持续扫 VI 级不动，只让旋律走动，另挂一个 Pad 在高声部做色彩变化，功能仍锁在 VI。**这里刻意写得比第一段更平**——前面的推进感已经很强，写平是为了给下一次推进攒新鲜感。

心力花在「哪几处要变」上，其余原样照抄。

### 第五步：C 段与末次副歌之间用留白

**衔接没思路、前后段落又差异很大时，留白最省事也最有效。** 所有声部停一小节（或半拍），然后一起砸进来。

末次副歌改用减法：木吉他先独自打节奏，贝斯与打击乐押后进场，鼓只打鼓边慢慢铺开，最后全体涌入。这是第二种层次。

### 第六步：结尾用终止式收住

尾声用钢琴铺底、人声哼唱，落在 V→I。**要让人记住，就得有终止感。**

## 改后效果

- 主歌与副歌之间有明确的能量落差，而且是配器差，不是音量差。
- Pre-chorus 有方向了，进副歌那一下有释放感。
- 第二段照抄之后，副歌旋律两遍就进脑子了——「听完没印象」这条就解决在这儿。
- 第二段主歌刻意写平，末次副歌的冲击力反而更强。
- 留白、做减法、再全体涌入，全曲的第二个高点就出来了。
- 结尾收得住。

## 可复用判断标准

1. 把前奏当作留牌的机会——**先只出一部分配器**，后面的加法才有地方加。
2. 推进感来自配器加减、和声色彩与留白；推子只负责音量平衡。
3. 进副歌前用属和弦，副歌开头用终止式，结尾走 V→I。
4. Pre-chorus 撤打击乐、换乐器扛律动，是性价比最高的一招。
5. **第二段大面积照抄是专业写法**；心力花在「哪几处要变」上，而且要挑省心的位置变。
6. 变奏一多就是用力过猛，听众会找不着北。
7. 乐句按 4 小节走，乐段是 4 / 8 / 16 小节。

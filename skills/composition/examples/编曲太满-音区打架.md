# 案例：编曲太满、音区打架

> 分类：配器/编曲 ｜ 症状：听着糊成一团、听不清人声、每件乐器都在响但没有层次，而且「EQ 怎么调都救不回来」

## 问题

一首中速流行铺了七件乐器：钢琴、木吉他、失真吉他、贝斯、弦乐组、Pad、架子鼓（人声先用钢琴代替）。
听感：**很满、很浑浊**，人声听不清，单独听每件乐器却都没毛病。

工程里各声部实际写成这样：

| 声部 | 实际写法 |
|---|---|
| 钢琴 | 左手在 C2–C3 堆柱式和弦，右手在 C4 弹和弦 |
| 木吉他 | 全用最低几根弦，音区落在 E2–E3 |
| 贝斯 | E1–E2 |
| Pad | 从 C2 一直铺到 C5 |
| 弦乐组 | 大提琴 C2 / 中提琴 C3 / 小提琴 C5 |
| 失真吉他 | 只有一把，pan 在左边 |
| 节奏 | 所有乐器都走四分音符 |
| 声部关系 | 弦乐旋律与人声旋律同向同度上行 |
| 导出 | 整首导成了单声道 |

## 诊断

**① 音区打架（根本问题）**——钢琴左手、木吉他、Pad，加上贝斯与大提琴，**全挤在同一个 C2–E3 区间里**，所有旋律乐器撞在一起，音响必然浑浊。这是配器法最基础的一课没上。

低频区还踩到了 low interval limit 这条规矩：钢琴左手把柱式和弦堆在 C2，同时响的两个音间隔不到纯五度。音越低越要拉开距离，靠得近就一定糊，哪怕没有撞音。

**② 木吉他被写在错误音区**——吉他和钢琴同属中频乐器，作为节奏乐器时音区应当在 **E3–E4**（实际音高）。压到 E2–E3，就是直接和贝斯、钢琴左手抢地盘。

**③ 弦乐组的音区分配错了**——大提琴 C2 已经踏进贝斯区；**倍大提琴与大提琴之间、大提琴与中提琴之间的音程至少要有五度**，这里大提琴 C2 到中提琴 C3 是纯八度，勉强合规，但整组压得太低。另外中频已经有钢琴和吉他，**中频乐器有两样通常就够了**，中提琴完全可以砍掉。

**④ 全部走四分音符**——织体一顿一顿。**每件乐器该贴不同的鼓件、走不同的节奏层。**

**⑤ 弦乐与人声同向同度 = 无效写作**——节奏重合、走向也重合，两条线互相削弱力度，听起来反而没色彩。更麻烦的是人声出现时同音区还堆着别的东西——**人耳是跟着一条线条在听的**，两条线抢位置，耳朵就不知道该听谁。

**⑥ 失真吉他只有一把**——摇滚与流行摇滚里，失真吉他从来是两把成对出现，左一把右一把、弹的内容完全相同。只留一把必然稳不住。

**⑦ 导出成单声道**——后加的 Pad 直接白做，所有声像设计一起报废。

**⑧「EQ 救不回来」的真正原因**——**混音在挑乐器的那一刻就开始了**。这首歌缺的并不是 EQ：EQ 只能做减法，补不回一个根本不存在的频段，也拆不开两件挤在同一频段的乐器。

## 怎么改

### 第一步：画一张频段分配表，一件乐器占一格

| 乐器 | 目标音区 | 频段职责 |
| --- | --- | --- |
| 贝斯 | E1–E2 | 低频 80–200 Hz |
| 底鼓 | — | 超低频 + 低频 |
| 钢琴左手 | 抬到 C3 上下，E1–E2 归贝斯 | 中低频 200–500 Hz |
| 大提琴 | C2–C3 | 中低频，节奏与钢琴左手错开 |
| 木吉他 | **E3–E4**（别再用最低那几根弦）| 中频 500–3000 Hz |
| 失真吉他（两把）| E3–E4，一把 pan L、一把 pan R | 中频 |
| 钢琴右手 | C4–C5 | 中高频 |
| 小提琴 | C4 起，情绪激烈时上行 | 高频 |
| Pad | **C4–C6**，做低切 | 高频填充 |
| 人声 | C4–C5 | 把 400–1000 Hz 让出来 |

**中提琴直接砍掉。** 中频里钢琴、木吉他和失真吉他已经三样，大提琴还能顶掉它一部分角色。

### 第二步：Pad 做低切

Pad 从 C2 铺到 C5，是「太满」的头号元凶。把它低切到 400 Hz 以上，只留高频那一段做填充。铺底乐器不等于可以把整条频谱占满。

### 第三步：钢琴左手拉开音程

低音区里同时响的两个音，间隔至少一个纯五度——写一个五度就够，这也是最常规的写法。左手最高音到右手最低音的距离，压在八度以内：钢琴的音色决定了它适合相对密集的排列。

### 第四步：拆开节奏层（关键）

```
钢琴      二分音符柱式      ─── 和声骨架
木吉他    四分音符分解      ─── 中速律动
弦乐      八分音符长音      ─── 流动感
失真吉他  四分音符强力和弦  ─── 中频支撑
贝斯      贴底鼓重音        ─── 低频推进
```
各自走不同节奏层 → 织体立刻立体。

**把每件乐器的线单独拎出来听，也该是好听的**——这是弦乐写作的基本要求，其他乐器同理。

### 第五步：解决弦乐与人声打架

三条路挑一条：

1. **走反向或斜向**：人声往上走时弦乐往下走，或者人声在动、弦乐就按住长音。**最要紧的一步仍然是把节奏错开。**
2. **同度齐奏（省事且不会错）**：让弦乐跟人声弹一模一样的旋律做同度齐奏——流行里常用它来呼应强调——但只放在人声不唱的空余小节。
3. **填空**：人声一句唱完的空当里，弦乐接一句补上。加花的本质就是填空：我这条线结束的地方，你在别处接上去。

小提琴越过 C5 之后会成为全曲最抓耳的声音，**有人声时压住它，主角的位置留给人声**。

### 第六步：失真吉他复制成两把

两边各一把，左 pan 100 / 右 pan 100，弹的东西一模一样。扒不出来就去翻别人的 cover 看。

### 第七步：声像与导出

- 中频乐器（吉他、钢琴）摆两边。
- 贝斯、底鼓、军鼓与人声一律居中。
- **一律导 stereo。**
- 剩下的乐器做干净的低切，把 400–1000 Hz 这一段让给主唱；伴奏压得更狠一点（增益衰减取 -5 ~ -10 dB、attack 20 ms 上下），把动态余量和空气感都留给主唱。

### 第八步：导出前必做的自查

**把所有 MIDI 全选起来一起看，找出大二度、小二度的撞音**，这件事五分钟就能做完。

## 改后效果

- 浑浊消失——不是 EQ 削出来的，而是每件乐器回到了自己的频段。
- 人声浮出来了：同音区的东西被挪走，400–1000 Hz 让了出来。
- 节奏层拆开之后，织体从「一顿一顿」变得有前有后。
- 砍掉中提琴反而更清楚——**问题从来不在乐器数量，而在频段冲突**；很多日系和 R&B 作品的配器比这还少。
- 失真吉他两边一出来，中频立刻宽了，也稳住了。
- 声像设计生效，听感是被环绕的。

## 可复用判断标准

1. **中频（C3-C5）最多留 2 件乐器 + 人声**，超了必糊。
2. **两件乐器不能走同一个节奏型**——同向同度的声部是无效写作。
3. **低频只给贝斯/底鼓**，其他乐器低于 C2 的音要检查是否和贝斯撞。
4. 低频区同时响的两个音，间距至少要有一个纯五度（low interval limit 这条规矩）。
5. **每件乐器一个频段，全程稳在里面**——"少了某件乐器留下的频段空洞，靠 EQ 补不回来"，混音在选乐器时就开始了。
6. 人声一进来，同音区就腾给人声；真要垫，只做同度齐奏。
7. 摇滚里的失真吉他必须成对：两把各占一边，弹的内容完全相同。
8. 一律导 stereo，否则前面的声像设计全废。
9. 所谓「编曲太满」，十有八九不是乐器太多，而是乐器全挤在一处。
10. 诊断"糊"的第一动作：**列乐器音区表 + 节奏层表**，重叠处就是病因。

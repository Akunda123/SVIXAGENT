# 案例：想借鉴参考曲，结果整首跟人家一样

> 分类：创作方法/借鉴 ｜ 症状：成品与参考曲相似度过高；作者的自辩是「旋律我改了、调也换过」

## 问题

这是一首日系流行，参考曲挑的是一首耳熟能详的 J-Pop。反馈是：跟参考曲像得已经不能算借鉴了。

逐项对照下来，这首歌从参考曲里取走的东西：

- 整首都套 `IV-V-III-VI`（4536）这条进行，而且主歌、Pre-chorus、副歌各分到哪一段也照抄。
- 参考曲副歌第 3 小节的 IV 级做的是 sus4 转大三，这首歌在同一位置也做 sus4 转大三。
- 主歌那串转位走法原样搬了过来：`IV → I/III → Vsus4/II → I`，一个音没动。
- 旋律的骨架音走向、节奏型与参考曲高度接近。
- 律动、配器、鼓的写法一并照搬。

## 诊断

**用 4536 本身不是问题。** 4536 属于公共财产，日系流行里到处都是。套路和声的长处就是「它确实好听」，写作者做的事不过是：在几个成熟模型里挑一个跟当前推进方向对得上的套上去——大量入门作品从头到尾套 4536 也能过关。

真正的问题叠了三层：

**① 进行、转位、织体是捆在一起搬走的。** 单拿一段和声进行没问题；但把「参考曲用 sus4 转大三，我也跟着转」「参考曲把 I/III 做转位下行，我也照样下行」一起搬，复制的是参考曲的**声部写作**，不再是在使用一条公共进行。这种像，是听得出来的。

**② 旋律骨架也被拿走了。** 这是全场唯一一条不能碰的红线：配器、律动、和声进行都学得，唯独旋律学不得——两首歌的旋律撞上了，才是真的像。「换了调」救不了场：情绪色彩由调式决定，跟调高没关系，C 大调与 G 大调并不会因此变成两种情绪。

**③ 连段落分工都对齐。** 哪一段配哪条进行、位置一模一样，等于把参考曲的曲式也一并借走了。

**判据**：把两首同速对齐播放，如果大段能对上，那就是照搬。

## 怎么改

### 先分清哪些能借

| 可以借 | 不许借 |
| --- | --- |
| 调性、和声色彩 | 旋律本身（骨架音走向与节奏型）|
| 律动、拍号、速度 | 整段进行连同转位手法与织体 |
| 配器的种类与数量 | 哪一段配哪条进行 |
| 鼓的写法与力度习惯 | |
| 声像摆位、响度排序、频段分配 | |

配器「拿来就用」基本不出事——本质上等于在记一种节奏型。

### 具体动作

**① 4536 留着，转位手法扔掉。**

进行保留，全部退回原位柱式，再自己决定哪几处需要转位。转位只为两个目的服务——躲开难听的音程、把贝斯的音高稳住——理由必须从这首歌自身的问题里推出来。

重算一遍：贝斯线里有没有超过五度的跳进？旋律与低音之间出现过同度、或隐伏八度吗（8 小节内最多允许 1 次）？按这些答案决定转位，结果自然与参考曲不同。

**② 段落分配改掉。**

参考曲的排法是：主歌与副歌都走 4536，Pre-chorus 走 4536251。可以这样重排：

- 主歌改用小调色彩的走向（VI-III-IV-I），先把调性平衡住；
- Pre-chorus 就停在 IV 级上把情绪按住；
- 4536 留到副歌再用，进副歌之前拿属和弦顶一下。

这样 4536 还在，但结构关系是自己的。**流行本来就是层层递进或情绪交替，段落之间的调性色彩要互相平衡。**

**③ 旋律重写，而且必须唱出来。**

- 先关掉参考曲，对着自己的和弦即兴唱几遍、录下来。
- 拿录音查三个证据：是不是每个音都落在五声音阶里（即兴唱不可能做到）？有没有句法结构？一句之内有没有跨八度？
- 用挂留的思路写旋律：音还是和弦音，但线条走 `do-re-so` / `do-si-so` 这种带色彩的走向，把 `do-mi-so` 那类傻瓜式和弦音换掉。
- 中文一句写到 6–7 个字就该留气口了。

**④ 律动动机换成自己的。**

参考曲的律动骨架可以学（比如军鼓落在哪、hi-hat 有多密），但**律动动机**——那个反复出现、听众能一把抓住的东西——得自己造：把贝斯的切分位置挪一挪，或者换件乐器来扛节奏，都行。

**⑤ 一次只学一首。**

同时挂两首配器语言完全不同的参考曲（比如一首布鲁斯摇滚、一首金属），学法会当场乱掉。**选一首，拆到一个元素都不漏。**

## 改后效果

- 和声骨架还是那条好听的 4536，「好听」没有损失。
- 转位与声部走法是从这首歌自己的问题推出来的，不再和参考曲逐音对应。
- 旋律是唱出来的，有气口、有方向、有跳进与级进的分工，与参考曲不再重合。
- 段落分配换过之后，两首同速对齐播放已经听不出是同一首。
- 留下来的是「为什么这里要转位」的理解，而不是「参考曲这里转位了」的记忆。

## 可复用判断标准

1. **借鉴只借元素，整首得自己搭。**
2. **旋律自己写**——这是唯一一条硬红线。
3. 「换了调」不算原创——调高并不能改变情绪色彩。
4. 参考曲只选一首，拆到不漏；没有参考曲等于漫天打靶。
5. 转位的理由是「躲开难听音程 / 稳住贝斯音高」，不是「参考曲这么转过」。
6. **写法可以学小众歌；混音与制作水准要去学正经出版物。**

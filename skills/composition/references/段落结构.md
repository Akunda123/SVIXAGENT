# 段落结构（Form & Structure）

> 补充 SKILL §6。核心：**流行快感来自重复性和熟悉感**。
> 另：本文 §5（减法优先）原为 `SKILL.md` §11.1，已并入本文件。

## 1. 基本单位

- 乐句 4 小节，乐段 4/8/16 小节。
- 常用结构：`Intro → Verse → Pre-Chorus → Chorus → Verse2 → Chorus → Bridge → Chorus → Outro`。
- 动态段（电子）：`Build → Drop → Breakdown`。

## 2. 各段职责

| 段 | 职责 | 药方 |
|---|---|---|
| Intro | 营造氛围 | 精简配器、留悬念 |
| Verse | 叙事推进 | 舒展、字多、信息量 |
| Pre-Chorus | 蓄力 | **值得花最多心思**：撤打击乐、换一件乐器扛律动 |
| Chorus | 高潮记忆点 | 最亮、最齐、最重复的记忆点 |
| Bridge | 转折/升华 | 功能可换、情绪对比 |
| Outro | 收束 | 渐弱/回主功能 |

## 3. 推进手法

- **第二段大量复制粘贴是正常做法**，精力花在「决定哪几处变」上；变太多用力过猛。
- 进副歌前一般走**属和弦**（日系摇滚里占比接近 99%）。
- 段落衔接、前后变化大时，**留白**最万能（量化做法见下）。
- 高音区在副歌；Pre-Chorus 可推高张力。

### 推进靠配器加减，不靠音量

> 📌 来源：SynthVCopilot-SKILLS《段落与结构》「怎么做推进感」（摘要改写）

典型的三段推进是这么分层的：
- **主歌**：乐器少，节奏散（附点八分那种），律动偏弱，先给后面留足余地。
- **Pre-Chorus**：塞进一件此前没露过面的乐器（古筝刮奏、切片、钢琴柱式都行），鼓从散拍回到常规节奏，律动比主歌高一档。
- **副歌**：配器堆到最满，**Crash 落在第一拍**。

判据：**副歌如果只是把总推子推大 2 dB，等于没有推进。** 推子动的是整体响度，不是层次；听众靠「多了什么、少了什么」识别段落，不靠音量表。Pre-Chorus 这一段的性价比最高，值得投进比主歌副歌更多的心力——撤掉打击乐、换一件乐器扛律动，是常用且有效的做法。

### 靠和声色彩推进

- 该往上推却写成 **6→5→6**，等于绕一圈回原地；改成 **6→5→4** 才真的顶上去。
- **音往下走，情绪照样能上去**——这跟音高走向无关，是换了和弦之后色彩变了。
- 副歌前那个收尾和弦若落回主和弦，情绪会泄掉、有脱力感。改法是停在 **IV 级 hold 住**再释放，或者走 **III→VI**、**IV→V**。
- 想让副歌炸，**必须用终止式**；终止式的具体用法见 `和声进行.md` §9。

### 留白的量化

- 衔接没思路、前后段落又差异很大时，留白最万能：**所有乐器先全停**，停够半拍到一小节，然后一起轰进来。
- 留白长度可以当旋钮用：停得越长，越像一段大段落的边界。
- **第三段副歌反着做减法**：木吉他单独扫节奏，贝斯与打击乐先别进，鼓只打鼓边慢慢铺开——这就是「第二种层次」，最后一轮副歌不靠更响、靠更空取胜。

### 前奏留牌，收尾收住

- **前奏只出一部分牌**：鼓和贝斯先别进，或者只留两件分解乐器。一开场就把全套摆满，后面再没有加法的余地，推进只剩推推子一条路。
- **结尾别用淡出。** 淡出等于放弃终止式；想让人记住就得有终止感，用钢琴打底加人声哼唱、落在 V→I 收住最稳。
- 第二段的变奏额度只留一处，而且要挑省心的位置——比如木吉他一直扫同一个级数不动、只让 Pad 在高声部做色彩变化；其余段落整段复制粘贴。

## 4. 能量动线（整首）

```
Intro(低) → Verse(中低) → Pre(升) → Chorus(高) → Verse2(中低) → Chorus(高) → Bridge(低/对比) → Chorus(顶峰) → Outro(收)
```
- 不要全程一个能量档；起-承-转-合。
- 「合」要回到主功能/主调，才有结束感。

## 5. 进副歌先"减"再"加"（减法优先）

> 承接原 `SKILL.md` §11.1。推进感**不等于**一路加东西。

**有效的抬升往往来自减法**：进副歌前抽掉一层（鼓 / 和声垫 / 低音），或留一小节空。

- 判据：**哪一小节谁退出**、退出落点是否**正好在小节线**上；
- 反例：为了"炸"在 pre 里把乐器加满 ⇒ 副歌无处可加，听感反而平；
- 反直觉但合法：**第二段主歌比第一段更空**也是选择 —— 取决于你想让副歌显得多高。

> 规格表里的「进出场」字段就是拿这条判据核对的（见 `规格表.md`）。

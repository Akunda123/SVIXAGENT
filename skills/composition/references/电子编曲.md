# 电子编曲（Electronic Arrangement）

> 📌 来源：SynthVCopilot-SKILLS `composition-arrangement` 的 `references/电子编曲.md`（主素材）、`references/配器与音色.md`（第 61–155 行）、`examples/电子编曲只写了上半部分.md`（摘要改写；上游 source-available，不逐字照抄）。
>
> 配合 `references/编曲配器.md`（频段 / 音区 / 常见病）与 `references/段落结构.md`（Build → Drop 动线）一起看。
>
> **核心判断**：电子乐先看听众能不能踩上拍、肯不肯动起来，音色好不好听排在第二位。和声要干净，色彩要说得清。

## 1. 电子硬伤清单（按出现频率排）

### 1.1 Sub bass 写高了一个八度

- **合格位置：E1–A1（大字一组）。** 落到 E2–A2 就是整体高了一个八度。
- 高过 A1 之后它只是条普通的贝斯线，低音重量全部消失。
- 这条错误戴耳机根本听不出来，必须开监听音箱或看频谱确认。

### 1.2 底鼓的音高没有压在军鼓下面

- 两者的参数写法确实接近：起音几乎瞬间到位，Sustain 和 Release 都归零，Decay 偏短。
- **硬性要求：底鼓必须比军鼓低。** 底鼓主体在 50–150 Hz，军鼓的低频主体在 200–300 Hz。
- 两者音高撞在一起，打击乐组就分不出层，鼓听起来是一团。

### 1.3 Pad 塞进低频，挤到贝斯的地盘

- Pad 的岗位是中高频填充。把它按到低频去，就是抢地盘。
- **Pad 必须低切**，只留高频 / 中高频那一段。
- 回到最底层的规矩：一件乐器认领一段频率，全程别跑出去。
- 最常见的具体症状是底鼓和贝斯在 100–200 Hz 打架；曲线峰值错误地堆在这里，鼓会发塑料味。

### 1.4 没有律动动机，也没有重音

- 症状：整首找不到一个强调重拍的音，跟着打拍子打不下去。
- 正确起步：**先钉一个律动动机**（鼓 + 贝斯），之后每一拍换一个抓耳朵的元素顶上去——人声切片、失真的 Bell、两声 Bell、Wobble bass 都行。
- 有些电子曲压根没有主旋律线条，全靠律动推着走。
- **一上手先写旋律，路子从第一步就走偏了**：旋律会盖过律动，最后只能靠不断加东西补救。

### 1.5 侧链该挂不挂

- Future Bass、Electro House 这两类的贝斯层和 Pad 层，常规做法就是挂侧链压缩。
- 别人的歌听着顺，多半不是写得花，而是**制作到位**。
- 判断很直白：低频元素与底鼓同拍，却不跟着抽吸 → 该补侧链。

### 1.6 和声铺得太乱

- 进行写得简单，就让它清清楚楚摆在那儿，别往上堆东西。
- 典型连锁反应：乐器结构没抓住 → 拼命加旋律 → 新旋律的音没跟和弦对齐 → 整体糊成一片。
- **Pad 同样得落在和弦内音上**：铺底乐器不是自由声部，它也是和声的一部分。

### 1.7 循环周期写错

- 参考曲里 Pad 一小节回来一次，你写成两小节一次，律动跟着一起变形。
- **一个元素隔多久重复一次，本身就在参与律动的塑造**，不只是配器问题。

### 1.8 声部只出现在一边

- 锯齿类元素只放在右声道 → 整体听感单边倾斜。
- 改法：**左右同时出现**，后面再垫一层 Pad（加大混响的电钢、做大架构的弦乐）。
- 低频与人声照旧归正中间。

### 1.9 音色做到位了，音乐性没跟上

- 旋律连自己都哼不顺、和声跟旋律对不上调、整首没有能说清的结构。
- 这类作品救不回来，退回去重写，不要在音色上继续加码。

## 2. 拆解音色的四层

拿到一个音色想仿出来，先别抄参数，按四层问自己：

| 层 | 听什么 | 由什么决定 |
|---|---|---|
| **声音类型** | 短促还是悠长？音头利不利？在曲子里顶哪件真乐器的班？ | **ADSR** |
| **声音质感** | 刺耳还是温和？厚还是轻？ | **振荡器波形** |
| **声音变化** | 整段里音高、音色有没有动？ | **包络 + LFO** |
| **声音特色** | 跟一种纯波形比，多了什么味道？ | **后处理**（滤波、混响、失真、合唱） |

- 四层彼此独立可调：先定类型（ADSR）→ 再定波形 → 最后才动 LFO 与后处理。
- 判断「像不像」也照这个顺序走：类型不对，后面怎么调都不像。

## 3. 常见音色配方表

| 音色 | 频段 | 波形 | 手法 |
|---|---|---|---|
| **Kick 底鼓** | 50–150 Hz（做 Trap 时取 80–100 Hz） | 近正弦 | Attack 很短，Sustain 和 Release 归零，Decay 略短。音头那一瞬间，在音高上叠一个包络或单次 LFO，做出鼓皮那一下 |
| **Snare 军鼓** | 低频主体 200–300 Hz | 近正弦 + 白噪 | 做法与底鼓一致；起音之后叠一层白噪，模拟弹簧震动 |
| **镲片** | 高频 | 白噪 | 起音极短，Decay 和 Release 都拉得比较长 |
| **808 / Sub bass** | 基频 40–60 Hz | 正弦 | ADSR 近似底鼓但 Release 拉长；**音头处用 LFO 提一下音高**，音头才立得住 |
| **Pad** | 中高频 | 方波 / 锯齿 | Attack 拉很大，Decay、Release 同样大；**滤波器或音量上挂 LFO** 让它一直动 |
| **Pluck** | 中频 | 锯齿 / 三角 | Attack 偏小、Decay 较大、Release 保持小（大了会拖）；角色等于钢琴或吉他 |
| **Lead** | 中高频 | 锯齿类 | Attack 不能太小，Sustain 大，常配 Portamento（Glide）与 LFO |
| **Bell** | 高频 | 方波 / FM 波表 | 做法跟 Pluck 一路，但换更刺的声源 |
| **Bass（锯齿型）** | 贴着真贝斯的音区 | 锯齿 | Attack 大、Hold 大、Release 小，干脆利落，律动才清楚 |

旁注：

- 采样合成器自由度最高，能做一般合成器逻辑推不出来的声音；FM 适合纯噪音、音效和仿真实乐器的复杂声音。
- 调色工具还是同样的几样：包络、LFO、滤波。

## 4. LFO 的三种挂法

| 挂在哪 | 频率 | 听感 |
|---|---|---|
| 总线音量 | 每十六分音符循环一次 | 颤音 |
| 总线音量 | 每四小节循环一次 | 像波浪一样起伏 |
| 滤波器 | — | 一开一合的「哇」声 |

- **音色刺耳，最常用的解法是挂一个低通、切掉一段高频。** 先试这个，再考虑换声源。
- 挂 LFO 顺手把深度开够；幅度太小等于没挂。

## 5. Build up 与 Drop

### Build up

- **底下至少垫一层锯齿**，并且一小节比一小节升高音高。
- 音效常用 Riser、Swell。
- 与 Drop 的质感反差做得越大越有效。

### Drop

- **Lead 要厚**：厚度来自多层叠加——高八度一层、低八度一层、再加一个纯五度，最底下垫正弦稳住基频。只写单音一定单薄。
- 厚 super saw 的常见配法（把失真吉他让出的频段填掉）：两个锯齿振荡器，unison 拉到最宽，上下各叠一个八度，底部垫正弦并混一点白噪。
- 段落之间做不出层次差，**常常是少了一层挂在高频的 Pad**。
- 参考曲里 hi-hat 经常和打击乐组落在同一个点上，为的是把每一下的力度加厚——这招可以照学。
- Hit 类音效配大混响，能炸出力度与空间感。

## 6. 分风格的具体要求

### House

- 音色不限。
- 底鼓四踩（Four-on-the-Floor），其余打击乐自由。
- 贝斯得写出活力来，不能只铺长音。
- **先把 House 的律动骨架保住，再往上搭和声**；和声节奏定下来就别乱动，四踩的骨架要全程听得见。

### Trap

- 底鼓主体频段 80–100 Hz，**这一段低频的主角是 Sub bass**，别让底鼓占满。
- Hi-hat 要打得没有规律，越规整越不像 Trap。
- 旋律一般走小调。

### Future Bass

- **左右那两层锯齿，本质属于贝斯声部，不能当中频乐器使**：
  - 两耳音量必须相等、摆在正中；一旦 pan 到两边，这个角色就废了。
  - 在滤波器上挂 LFO，让它晃起来，幅度要开大——这是这个风格的标志听感。
  - **音高往下压**，重心放在中低频，别停在高频。
- 中频整体也要偏锯齿。
- 和声层可以堆七和弦、九和弦这类延伸和弦，调性一般是大调。
- 低音层交给 Sub bass。
- Wobble bass 与 Hi-hat 要在律动上错开；别的乐器加花时，hi-hat 回去打稳的十六分。
- 军鼓写法：先把完整一套鼓组写出来，随后把底鼓整条拿掉，改在每小节头一拍补一声军鼓；重心压在 2、4 拍，每一层力度都要拉开，把重音放到反拍上去——这套思路和底鼓完全分开。
- 速度约 130–160 BPM（贴着 Trap 走）。速度一改，风格可能整个换掉。

### Lo-fi / Hip-hop

- 律动要让人陷进去：每小节都换花样，人反而陷不进去。
- 织体错开，律动感靠**填空**挣出来：萨克斯或主旋律的落点要跟贝斯让开，各自占不同的空档。
- 配置极简：鼓、贝斯、钢琴、萨克斯、Pad——其中旋律乐器只有三件。**越简单越容易露馅**，三件怎么用就是基本功。

### 元素清单（以 Electro House 为例）

一首好听的 Electro House 常常只有 6–7 样：

1. 底鼓
2. Clap
3. hi-hat（叠层 + 侧链）
4. 用 FM 或环形调制做的 Bell，Attack 很短，带半点打击乐味，弹和弦内音
5. 低通锯齿 Pad（同样挂侧链）
6. 八度 bass（挂侧链）
7. Lead

**数量不是重点，做没做到位才是。**

## 7. 「只写了上半部分」怎么救

> 症状的完整诊断过程见 `examples/电子编曲只写了上半部分.md`；这一节只放结论与数值。

典型听感：音色下了不少功夫，结果又薄又飘，Drop 也不炸；基频掉在 40 Hz 以下，能量全堆在超低频。

**缺的是低频声音设计这一整层**，不是音量问题，EQ 也补不回来。要补三样：

1. 一条 **Sub bass**，失真开得很重。
2. 一只**很薄很近**的底鼓——能量集中在 100 Hz 往上，与 Sub bass 分工，谁都不抢谁。
3. 一点锯齿波，做中低频的衔接。

这一层撑起来的是「本来很轻，突然轰一下」的对比。少了它，作品就只剩上半身，再怎么调也炸不起来。

同一份诊断里的配套动作：

- Sub bass 降回 E1–A1，正弦波 + 较长的 Release，音头用 LFO 提音高；基频落在 40–60 Hz，别掉到 40 Hz 以下。
- 打击乐分频：底鼓 50–150 Hz，军鼓低频 200–300 Hz（音头后加白噪），hi-hat 走高频道用白噪。
- Pad 低切到中高频以上，只做高频填充；要补层次时，新加的那层也得留在高频。
- Lead 叠八度与五度，单音不成。
- 速度先锚定到风格区间，其他判断才立得住。
- 锯齿波保持干声；人声切片也要和其他元素共处同一个空间，距离感必须一致。

## 8. 交付前自查

- Sub bass 落在 E1–A1 吗？
- 底鼓比军鼓低吗？
- Pad 低切了吗，有没有和贝斯抢低频？
- 有没有一个说得清的律动动机？重音在第几拍？
- 低频元素与底鼓同拍，却忘了挂侧链吗？
- Pad 的每个音都在和弦里吗？
- 各元素的循环周期与参考曲对得上吗？
- 锯齿类元素左右都有吗？
- Build up 底下垫了锯齿、并且一小节比一小节高吗？Drop 的 Lead 叠上八度和五度了吗？
- 第 7 节那层低频设计补上了吗？

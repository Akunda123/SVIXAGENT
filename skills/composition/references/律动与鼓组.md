# 律动与鼓组（Groove & Drums）

> 📌 来源：SynthVCopilot-SKILLS\composition-arrangement\references\律动与鼓组.md（摘要改写；上游 source-available，不逐字照抄）

> 补充 SKILL §3.3 / §3.4。核心：**先把节奏的底子铺稳，再谈花活；律动不稳，听众的第一反应就是「乱」。**

## 0. 律动是什么

- 律动不等于「鼓 + 贝斯」，它是整首歌所有声部叠在一起给耳朵留下的风味印象。
- 速度相同、鼓型互换，风格标签立刻就换：动次打次是华语 R&B，咚次哒咚咚是摇滚，咚咚咚哒是 bossa nova。
- 现代流行歌里，节奏的可听权重不比旋律低。旋律写得再好，节奏塌了整首也立不住。
- 硬约束来自人体：鼓手只有两只手两只脚。**同一瞬间在响的鼓件别超过 4 个**，超过就没了真实感。

## 1. 鼓的写作顺序（6 步，别颠倒）

| 步 | 写什么 | 具体做法 |
|---|---|---|
| 1 | 底鼓型 | 先定驱动逻辑：平均四分（落 1、3 拍），还是靠附点推着走 |
| 2 | 军鼓 | 常规放 2、4 拍，技法用 Hit；情绪平缓的段落换 Side Stick（鼓棒横压鼓边，闷、体积小） |
| 3 | 固定镲片 | 多数风格默认上 Hi-hat，Closed 和 Open 交替使用最常见 |
| 4 | Crash | 落在段落第一拍，通常每 4 小节来一次；全曲最高点可以额外加 |
| 5 | Ghost Notes | 在弱拍或空隙塞音量极低的音符，一般交给军鼓 |
| 6 | Fill 加花 | 段落之间衔接用，主体是通鼓；摇滚里地通也能直接扛某段的主要节奏 |

第 3 步的两个补充：

- **段落之间可以换镲**：同类段落前半用 Hi-hat、后半切 Ride，听感有区别而骨架不变。
- **Ride 上打 Crash 技法只留给情绪顶点**，常规段落别滥用。

> 顺序反着来的代价很大：先写花、后补底子，基本等于推倒重做。

## 2. 力度分档（本节最重要，可直接落成 SV 音符 dynamics）

音源的采样是照着真人演奏录的，**同一套节奏听起来像不像人打，全看力度有没有分层**。

### 2.1 整体档位（占满力度的百分比）

| 风格 / 段落 | 建议区间 | 说明 |
|---|---|---|
| 摇滚 | 70%–90% | 要有冲击力，但不能整轨顶满 |
| 流行、古风、爵士 | 80% 以下 | 更收敛，给人声留空间 |
| 轻的段落 | 50% 上下 | 主歌、Bridge、清唱段 |

换算到 SV 的 dynamics（0–127 量表）：70% ≈ 89，80% ≈ 102，90% ≈ 114，50% ≈ 64。

### 2.2 逐件数值（直接抄）

| 鼓件 | 位置 | dynamics |
|---|---|---|
| 底鼓 | 正拍（1、3） | 100–110 |
| 底鼓 | 弱位 / 切分位 | 80 左右 |
| 军鼓 | 主要 Hit | 95–110 |
| Hi-hat | 正拍 | 90 |
| Hi-hat | 反拍 | 60–70 |
| Ghost（军鼓） | 弱拍填缝 | 30–40 |

补充规则：

- 军鼓改 Side Stick 的段落，整体再降一档。
- 一个段落里最好只出现 2–3 个力度档；档位乱跳是另一种「乱」。
- 音量大不等于有重音——**重音靠相对关系做出来，不靠绝对值。**

### 2.3 最常见的鼓组硬伤

- 军鼓每一下力度完全一致、重音全压正拍：听感立刻变机器。
- 全轨推到 127：每一下等重，听众感知的重音层级直接归零。
- 分层只做了鼓、没做别的声部：鼓有起伏但整体依旧平。

## 3. 铁律与硬性判据

### 3.1 鼓必须连续流畅

- 从第一小节一节接一节续到最后一小节，中间不留洞。
- 反面典型：前半小节塞满十六分，后半小节完全空白。这不是留白，是鼓丢掉了节拍器职能，听众当场失去落脚点。
- 留白是编曲手段，但**留白要在别的声部扛住时间的前提下做**，不能让鼓自己空掉。

### 3.2 重音必须被点出来

- 如果整首歌找不出任何一个音在强调重拍，那拍子就没法打。
- 有律动动机的轮廓、却在重音上没人点一下，等于这个动机不存在。
- 一旦点出来，零散的各声部会突然收拢成一件事，有了主心骨。

### 3.3 军鼓钉在 2、4 拍

- 军鼓落点直接决定听众感知到的重音位置。
- 想要变化，走音色（Hit ↔ Side Stick）和力度，别把军鼓搬走。一旦搬走，重音锚点跟着移位，一般听众就摸不清拍子落在哪儿了。
- 同理，**Hi-hat 要扛起全曲节拍器的角色**：前后段落的律动骨架要基本一致。老老实实走「咚 呲 大 呲」，比一小节只响一下的怪型稳得多。

### 3.4 抢拍进入前垫一下底鼓

- 人声提前半拍抢进来之前，先给一下底鼓，耳朵有了落点才不会觉得「进早了」。
- 反过来，如果抢拍处没有任何铺垫，即使人声本身没唱错，听感也像抢。

### 3.5 检验法

- **跟着点头或打拍子**，从第一小节打到最后一小节。
- 打到哪一段打不下去了，那一段就是烂的，回去改那一段。
- 如果只有作者自己打得出、旁人跟不上，这段已经废了。

### 3.6 切分律动要在第一小节就露头

- 三三二型切分（3-3-2，tresillo）要在第一小节就由某个声部带出来，之后持续沿用。
- 前四小节什么律动，后面大体就是什么律动；等中段才第一次冒出来会脱节。

## 4. 贝斯面

### 4.1 音区与摆位

- 主要工作区间 **E1–E2**；绝大多数情况下最高音不要越过 **E3**。
- **pan 永远居中。** 低频偏到一侧，整首歌的重心就歪了，这个错误很隐蔽但很致命。
- 贝斯的功能是垫稳低频、给人饱满的底座。想听起来高级就往下走，不是往上挤。

### 4.2 与底鼓的咬合

- 每个重音底鼓的位置上都要有贝斯音，低频才有落点。
- 那个贝斯音取和弦的根音（1 音）或 5 音；若换成 3 音、7 音，和声会听着不稳。
- 贝斯节奏和底鼓完全一致会有点死板，允许稍有区别，**但重音必须对上**。
- 一段之内，除了加花的地方，音程跳跃都别超过五度；实在要跳，改用转位。
- **低频要分工**：底鼓的能量主体落在 50–100 Hz，贝斯落在 80–200 Hz；两条都挤在 100–200 Hz 这一段，低频就糊了。

### 4.3 常见问题 4 条

| 症状 | 病因 | 处方 |
|---|---|---|
| 和钢琴糊成一团 | 音符写得太密，跟钢琴撞在同一拍 | 慢速歌里贝斯不需要跑得快；砍到只留骨架音 |
| 全程只有根音 | 没做律动动机，音符也没起伏 | 保留根音为主，隔一句做一次音型变化或加花 |
| 泛音发刺，低频位置上被底鼓压住 | 音区写高了 | 整体下移一个八度，回到 E1–E2 |
| 听着不搭、踩不到和弦 | 和其他轨不在一个调 | 导出前逐轨核对调性，别只凭耳朵蒙 |

### 4.4 Slap 技法（进阶选学）

- 本质是**用贝斯模仿一套架子鼓**：拇指砸低音弦＝底鼓，食指勾高音弦＝军鼓，左手敲弦＝hi-hat。
- 落地办法：先写一套比现在更复杂、更完整的鼓，再把那套鼓的节奏整体搬到贝斯上。
- 代价：Slap 音色亮而扁，会损失一部分低频职责，要在音色选择或混音上补回来。
- 铁律：**一首歌的低频主色只能有一种。** 常规律动从头到尾统一用普通贝斯，或者统一用 Slap；频繁横跳会让低频忽厚忽薄，非常不稳。

## 5. lay back

- 真人演奏本来就会比网格线稍晚一点出来，这一点「晚」通常更好听，就是 laid back。
- 它来自乐手的乐感，学术上也没有「该晚多少」的量化规则，只能靠反复扒带和实弹慢慢攒。
- 反面案例：某一轨整体比网格慢了约一个十六分音符，跟其他声部完全对不上。**这属于工程失误，不该当风格留着——延迟没补偿、量化也没做好。**
- 区分标准：真正的 lay back 是「同一条线上略微落后、幅度还会变化」；延迟是「整轨恒定偏移」。后者一律先修工程设置，别当成风格留着。
- 这种小细节足以毁掉一首歌，做 lay back 之前先把网格对齐。

## 6. 风格律动速查表

| 风格 | 常见速度 | 律动特征 |
|---|---|---|
| House | 110–130 | Four-on-the-Floor：底鼓每一拍都落一下 |
| Hip-hop | 75–110 | 速度慢，鼓带明显切分感 |
| Trap | 50–100 | 底鼓切分强烈，hi-hat 型不规则、常带滚奏 |
| Drum & Bass | 约 160–190 | 快速激烈，基本是 Hip-hop 律动加速后的样子 |
| Future Bass | 约 130–160 | 速度接近 Trap，律动更自由 |
| Dubstep / Brostep | 100–140 | 看点是 Build up 和 Drop 之间质感的落差 |
| 华语流行 | 偏慢 | 旋律句幅长，鼓相对规整 |
| J-Pop | 偏快 | 摇滚与电子元素混用较多 |
| Funk | — | 律动是唯一主角，和声基本围着主音属七和弦转 |
| 爵士 | — | Swing 三连感＋即兴，Ride 打循环型 |

- **相当多电子风格的标签其实由速度决定。** 速度往后挪一档，同一套做法就从 Trap 变成 Electro、从 R&B 变成 Drum & Bass。
- 动手前先把 BPM 对准参考曲，风格选择是速度的下游。

## 7. 律动动机：靠「填空」搭织体

一句话原则：**律动感是填空填出来的，不是叠出来的。**

### 7.1 每件乐器贴一个鼓件

| 乐器 | 贴哪个鼓件 | 它的节奏层 |
|---|---|---|
| Pad / 弦乐 | 长音底色 | 全音符、二分音符 |
| 钢琴 / 键盘 | 军鼓式点 | 二分柱式或稀疏分解 |
| 吉他 | hi-hat 式扫弦 | 四分或八分 |
| 贝斯 | 底鼓 | 律动动机，1–2 小节一循环 |
| 主唱 | — | 占正拍重音，其他声部避开它 |

### 7.2 三层错开（顺序：节奏 → 方向 → 音区）

按重要性从高到低排，前一层做不到就谈不上后一层。

1. **节奏错开（最要紧）**：贝斯把重音压在 1 拍和第 2 拍的后半，旋律就挪到第 2 拍正拍与第 4 拍后半上去，正好插进贝斯空出来的位置。
2. **方向错开**：一条往上走时另一条往下走（反向进行）；也可以一条原地不动、另一条自己走（斜向进行）。
3. **音区错开**：贝斯守在 E1–E2，旋律乐器落在中高频，天然就分得开。

同向同度（同时、同拍、同方向）是无效写作：两条线不是加厚，是互相抵消，各自的力量反而都弱了。

### 7.3 动机要先定，再守满一个段落

- 先挑一个 1–2 小节的律动动机（通常取自贝斯那一句），整段原样重复。
- 把这一轨单独 solo 出来，看自己能不能一直跟着点头；跟不上就换一个动机重写，**这一步没过就别继续往下做**。
- 每小节换一次型＝全曲都在加花＝听众找不到支点，只会越听越累。

### 7.4 全声部齐走四分 = 一顿一顿

- 所有乐器齐步走四分，织体退化成一条线。
- 正确顺序是：先让各声部分到不同节奏层，再考虑加花；别的乐器加花时，Hi-hat 就退回稳定的十六分。

### 7.5 加花要收敛

- 加花大约每 3–4 小节放一次，作用只是把情绪往前推，常规律动的框架全程不动。
- 参考曲的花往往比听感上以为的少：律动骨架不动，只在细节上换音色——比如某一记 hi-hat 改打 open，或在某小节添一记通鼓。
- 推进感优先靠**配器加减与留白**（撤掉某件乐器、换一件乐器扛律动），而不是靠塞加花和推音量。

## 8. 交付前自查清单

- [ ] 鼓从第一小节连续到最后一小节，没有半小节空白
- [ ] 军鼓钉在 2、4 拍；缓段用 Side Stick 而不是把它搬走
- [ ] Hi-hat 前后段落骨架一致；Crash 只在段首、每 4 小节
- [ ] 力度做了分层：整体档位 + 逐件数值都填了，没有全轨 127
- [ ] 至少有一个明确的音在强调重拍
- [ ] 人声抢拍进入前有一下底鼓垫着
- [ ] 每 4 小节上下放一次加花，常规律动框架没动
- [ ] 贝斯 pan 居中、最高不越 E3、重音贴底鼓、落 1/5 音
- [ ] 低频主色只有一种（普通贝斯 或 Slap）
- [ ] 各声部贴的是不同节奏层，没有全曲四分齐步走
- [ ] 跟打拍子能从第一小节一直打到最后一小节
- [ ] 若怀疑某轨有 lay back，先排除延迟与量化问题

## 9. 衔接 AKDAgent 工具

- 击打力度分档可以直接写进音符的 dynamics 属性，SV 钢琴窗里逐音符设定即可。
- 律动骨架定了之后再铺和声：`sv_write_chords` 可选 `broken` / `arpeggio` 模式充当律动层（block 是柱式，别让它和 hi-hat 抢同一层）。
- `sv_generate_melody` 生成旋律后，检查旋律重音是否落在鼓的重音上；如果旋律重音和底鼓重音全程错开，会导致整首「找不到拍」。
- `sv_write_chords` / `sv_align_audio` / `sv_apply_tempo` 都依赖小节线正确：**先把工程网格和伴奏对齐，再谈 lay back**，否则分不清是风格还是工程错。

# 规格表（Spec Sheet）

> 补充 `SKILL.md` §10。核心：**一句话的提示没法逐项检查，一张表可以**。
> 📌 来源：`jtydhr88/music-composition-skills`（skills 部分 MIT）的**思路**启发，**文字为自行撰写**、未逐字复制。

## 1. 为什么值得先写一页表

- 可以**逐字段对照产物**：交付来的东西哪一项没做到，一眼就能指出来；
- 可以**一次只改一个字段**做 A/B —— 不然改完也说不清是哪一处起的作用；
- 可以**留档**：半年后还能说清"第二段副歌为什么这么编"。

## 2. 最小规格表（一页写满就够，字段名自定）

| 字段 | 写什么 | 判据 |
|---|---|---|
| **调性 / 速度** | key（含大小调）· BPM | 与 demo / 参考一致；变速段落单独标 |
| **段落图** | 按**小节**列 intro / verse / pre / chorus / bridge / outro | **每段起止小节数要写出来**（"大概三分钟"不算） |
| **和声** | 每小节和弦，**字母 + 级数双写**（如 `C(I) → G(V) → Am(vi)`） | 级数能对上调式；转调处单独标 |
| **进出场** | 每段谁进来、谁退出（乐器 / 声部） | **进副歌前至少一件乐器退出或留白**（SKILL §11.1 → `段落结构.md` 的「进副歌先减再加」） |
| **能量曲线** | 逐段 1–5 分（与 SKILL §6 情绪打分同尺） | 落差要**落在小节线**上，不要"渐变" |
| **人声处理** | 音域 / 力度走向 / 要不要和声 / 哪句留白 | 与实测音域一致（别写出唱不到的音） |
| **混音意图** | **目标**（谁在前景、低频归谁），不写参数 | 不写 EQ / 压缩数值（那是混音环节的事，见 `混音与母带.md`）|

## 3. 四种用法

| # | 用法 | 做什么 |
| :-- | :-- | :-- |
| ① | **交付** | 把表交给编曲 / 生成模型 |
| ② | **对照** | 产物逐字段比，缺哪一项直接指出 |
| ③ | **A/B** | **只改一个字段**再跑一次，听差别 |
| ④ | **验收基线** | 留档，供日后复盘（"这次比上次好在哪"） |

## 4. 写作纪律（很值，已推广到本 skill 全篇）

**每条规则要么给出"失败条件"，要么给出"自查动作"** —— 测不了的规则只是观点，别写进规格表。

## A. 混音

### A1. 混音只在解决三件事

不管挂多少插件，混音的目标可以收成三条：

| # | 要解决的事 | 手段 |
| :-- | :-- | :-- |
| 1 | **音量与动态平衡**：横向看，同一时刻没有谁过分抢戏、也没谁被埋掉；纵向看，整首歌各段落的响度不该莫名其妙地忽大忽小 | 推子 + EQ（平衡），压缩（动态） |
| 2 | **频段均衡**：每段频率都有位置，没有哪一段堆得过厚、把别的段挤扁 | EQ |
| 3 | **声像与声场**：Pan 管左右横向位置，混响管前后纵深与空间感 | Pan + 混响 |

三条里任何一条没做到，都补不回来——尤其第 2 条：频段已经打架时再上压缩，只会越压越糊。

### A2. 六步流程（按顺序走，别跳步）

1. **Gain Staging**：先把各轨推子归零，用 clip gain / 输入增益把每轨峰值落到 **−10 ~ −18 dB**（最常用 **−12 dB**）。目的是整个流程从总线余量充足的状态起步，不会一路红着往下走。
2. **声像**：中频乐器推到两侧，贝斯、鼓组与人声都留在正中。
3. **音量**：挑一轨当锚点（人声 / 钢琴 / 打击乐，看曲风定），它全程不动，其他轨围着它定比例；同时挂一首参考曲随时对照。
4. **动态**：先用 EQ 削掉刺耳的频点，再上压缩；处理次序从最核心的轨排到最不重要的轨。起步参数 Ratio 2:1，靠 threshold 把压缩量（Gain Reduction）压在 −3 dB 上下；想尽量听不出痕迹，整段别超过 5 dB。
5. **频段**：EQ 把三段量对齐。做法是"哪段多就减哪段"，而不是"哪里少就猛加"。
6. **声场**：最后铺混响。先给打击乐组铺（它定全曲空间），越重要的元素越晚进场、量越克制。

### A3. 压缩参数怎么取

- **Attack**：长 → 音头冲击力留住（底鼓、军鼓要靠它）；短 → 声音变柔和。
  ⚠️ **如果所有轨道的 attack 都塞在 5 ms 以内，音头会被压没**，整首歌会失去力度和颗粒。
- **Release**：短 → 颗粒感强、紧凑；长 → 柔和、绵。
- **平行压缩**（军鼓发软时的标准解法）：并联一条重压的副本——ratio 拉大、threshold 压低、attack 短、release 长，再用干湿比例混回主信号，既有劲又不瘪。

### A4. 混响

- **先把这首歌的空间定下来**（空灵、亲切、疏远、温情 四选一），想清楚再动手，别边听边加。
- **从打击乐开始做**：一组鼓的空间感是整首歌的地基，后面所有元素都得往这个空间里放。
- **在达成目标空间感的前提下，量越小越好**。混响是叠在频段之外的声音，加多了各乐器互相干扰、冲击力归零。
- **低频必须保持干净**：**200 Hz 以下不管混响开多大都听不出混响感**，只会把低频弄浑浊。所以给混响轨做低切。
  - 底鼓缺冲击时，可以叠一个 Room 类混响并稍微加大 pre-delay 来增厚；
  - 贝斯与底鼓上的混响一律选小 size，reverb time 也取短。
- Spring、Plate 属于染色型：Plate 适合给人声做空间感、给打击乐做体积感。
- **从鼓组到人声切片，全都要待在同一处空间里**，不能人声在小厅、鼓却在大教堂。

### A5. 人声处理链

**人声听不清，靠压缩把能量挤出来；推子只负责平衡，不负责"让人声变大"。**

```
EQ 削掉难受的频点
  → 光电压缩，动作慢（LA-2A 型：把整首的音量压平均，做整体控制）
  → FET 快速压缩（1176 型：把音头和咬字顶出来，做细节控制）
  → EQ 修质感
  → 混响
```

**为什么是 LA-2A 在前、1176 在后**：

- 慢的光电压缩动作迟缓、透明，擅长把长句的音量差抹平，适合当"总控"；
- 快的 FET 压缩反应迅速、染色明显，专门抓辅音和音头，负责"细节"；
- 顺序反过来（先快后慢）时，慢压缩会重新改写快压缩已经做好的动态，细节反而被吃掉。总控在前、细节在后，两级各干各的活。

加料做法：人声至少挂两级压缩。同时把伴奏推向两侧、低切做干净，400–1000 Hz 这一段腾给人声；伴奏压得比人声更狠（GR 约 −5 ~ −10 dB，attack 取 20 ms 左右），把动态余量和空气感都让给人声。

### A6. Limiter 与导出规格

- **Limiter 阈值约 −1 dB**，而且**必须看 True Peak**。只看采样峰值会漏掉限幅后重采样回放时冲出的过载，流媒体上传时会直接被削。
- 导出规格：
  - **wav 16 bit / 44.1 kHz** → CD、流媒体
  - **wav 16 bit / 48 kHz** → 配视频用

### A7. 响度排序

参考曲的响度排序要照学——它比任何频谱分析都更能说明这首歌"该长什么样"。常见排序：

**鼓 ＞ 中频乐器 ＞ 人声**（越靠左越响，人声反而排在最后）

- **中文流行最常见的毛病是把打击乐混得太小**，听起来软、平、没有推力；欧美流行反过来——人声偏小、鼓非常大。
- **摇滚里鼓要盖过除人声以外的所有乐器**：这一条在摇滚几乎不能让步。

## B. EQ 捏音色（调声侧的"三段式"）

在干声真正移交给混音师之前，修改它都属于调声的工作范围。

### B1. 三步法

1. **分析现有音色**：把干声拖进能看频谱的音频工作站，逐段读它的能量分布。
2. **分析目标音色**：找目标歌手的样本，同样丢进去看频谱。
3. **用 EQ 把两者接起来**：把差异逐段填平／削掉，让现有音色往目标靠。

工具要求：

- **频谱必须能看见**：看不到就不清楚自己动了什么、改动为何让声音变好或变坏；
- 调声线要**手动 EQ**。自动 EQ 是后期混音阶段的工具，拿来调声线会失去可控性。

### B2. ⚠️ 为什么必须先分离气声，再做大幅 EQ

导出时把气音输出改成**分离气声（写成独立的附加文件）**，你会拿到两个文件：

- 不带后缀的那个文件 = **纯谐波**（只有基频加泛音列）
- 带 `_asp` 后缀 = **纯气声 / 噪波**

**原因是噪波的成分问题**：噪波里含着一大块**轻辅音**——**j、q、x、zh、ch、sh** 这一类擦音、塞擦音，而每个这类辅音都有自己相对集中的频段。如果拿着合成后的整条人声去大幅 EQ，就等于同时在动这些辅音的频段，**咬字的辨识度会被削掉**（给真人混音时 EQ 幅度受限，也是同一个道理）。

拆开之后就安全了：**只对纯谐波那条做夸张 EQ，咬字部分一点不受影响**；最后在多轨工程里把两条对齐、合并。

> 操作细节已有：见 `skills/sv-scripting/references/07-melody-accent-pitch-params.md`（分离导出一节，918–920 行）。这里补齐的是**为什么要分离**。
>
> 交给混音师时，要提前说清气声与谐波各自打算怎么处理，否则对方默认合到一块混，你的分离就白做了。

### B3. 频段对照表（女声库参考，男声整体下移）

| 频段 | 主要对应 | 充足时 | 不足时 | 过量时 |
| :-- | :-- | :-- | :-- | :-- |
| 500–600 Hz 以下 | 胸腔支撑与基频 | 厚、有分量、稳 | 薄，像纸片 | 发闷，像蒙了层布 |
| 600 Hz–1.2 kHz | 一二号泛音、口腔集中度 | 饱满有肉 | 发虚、没底气 | 瘪，带塑料味 |
| 1.2 k–2 kHz | 鼻腔共鸣偏低的一段 | 黏糯，有集中的劲儿 | 散、不聚焦 | 过于粘连、糊成一团 |
| 2 k–4 kHz | 鼻腔共鸣的集中处 | 圆润 | 不够圆润 | 憋、鼻音重，像感冒 |
| 4 k – 5 kHz | 鼻腔与头腔交叠区 | 清亮甚至偏冷 | — | — |
| 5 k – 7 kHz | **人声缺频**（人类很难在这一带产生集中泛音） | 有凹陷 = 更像真人 | 完全没有 = 音色非常独特 | — |
| 7 k–13 kHz | 声带边缘的摩擦加头腔润色，即"金属芯 / 颗粒感" | 亮、穿透力强，能从伴奏里跳出来 | 常被伴奏压过去 | 尖利、扎耳朵 |
| 13 kHz 以上 | 人耳基本发不出明显泛音 | — | — | — |

### B4. 歌手共振峰（决定人声能不能穿透伴奏）

- **男声一般在 2500–3000 Hz**
- **女声一般在 3000–4000 Hz**
- **共振峰位置越高，音色越细越尖；越低，越粗越厚。**
- 过了 4000 Hz，男声基本就没有明显共鸣了。

腔体对应的频段大致是：胸腔管基频段，口腔管中频泛音（咬字的口型就在这里），鼻腔落在 2–3 kHz 一带，头腔覆盖 3–10 kHz；共振峰位置和强弱由这两处腔体一起决定。

### B5. 操作要点

1. **顺序：从高频段起步，一路往低频段走。**
2. **多轮迭代**：先按大方向粗调一轮，再看哪里不足补哪里，一遍一遍试；可以拆成几次小幅渲染，不要一次调到死。
3. **逐字扫描**：盯着频谱，找出与前后接不上的个别字（典型是开口小、超高段能量不够的那些字），圈出来单独拉回去。单字 EQ 也能做渐变，前提是不破坏前后音色的连贯。
4. **爆频检查**：波形冲出来了，说明那个字的共振峰正好落在你提升的频段上——这个字要单独处理，提升量收小。
5. **幅度一定要克制**：捏音色只是润色辅助，不可能颠覆声音本质。两种典型翻车：
   - 觉得声音厚重，就把 500 Hz 一刀切掉，可 200 Hz 的基频还留着，出来的根本不是人声；
   - 想让声音更亮，结果在 3–4 kHz 抬起来的增益把本来不存在的底噪一并抬了出来。
6. **判据：调完的声音必须还在"能听"的范围内**——自己都觉得难听，那调它干什么。
7. **频段认知必须准确**：很多人嘴上说要调"头腔""鼻腔"，手上动的频率其实是错的，效果自然和预想对不上。

## C. 与混音的衔接 & 导出

### C1. 衔接

- **成品效果里，混音至少占一半功劳**。混得清楚，你辛苦画的细节才有人听得见；混不好会倒扣分。不想承担这份风险，就直接交干声。
- **动态要画得比理想状态更大**——后面混音阶段的压缩会吃掉大部分动态余量。编排越密集、情绪越往上冲的段落，越要提前把起伏拉开，否则成品会被压得扁平，一点强弱变化都不剩。例外：伴奏本来就很轻柔的时候。
- **声线取向跟着编曲走**：伴奏铺得越饱满，人声高频越要给足，否则会被压死；伴奏稀疏时，声线也应当收着点。
- **挂了压缩器之后，前期 EQ 做出的音色会打折扣**——这一条只能取舍，不可能两全。
- **低切默认交给混音师**；只有对胸腔共鸣有特别要求时，调声阶段才自己处理。
- **呼吸音要在交付前自己加好**——对方无从知道你想在哪些位置留气口。

### C2. 导出

- 正规做法是**单独导出干声再拿去混音**；带伴奏的那个版本只用来听个响，别当成品。
- 渲染设置里选"偏好速度"就等于放弃品质，成品音质会打折扣。后台线程数调高可以加快渲染，代价是对机器配置要求更高。
- **导出的音频跟伴奏对不上拍 → 先确认导入伴奏的格式是不是 mp3**（mp3 带编码延迟，会让整条时间轴偏移）。
- 需要做 EQ 捏音色时，用**分离气声**的方式导出（见 B2）。

## D. 母带

- **以参考曲 A/B 对齐为准，不要照套某个平台的数字**。各平台对流媒体响度做归一化的算法都不一样，而且还经常调整，盯着平台参数做等于追一个移动靶。做母带时反复切换成品与参考曲，把**听感响度**对齐就够了。
- 常见落点是**积分响度 −9 ~ −12**。要盯的是积分响度，跟 Output Ceiling 拉到 −9 完全是两回事。
- Limiter 阈值约 **−1 dB**，而且要**看 True Peak**。
- **限幅做完了，响度却依然明显追不上参考曲，那问题出在混音环节**，别指望在母带上硬顶。两条回退路径：
  1. **降低低频的音量**——人耳对中高频更敏感，低频占掉的能量对响度贡献小，却让 limiter 提前动作；
  2. **退回混音阶段，用激励器、失真给各件乐器补泛音**，泛音够丰富了，响度自然上得去。

## E. 织体的空间预算与临界频带

> 承接原 `SKILL.md` §11.2。织体（"同一串和弦怎么铺开"）另见 `sv-texture` 技能；这里只管**怎么分空间、为什么会糊**。

- 分三层想：**前景**（主唱 / 主奏）· **中景**（和声垫 / 节奏乐器）· **背景**（氛围 / 细节打击）—— 给每层一个"位置"，而不是给每件乐器单独想。
- **掩蔽的真正单位不是"频率重叠"，而是临界频带（critical band）**：两条线只要落进**同一条临界频带**就会互相糊，即使频率并不重合。
- 推论：**低音区相差五度的两件乐器最容易打架**（低音区临界带宽窄）⇒ 低音区**只留一件**，或严格错开八度 / 时值。
- 自查：把"互相糊"的两件分别独奏再一起听 —— 糊的那对，大概率在同一临界频带里。

## F. 机器痕迹自检（"听着像 AI"）

> 承接原 `SKILL.md` §11.3。"听着像 AI"通常不是玄学，而是**可以逐条数出来的**：

1. 每段的乐器数量都一样（没有真正的进出场）；
2. 能量曲线单调上升，从不回落；
3. 所有段落都是 8 的整数倍，且**没有任何一次**提前或延后；
4. 鼓组从头到尾一个 pattern，fill 只出现在段落交界；
5. 每句旋律都在同一音区、同一时值密度；
6. 和弦走向永远是 I–V–vi–IV 的换皮；
7. 副歌只是"主歌 + 更大声"（音色 / 织体 / 律动都没换）；
8. 结尾不是渐弱就是硬切，没有设计过的收束句。

> **两个问题要分开问**：① **它有没有照我的规格表做**（对照 `规格表.md` 就能答）② **它有没有机器指纹**（上面这份清单）。**一首歌可以过了第一问、栽在第二问。**

## G. 速查

| 项目 | 关键数字 / 结论 |
|---|---|
| Gain Staging | 峰值 −10 ~ −18 dB，常用 −12 dB |
| 压缩 attack | 全部 <5 ms ⇒ 音头被压没 |
| 军鼓发软 | 平行压缩：大 ratio、低 threshold、短 attack、长 release |
| 混响低切 | 200 Hz 以下听不出混响，只会浑 |
| 人声链 | EQ → LA-2A（慢，整体）→ 1176（快，细节）→ EQ → 混响 |
| Limiter | 阈值 ≈ −1 dB，看 True Peak |
| 导出 | 16 bit / 44.1 kHz（CD、流媒体），16 bit / 48 kHz（视频） |
| 响度排序 | 鼓 ＞ 中频乐器 ＞ 人声；中文流行通病 = 打击乐太小 |
| 摇滚 | 鼓盖过除人声外的一切 |
| 共振峰 | 男 2500–3000 Hz，女 3000–4000 Hz |
| 大幅 EQ | 先分离气声（噪波里有 j / q / x / zh / ch / sh） |
| 母带 | 与参考曲 A/B 对齐；压完仍偏低 = 混音问题 |
| 空间预算 | 打架单位是**临界频带**，不是频率重叠；低音区相差五度最易糊 ⇒ 低音区只留一件 |
| 机器痕迹 | 8 条逐条数（见 F）；"像 AI"与"没照规格表"是两个问题 |

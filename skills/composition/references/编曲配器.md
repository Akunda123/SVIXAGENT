# 编曲配器（Orchestration & Arrangement）

> 补充 SKILL §5。核心：**挑乐器这一步就已经在做混音了**。

## 1. 频段/音区分配（每乐器占一格）

| 乐器/元素 | 音区/频段 | 注意 |
|---|---|---|
| 贝斯 | E1~E2（大字组低音）| 想高级就低；落和弦 1/5 音 |
| 底鼓/军鼓 | 低频/中频 | 放正中间 |
| 人声 | 中频 | 同音区留给人声 |
| 中频乐器 | 两边 | 弦乐/吉他/键盘摆中间两侧 |
| 高频乐器 | 乐器自己频段 | 每乐器全程稳在一个频段 |
| 钢琴 | 左手 C3~C4 | 同时发声 ≤6 音；左手在贝斯之上；左右手间距 ≤八度 |
| 吉他（节奏）| E3~E4 | 相邻音程小三度~纯五度；音符数量要平衡 |
| 小提琴 | C4 起，可上行 | 越过 C5 就抢耳朵；有人声时收着用 |

**低频区（C2 及以下）**：同一时刻响的两个音，间距不得小于纯五度（low interval limit 这条规则）。

**弦乐组内部**：大提琴守在 C2–C3，别压进贝斯区；倍大提琴、大提琴、中提琴三者相邻之间，同时发声的音程不少于五度。整组压得太低，中频会跟着一起变浑。

## 2. 节奏分层（织体立体的关键）

- **各乐器分属不同节奏层**：钢琴走二分柱式、吉他走四分分解、弦乐走八分——织体才立得住。
- 所有乐器都踩着四分音符，听感会一顿一顿。
- 声部之间走反向或斜向，**最要紧的一步还是把节奏错开**；走向和节奏双双重合（同向同度）等于白写，两条线互相削弱。

## 3. 乐器性格

- **摇滚**：失真吉他必须两把，左右声道各摆一把，两边弹的内容完全相同。
- **贝斯**：律动跟底鼓不要贴死，活一些；加花时躲开人声。
- **Pad/氛围**：低频区贴近贝斯音区之上，别和贝斯抢。
- **钢琴**：左手一带 C3~C4，必须压在贝斯（E1~E2）之上；同时按下的音控制在 6 个以内（约等于两手各一个三和弦）；右手最低音与左手最高音之间尽量不超过一个八度；写到 C2 附近时，两个同时响的音中间至少留一个五度。
- **吉他（节奏）**：音区锁在 E3~E4，中频才饱满；相邻两个音的音程限制在小三度~纯五度这个范围（弦距四度、人手跨度有限）；和弦的弦数要平衡，前一个用了 6 根，后一个最好同样是 6 根、至少不低于 4 根。
- **弦乐/小提琴**：小提琴从 C4 起；越过 C5 之后它就成了全曲最抢耳的一件，**有人声的时候要收着用**，主角位留给人声。中频已经有两样乐器通常就够，中提琴可以省。所谓「单调」，真正常见的原因是**乐器缺细节**（只做了结构性作用、没提供流畅与色彩），不是乐器数量少。

## 4. 常见配器病 → 对策

| 病 | 对策 |
|---|---|
| 编曲太满 | 撤掉一层（打击乐/和声）留白；留白最万能 |
| 太空 | 补一件乐器；或把和声垫厚（pad）|
| 打架（音区乱）| 每乐器固定频段；中频两边、正中间留低频+人声 |
| 频段糊 | 高低频让位；EQ 补不回缺乐器的空洞 |
| 声部交叉 | 低声部与旋律声部必须完全分开，各走各的音区；互相窜就会听感脱节 |
| 屏蔽效应 | 贝斯重音别与人声重音贴在同一点，否则贝斯被人声盖住 |
| 缺中频 | 中频至少两件乐器；只靠钢琴顶不够 |

### 人声与弦乐抢位置时

1. **反向或斜向**：人声上行时弦乐下行，或人声唱、弦乐按住长音——最要紧的仍然是把节奏错开。
2. **同度齐奏**：让弦乐跟人声走完全一样的旋律做同度齐奏，只在人声不唱的空余小节用。
3. **填空**：人声一句唱完的空当里弦乐补一句，接住气口。

## 5. 衔接 sv_generate_harmony / sv_write_chords

- `sv_generate_harmony`：给主旋律垫和声（三度/六度），适合流行/人声。
- `sv_write_chords`：把和弦写成柱式（block）/分解（broken）/琶音（arpeggio），按节奏层需求选 pattern。
- 配器时，和弦层可选「分解/琶音」做律动层，人声层用和声垫——分节奏、分频段，织体就立体了。

# 作曲与编曲（Composition & Arrangement）

面向 AKDAgent 的作曲编曲指南。**核心：每条判断都要能落地执行**——说清楚是**哪件乐器、落在哪一拍、用哪个音程、到哪级和弦、占哪个频段**。「要有层次感」这类话等于没说。

## 0. 开工前先确定（协作模式）

| 维度 | 选项 |
|---|---|
| **身份** | 词作者/作曲/编曲(术语直给)/独立音乐人(跨环节权衡)/学生(要解释)/制作人(给结论取舍)/甲方(说人话+验收标准) |
| **储备** | 教学(讲原理拆例子)/引导(给判断标准)/辅助(给方案+取舍)/自主完成(直接做技术活) |

**底线**：AI 只负责扛技术活，创作主体始终是人。作品表达什么、什么情绪，**回来问用户**；「自主完成」指自己把技术性劳动做完（按既定方向铺草稿、量产、落地）。

## 1. 先问清楚再动手

1. **参考曲**（一首，不是三首）——决定速度/拍号/配器数量/律动/混音响度排序。
2. **风格与速度**——很多电子风格由速度定义（速度一改 Trap 变 Electro、R&B 变 Drum & Bass）。
3. **眼下写到哪一步**——手上只有旋律？和弦有了但没配器？还是整首铺完了在挑毛病？
4. **调性与拍号**——这俩错了后面全白改。

## 2. 写作流程（切入点）

| 情况 | 从哪开始 |
|---|---|
| 没想法 | 先定**和声进行** |
| 风格明确（摇滚/电子/Funk）| 先写**鼓**，钉死律动 |
| 流行/有人声 | 先唱**旋律**，再配和弦 |
| 配乐/氛围 | 先做**音色和配器** |

**共同点**：先找一个立足点（律动动机/和声骨架/主题旋律），其他围着它铺。没有立足点就狂加旋律，是「乱」的根源。

推荐顺序：`先挑参考曲 → 定速度/拍号/调 → 立律动动机(鼓+贝斯) → 把旋律唱出来 → 再铺和声进行 → 做配器分层 → 排好段落结构 → 过一遍自查清单 → 混音 → 母带`

## 3. 乐理速查（硬性判断标准）

### 3.1 旋律
- **必须自己唱一遍**。没唱过一听就知道：全落在五声音阶、一句 11-12 字唱到没气、一句跨八度。
- 中文一句 **6-7 字**、1-2 秒留气口。
- 旋律用 `do-re-so`/`do-fa-so`/`do-si-so` 这类走向，色彩感立刻就有了；要是通篇 `do-mi-so`，全是和弦内音，听着就像儿歌。
- 落音看情绪挑：想要安定就收在 do/mi/sol，想要不安就收在 la/ti/fa。
- 中文写词让字调跟着旋律走向走（配合 sv-lyricist 的「倒字」避让）。

> 展开与判据见 `references/主旋律生成.md`（三证据 / 方向性 / 挂留和弦思维 / 工具链路 / **`sv_check_melody` 判据校验**）。

### 3.2 和声（关键铁律）
- **强拍上落的音必须属于和弦内音**。和弦是这一小节里所有乐器音高的总和。
- **避免音铁律**：旋律音要么压在和弦内音之下（低小二度无妨），要么高出去大二度以上；**高小二度属于硬伤**。
- 11 音纯四度色彩最不明确，**重音位置留给其他和弦音**；13 音放重音同样是硬伤。
- **属和弦的下一步只有三个落脚点**：I、IV、VI。
- 段落开头用主功能起；属和弦与 III 级放段中。
- 副歌进场前的收尾和弦通常落在属和弦；结尾走 V→I 正格终止。
- 乐句内部（约 4 小节）要让和弦持续向前走（`6-1-6-1` 来回横跳就是原地踏步）。
- 和声节奏定下来就守住（一小节一个/两个，段内统一）。
- 根音与旋律撞同度、或形成隐伏八度，8 小节里顶多出现 1 次。

### 3.3 律动/鼓
- 底鼓落在 1、3 拍，军鼓落在 2、4 拍。先把「咚哒咚哒」老老实实铺满，等规律立住了再加花。**军鼓钉死在 2、4 拍**，要变就变音色和力度。
- Hi-hat 相当于节拍器，各段之间的律动骨架基本不动。
- 加花约 3-4 小节一次，推情绪。
- 同时发声鼓件最多 4 个。切分律动（3-3-2）要在第一小节就露头。
- 检验法：**自己跟着打拍子，哪一段手跟不上，问题就出在那一段。**

### 3.4 贝斯
- 音区稳定在 **E1 到 E2**。贝斯想高级就要低。
- 落在和弦 1 音或 5 音（落 3/7 音不稳）。
- 每个重音底鼓上都有贝斯音；贝斯加花与人声错开。

## 4. 和声进行（常用套路）

### 自然大调
| 进行 | 名称/流行度 |
|---|---|
| `I-V-VI-III-IV-I-II-V-I` | 卡农进行 |
| `IV-V-III-VI`（4536）| 日式流行标配 |
| `IV-V-III-VI-II-V-I`（4536251）| **华语流行最常见** |
| `I-VI-IV-V`（1645）| 欧美流行常见 |

### 自然小调（大调级数表示）
- `VI-II-V-I`（爵士/日式流行）
- `VI-IV-V-IV`（日式流行，变体 IV-V-VI）
- `VI-III-IV-I-II-VII-I`（小调华语走向）

**用法**：
- **和弦按四个一组来，能反复用就尽量反复用**，不合适再换。
- 只锁关键点：把起点/终点色彩的和弦定死，中间衔接没那么所谓。
- 套路和声胜在"就是好听"，从几个成熟的模型里挑一个跟当前推进方向对得上的套进去。
- **借鉴只借元素**——可拿走某段和声进行，但连转位手法/织体一起照抄就相似度过高了。

### 各级功能（山的比喻）
- **I** = 山脚，很稳，确立调性，但要省着用（多了没动态）。
- **II** = 柔和特色，II-V-I 爵士。
- **III** = 忧郁有感情，放段中（起段头会像小调）。
- **IV** = 明亮带忧伤，最常见 IV-V-VI。
- **V** = 属，站在山顶准备跳，V-I 最爽。
- **VI** = 万金油，自然大调后接什么都不奇怪。
- **VII** = 倾向性极强，流行少用，当弱拍经过音。

## 5. 配器与音区（选乐器就定了混音一半）

- 中频乐器摆两边，贝斯/底鼓/军鼓/人声放正中间。
- 低频区（C2 及以下）里同时响的两个音，间距至少留出一个纯五度。
- 每乐器占一个频段，全程稳在里面。
- **各乐器分属不同的节奏层**：钢琴走二分柱式、吉他走四分分解、弦乐走八分——织体才有立体感；全部铺四分音符，就成了一顿一顿。
- 声部反向/斜向，最重要**把节奏错开**；同向同度是无效写作。
- 人声一进来，同一音区就腾给人声；真要垫，只做同度齐奏。
- 摇滚里失真吉他必须成对出现：两把各占左右一边，弹的内容完全相同。
- **少了某件乐器留下的频段空洞，靠 EQ 补不回来**——混音其实从挑乐器那一刻就开始了。

## 6. 段落结构与推进

- 乐句 4 小节，乐段 4/8/16 小节。
- **流行快感来自重复性和熟悉感**。第二段大量复制粘贴正常，精力花在「决定哪几处变」上。
- Pre-chorus 值得花更多心思：撤打击乐、换一件乐器扛律动。
- 不知道怎么衔接、前后变化大时，**留白**最万能。
- 副歌高光、主歌舒展；进副歌前一般属和弦。

## 7. 参考曲怎么借鉴

**能学**：调性 / 和声色彩 / 律动 / 配器种类数量 / 乐器数量 / 拍号 / 鼓的写法 / 声像摆位 / 响度排序 / 频段分配。
**不能学**：旋律；整段和声进行连转位一起照抄。
**正确做法**：元素可以借，整首得自己搭。某段和声进行能拿走，但旋律/律动/配器必须换成自己的。参考曲**只选一首**、拆到不漏；两首风格体系不同的参考曲会让学法乱掉。

**照搬的判据**：把两首同速对齐播放，如果大段能重合，那就是照搬。「我改了旋律 / 换了调」不构成原创——情绪色彩由调式决定，调高改不动它。

**转位要自证**：想用转位，先回答两个问题——贝斯线里有没有超过五度的跳进？旋律与低音有没有撞同度、或形成隐伏八度（8 小节内最多 1 次）？答案不同，转位结果自然和参考曲不一样。

**写法与制作分开学**：写法可以学小众歌；混音和制作水准照着各风格主流出版物学。

## 8. 交付前自查清单

1. **全选 MIDI 一起看，查大二度/小二度撞音**（导出前必做，5 分钟）。
2. 所有乐器是否同一调/同一和弦。
3. 跟打拍子，哪段稳不住。
4. 从头唱旋律，气口够不够、段落有没有结构关系。
5. 军鼓是不是稳稳在 2、4 拍；hi-hat 前后段落保持一致吗。
6. 贝斯音区是不是偏高；有没有跟底鼓在 100–200 Hz 上打架。
7. 声像：中频两边、低频与人声中间；有没有导成单声道。
8. 把导出的音频完整听一遍（真有人把节拍器也一起导了出来）。
9. 母带：积分响度 -9~-12 LUFS（不是把 ceiling 拧到 -9）。

## 10. 规格表（→ `references/规格表.md`）

**一句话的提示没法逐项检查；一张表可以** —— 把 **调性/速度 · 段落图 · 和声（字母 + 级数双写）· 进出场 · 能量曲线 · 人声处理 · 混音意图** 写成一页，就能逐字段对照产物、**一次只改一个字段**做 A/B、留档（半年后还能说清"第二段副歌为什么这么编"）。

- 字段与判据表 · 四种用法（交付 / 对照 / A/B / 验收基线）· 写作纪律 → **`references/规格表.md`**
- 提醒：**混音意图只写目标**（谁在前景、低频归谁），不写 EQ / 压缩数值 —— 那是混音环节的事；**进出场至少要在进副歌前减掉一件乐器或留白**（§11.1）。

## 11. 三件容易被忽略、但很值钱的判断

### 11.1 进副歌先"减"再"加"

推进感**不等于**一路加东西：**有效的抬升往往来自减法** —— 进副歌前抽掉一层（鼓 / 和声垫 / 低音），或留一小节空。判据是**哪一小节谁退出、退出落点是否正好在小节线**上。
反例，以及"第二段主歌比第一段更空"这个反直觉但合法的选择 → **`references/段落结构.md`**（进副歌先减再加一节）。

### 11.2 织体是"空间预算"：真正打架的单位是临界频带

**掩蔽的真正单位不是"频率重叠"，而是临界频带（critical band）** —— 两条线只要落进**同一条临界频带**就会互相糊，即使频率并不重合 ⇒ **低音区相差五度的两件乐器最容易打架**，低音区只留一件。
三层（前景 / 中景 / 背景）怎么分、怎么自查 → **`references/混音与母带.md`**（空间预算与临界频带一节）。

### 11.3 把自己做的歌当"机器痕迹"检查一遍

"听着像 AI"通常不是玄学，而是**可以逐条数出来的**（8 条：段落乐器数一样 · 能量只升不落 · 段落长度永远是 8 的整数倍 · 鼓一个 pattern · 旋律同音区同时值密度 · 和弦永远 I–V–vi–IV 换皮 · 副歌只是"更大声" · 结尾不是渐弱就是硬切）。
**两个问题要分开问**：① 它有没有照我的规格表做（对照 §10 / `references/规格表.md`）② 它有没有机器指纹 —— **一首歌可以过了第一问、栽在第二问**。完整清单 → **`references/混音与母带.md`**（机器痕迹自检一节）。

## 12. 借风格与"像某某"的处理（护栏 → `references/借风格护栏.md`）

用户说"像 X"，**能借的只有手艺**：速度区间 · 律动类型 · 和声密度 · 曲式 · 音域与咬字方式 · 配器密度 · 编曲层次 · 能量曲线 · 制作年代感。
**不碰**：旋律 · 歌词 · 标志性 riff · 采样 · 制作人签名音 · 极具体的嗓音身份 · 某张唱片里可辨识的编曲序列。

- 变量翻译与各自落点 · 传统 / 地域音乐的"点名，不要笼统标签" · 时效性纪律 · **已剔除、不要补回**的两类内容 → **`references/借风格护栏.md`**
- 案例：**`examples/借鉴变成照搬.md`**（先分清哪些能借 + 五步具体动作）

## 13. 用这份 skill 的加载纪律（省上下文）

1. 先读本文件的**症状索引**，再只打开**最相关的 1~3 篇** reference / example；
2. 要"某风格的律动 / 配器"→ 优先 `references/律动与鼓组.md`、`references/编曲配器.md`；要"段落推进"→ `references/段落结构.md`；
3. **时效性内容（潮流 / 榜单 / 平台）不在本 skill 里**，要现查（见 `references/借风格护栏.md` 的时效性一节）；
4. 本 skill **不产出音频、不做混音** —— 混音 / 母带只到"意图"层（`references/混音与母带.md`）。

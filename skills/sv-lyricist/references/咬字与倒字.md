# 咬字与倒字（字数 / 断句 / 声调）

> 填词的**技术地基**。故事和情绪写得再好，字塞不进旋律、唱出来是别的字，整首就废了。
> 本篇讲三件事：**扒词格（字数）→ 断句 → 倒字**，以及改倒字的纪律。

---

## 一、扒词格（字数）

**词格** = 一句旋律里排了几个音、因此也只放得下几个字的骨架。上手填词，第一件事就是把它扒出来。

### 怎么扒

1. 完整听一遍。
2. 顺着旋律一句句哼，哼一句数一句唱了几个音（数一个画一个 X）。
3. **有工程/MIDI 就直接数音符**（SV 里 `sv_get_selected_notes` / 读 NoteGroup 数 `getNumNotes()`）。
4. 随手先塞几个字进去试唱，看装不装得下。

### 硬规则

- **一个音符对一个字。** 旋律给了 4 个音，就落 4 个字；除非对方明说了这里要加字。
- **一个音符不一定是一个字——可能是转音。** 对着 MIDI 填完被说"这里我是想转音的"是常事；
  （转音处的 `-` 歌词处理见 `sv-scripting` 的 melody workflow）。
- **容差 ±1 字**。少一两个字问题不大；**多 3 字以上或少 3 字以上完全挂不住**，旋律和唱词各玩各的。
- **字要收在本句里**——一句话没说完、尾巴甩进了下一句开头，那属于断句没断对。
- 让一个字横跨两个格子（转音），比往一个格子里硬挤两个字安全；不过最稳的仍是一格一个字。

---

### 填外语原曲时的字数出入

**外语和汉语音律不同，字数天然会有出入**（填外文原曲时按"几个音符几个字"硬套会别扭）：

- 英文 **"hold my hand"** 可能摊到三四个音，中文只够写两个字，多出来的音交给**拖长音或转音**（比如写成"牵我"）；
- **中文的音节比日语多**；
- **日本作曲的 A2 段常常比 A1 多几个字** ⇒ 需要额外**垫一两个音**。

## 二、断句

**断句跟的是曲子的换气点，不是原词的行尾。** 扒不准时**先怀疑断句**（十有八九出在这），再去数字数。

- 例：旋律哼成「啦—啦—啦 啦啦啦啦」，词也得照这个切成**前三后四**。
- 原曲一句 6+6 就必须写两个 6。唯一例外：整句气口确实是 12（超长句）。
- 判断依据是**这一句里重音怎么分布**。

### 断句出问题的表现（自查）

- 跟着唱会**跟丢**（"跟着跟着就丢了"）
- 句意和句意断开，不知道哪句对应哪句
- 前几句都连着，某一句忽然在半路断开
- **关联词只写了一半**（"连……都……"的后半截没了）
- **定语挂错句**（上句改了，"……的时间"还留在下句开头）

---

### 扒不准怎么办（四步）

1. **先看断句**（绝大多数毛病都出在这）
2. **其次数字数**
3. **把速度降下来**，或者开 MIDI 直接点数：有几个音就填几个字；填完**按原速再唱一遍**，喘不上气就砍字
4. 听不出气口在哪的：干脆**把扒格子的活外包给 MIDI**

> 🔍 **反向检验**：翻任何一首成熟作品，若撞见**两句拼起来 12 个字**的别扭断句，
> 大概率只是词作者手滑多按了一次回车——是个案，不是范本。真正的判据永远是**重音在这句里怎么落**。

## 三、倒字（核心）

### 是什么

**倒字 = 唱出来听着像别的字。** 三个判据：
1. 字的**调子走向跟旋律拧着来**（旋律抬上去，字调却往下掉）
2. 听起来有**歧义**
3. 出现**不雅词 / 空耳**

> 记住这一条：**乐谱上的音高是钉死的，说话时的音高是活的（相对而言）。**
> 不看你这个音在谱上是 C 还是 F，只看**这个音跟旁边那个音比是高还是低**——这就是倒字检查的操作定义。

> 🔍 **"调类" vs "调值"（别混）**：
> **调类**这一层归类（阴平、阳平、上声、去声）是**语言学**的事，**填词人可以不碰**；
> **写词管的是「调值」** —— 也就是**这个字实际唱出来的相对高低走向**。
> ⇒ 判断倒字永远看**调值**（相对走向），不看调类标签。

### 必须改的位置（按优先级）

| # | 位置 | 为什么必须修 |
|---|---|---|
| 1 | **任何句尾的字** | 句尾扎眼，藏不住 |
| 2 | **句头的动词** | 动词倒了整句动向全乱 |
| 3 | **指向性强的重要名词** | 专名、核心意象一旦倒字，听众就抓不到你在说谁、说什么 |
| 4 | **副歌全线** | 高光段，对倒字最苛刻 |
| 5 | **方位名词**（上下左右/东西南北）| 固定表达，倒了一塌糊涂 |
| 6 | **二字/三字短句** | **句子越短倒字越明显** |
| 7 | **长音上的字** | 拖得长太明显 |

### 可以放过的

- 句头非动词、句中形容词、介词
- 主歌（旋律不重复，能混过去）
- **字密、唱得快的地方**（结构紧，唱得过去）
- 拖音特别长的（够长不会听成别的）

> **但句头可以倒、要分散**——全都倒在句头就非常明显了。选择性修，**修 60% 就没什么问题**。
> 另一信号：副歌卡得准、主歌全掉下来（或反过来）叫**割裂**，比零散几个倒字更难听，三段要均衡。

### 按严重度（决策）

| 级别 | 内容 | 处理 |
|---|---|---|
| 1 | 不雅词 / 动物名 / 特殊地点 | **一律改掉**（唯一说死的一档）|
| 2 | 严重歧义 | **必改** |
| 3 | **好吃的食物**（麦芽糖→鸭蛋那类）| 比严重歧义好一点，**尽量改**但不致命 |
| 4 | 意思差不多的（幻想/幻象、一身伤/一生伤）| 可忽略 |
| 5 | 藏在句子中段 | 倒了就倒了 |

**必改 / 可放过 对照表**（上游给的现成语料，直接照着判）：

| 原句 | 唱出来 | 判断 |
|---|---|---|
| 我**收集**那些碎片 | 我**手机**那些碎片 | **必改** —— 关键动词一倒，整句意思都换了 |
| 我**用尽**所有力气写下我的答卷 | 听不清在说什么 | **必改** —— "用"正好踩在重音上，"答卷"又落在句尾 |
| 一切如同梦境一**般**美好 | 一**半**美好 | **必改** —— "般"在重音上，意思变成"美好的梦只有一半" |
| 停留在了原**点** | 原**巅** | **必改** —— 句尾 + 不知所云 |
| 注定敢爱的人**一身伤** | **一生伤** | **可放过** —— 两种唱法都是伤在自己身上 |
| **旧梦**依稀 | **就梦**依稀 | **可放过** —— 句头非动词，无伤大雅 |
| 幻**象** | 幻**想** | **可放过** —— 意思差不多 |
| 种满**麦芽糖**在山坡 | **鸭蛋** | 食物类：**尽量改但不致命** |

> ⚠️ **最后一档必须警惕**：倒成**不雅词 / 动物名 / 特殊地点**是唯一说死的一档 —— **一律改掉**。

**人名要是撞上空耳，得格外当心** —— 重点不在倒不倒，而在**倒出来的那个人是谁**，闹大了很难收场。
**方言味本身不算错，只看用在什么场合** —— 放进普通话流行歌里很突兀，可甲方点名的就是**地方民歌**时，它反而非有不可。

> ⚠️ **倒字会被记一辈子** —— 听众记住的往往是那句"听错的"。**别指望"反正没人细听"。**
>
> 🎵 **腔无所谓新旧，悦耳为上** —— 别为了追"新"把腔弄得**怪、乱、俗**。

> 📌 本表来源：上游 `examples/例1-倒字与连锁修改.md`（**摘要改写**）。

## 四、改倒字的四种手段（代价从低到高）

1. **换同义词**
   - 崩塌 → 崩溃、情诉 → 倾诉、驱逐 → 追逐
   - **孔洞 → 空洞**（干脆直接写"空洞"，它就不倒了）
   - **冷冷清清 → 寂寥 / 空荡荡**
   - **乌鸦 → 秃鹫**
   - **理解生死 → 声嘶力竭**
2. **调字序** —— 两字词对调过来试（"眼泪"换成"泪眼"这种），哪个在旋律里不含糊就用哪个，**前提是带进歌里确实不倒**；动词和它的宾语也同样可以对调
3. **两处对调**（像拼拼图）—— 本句里闯祸的那个词，去跟隔壁句子的词换个座位；**字都是好字，只是坐错了地方，挪一下就顺了**
   - 例："**星辰里**" ↔ "**沸腾的生命**"、 "**火光中枯萎**" ↔ "**破碎的鸢尾**" —— 换完就不倒了
   - **写麻了的时候也用这招**：跟前面的换换，就不麻了
4. **整句重写** —— 改太多不如重写；也可以直接复制一句**已验证好唱**的复用

### 改词的纪律（重要）

- **改一个词必须看上下文**：把它旁边的词连起来读一遍，孤立换词会让句子不通。
- **保持该位置的声调走向**：先确定这里需要什么声调组合（如"阳平+上声"），再从同韵字里挑意象合适的。
- **万能补丁"的"**：三声位置容易倒，塞个"的"救急（"的"可作轻声也可作三声）。
- **改完检查是否跑离原意太远**、是否重复用了已用过的意象。
- **保大保小**：倒字和内容只能救一头时——**先保证没有语病，再保证没有倒字**（语病是骨头断了，倒字是摔跤）。
- ⭐ **先保西瓜，再捡芝麻**：返工最常见的事故，就是一路忙着改倒字，**把原先立好的意象、情绪和故事一并改没了**。
  改字的时候眼睛要**盯着内容别散**（上句写了"踩着一地瓜子壳"，下句就还得在这个画面里收尾，别突然跳去写别的）。

## 五、三字词与短句

单字句和三字句**最费脑子**。挑三字词的时候，**选意象负担轻的那个**。

> "回头"是两个意象（回的是头）；"停留"其实是一个意象（停即是留）——
> 听到"停"就接住意思了；听到"回"还要再听一个字。

**短句里每个字都藏不住**：尽量都押上韵、清干净倒字、选意象密度低的词。
两字两字的段落也要**装内容**——字少更要塞压缩过的内容。

## 六、可听性（判断一段词好不好懂）

| 考察项 | 该往哪个方向调 |
|---|---|
| 句子平均字数 | 越短越好 |
| 常用字多寡 | 越多越好 |
| 长而复杂的句子 | 越少越好 |
| 抽象概念 | **一首歌只讲一个抽象概念** |
| 人称代词 | 要有鲜明的"你我他" |

**配套三条**：
- **简单的事情简单讲**——断舍离，只保留关键信息。
- **好钢用在刀刃上**——最精彩的留给情绪最高处（尤其副歌）。
- **路人检验法**——假装自己完全不了解背景，**看得懂吗？看不懂就回去改**。

## 七、SV 特有：倒字还可以用音高线修

改词之外，SV/IX 里还有第二条路——**调音高线**：

- 字调走向和旋律冲突 → 可以在该字上画一点 **PitchControlCurve**（音头下沉/上扬）微调听感。
- 具体手法（音头下沉/上扬/抖动）见 `sv-scripting` 的
  `references/07-melody-accent-pitch-params.md`。
- **优先级**：**先改词**（治本、不依赖调校），改不动或不想动词时才用音高线救（治标、且幅度画过头会出电音）。

> 倒字检查流程（操作顺序）：
> ① **念出来，再唱一遍**（看着歌词发现不了倒字）→ ② 用"不顺感"定位 → ③ 逐字比对相对音高 →
> ④ 按位置分级筛（句尾→句头动词→重要名词→副歌→方位词→短句）→ ⑤ 按严重度决策 → ⑥ **隔一晚再改**（改不动就睡一觉）

## 八、重音（轻重格）—— 词的轻重要和旋律的轻重对上

> 📌 来源：`SynthVCopilot-SKILLS\lyric-writing\references\字数与咬字.md` §五（**摘要改写**；
> 上游许可 = Apache-2.0 + Commons Clause + Additional Terms，source-available —— **不逐字照抄**）。

**声调只是第一层**（§三 讲的就是它），**词内部的轻重搭配**同样得跟旋律的轻重合上拍。
它长得像倒字，根子却是**重音落错了位置** —— 所以"轻重对不上"归本节管，**别塞给 §三**。

**四个改词实例**（同类型的轻重对照，可直接套用）：

| 原词 | 问题 | 换法 |
|---|---|---|
| **璀璨** | 两个字**都吃重**，卡不进"重—轻"的旋律 | 换 **微光**（微重、光轻）／ **幽暗** ／ **几点灯火** |
| **争斗** | 同上，两字都重 | 找"**前重后轻**"的词，如 **出售** |
| **入梦** | "梦"是重音，可旋律里**第一个字**才重 | 要调（换词或换位置）|
| **鸢尾** | "鸢"太**重**，这半句旋律两个音一样重 ⇒ 该是轻声 | **换位置** |

**关键认识**：

> **在填词人眼里，重音这回事，说到底就是断句的事。**
> 语言学上叫**重音**，填词上叫**断句** —— **表象一样、解释方式不同**。
> ⇒ 排查时可以和 **§二 断句**一起做。

**典型案例（重音错位 → 空耳的完整链条）**：台词写"**妈已经走十年了**" ——
"妈"没被读成重音、"已"后头也没停半拍，一开口就滑成了"**蚂蚁竞走十年了**"。

> 🔗 **与旋律侧对接**：**哪几个音算"重"** 见
> `sv-scripting/references/07-melody-accent-pitch-params.md` **§1 重音判断**
> （强拍 / 时值 / 跳进 / 歌词语义 / 邻音降权）。
> **分工：本篇解决"词怎么改"，07 解决"哪些位置算重"。**

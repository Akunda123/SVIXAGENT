# 语体、质感与国风

> 决定一段词"看着尬不尬"。核心判据只有一句：**看着不尬**。
> 也是最容易自查失败的一块（**半文不白**是新手最高发的问题）。

---

## 一、质感统一

**落在这三处统一上**：
1. **一首词内部的语体要成一路**（书面腔／口语腔、文／白别混着来）
2. **歌词的情绪要和编曲对得上**
3. **同一段落里描述手法保持一致**

**最直白的判据**：我把词读一遍，**能不能被你拽进那个情绪、我会不会出戏**。
出戏的比喻：**在《猫和老鼠》里看见擎天柱，就纯扯。**

### 书面 vs 口语

对照：书面"我在售卖苹果" ／ 口语"我在卖苹果，5 块钱一斤"。

整篇定调后，必须保持口语的**程度和比例**——口语段落一路口语到底，
中间忽然插进一句"雨落青山"这样文绉绉的话，连贯感当场就断。

**段落内描述方式也必须统一**：前两句"天色渐暗，心情如何如何"，
紧跟着冒出"我回想起跟你一起去吃冰淇淋"，听众立刻被拽出情境。
要换表达方式，**必须留过渡口**。

## 二、半文不白：语体为什么会冲突

### 判定公式

> **拿古意象，配现代写法 = 好**
> **反过来，意象是今的、笔调却端着古腔 = 尬**   ← 多数人出问题都是这一种

**正面拆解**（逐句称赞的古风词）：

| 例句 | 好在哪里 |
|---|---|
| 北冥有鱼，云南迁扶摇 | 鲲鹏是《逍遥游》的典，意象纯古 |
| 羽翼从林下**催生**浩渺 | "催生"本是今人的字眼，紧跟"浩渺"又把氛围拽回古处，所以不尬 |
| **只一瞬**，晚风**去往**九霄 | 这两处措辞都带今人口吻，意象偏偏落在古处 |
| 把旧年月折成纸船，顺水漂进那年的渡口 | 用词和语法是今人的白话，落点却全在古意上 |
| **融**沧海进血液 | 就一个"融"字，气魄撑得极开 |

为什么好：**既顾到作者的艺术追求，也顾到听众能不能接住**——外行听着"好像很厉害"，
内行一听就知道典从哪来。**两边都有得品，谁也不落空。**

### 反面案例：整段塌掉

> 例子（某首古风词的前四句）：寒潭照影 / 孤雁南飞 / 剑上霜未消 / **我到底还在等什么**

头三句好不容易才攒出古意，**末了一句直通通的大白话，整座台子当场就塌**。

其他同类事故：
- "剑鸣三更 灯影摇晃"（还行）→ "**这波操作我属实没看懂**"（完蛋）
- "**晓风残月** 照我三世"——柳永那句本写离情，硬塞进"三世轮回"，只为凑上韵脚
- "红袖添香" 紧跟着 "**一刀断绝**"——这两笔之间有任何关联吗？
- "灯下红豆落笔 / **你在哪儿呢**"——前面还文言，后面直接找人，接得上吗？

> **单看每一句未必差，坏就坏在拼到一处：语体打架、意象各说各话、通篇只是在码字。**

### 规则

- **半文不白等技巧成熟后再动手**。不是不行，但要有很成熟的能力才写；
  **做不到就老老实实写白话。**
- **古风意象来源太好猜也是坏事**——中文听众受过的基础教育相近、背过的名篇相近，
  你从《水调歌头》搬，听众心里都有数。

## 三、国风 / 中国风 / 古风（三个词不是一回事）

| 词 | 比喻 | 实质 |
|---|---|---|
| **国风** | 大染缸 | 凡带中国传统文化元素/意象的都算（武侠、仙侠都在里面）|
| **中国风** | 改良汉服 | 有古有白那套，本质是**套了皮的现代流行**——扒掉皮剩下的就是流行歌 |
| **古风** | 现代复原的汉服 | **门槛最高** |

### 古风的门槛真正卡在哪

**门槛不在断句、不在词格、也不在发音，而在于古人的行文逻辑、语法和遣词造句。**

词格是最好填的——给你词格用现代白话文填进去，那不是古风。
**只要词里出现了偏现代的语法、语体或行文习惯，它就只算广义的国风，够不上狭义的古风。**

### 文白比例

写中国风参考：**七成白、三成文**。到六四味道就冲了、港剧味就出来了，语体冲突尬度超标。

### 这些时候不妨再白一点

意象已经整了，就去抠措辞让措辞不那么尬，**往往是再白一点就顺了**：
> 原："愿……还童无忧愁入睡"（"还童"前没有"返老"很怪，"无忧愁"繁复）
> 改成（把语体再往白里挪一点）：**愿我能如童时般无忧入睡**

## 四、用典（写中国风最容易翻车处）

### 必查三样：**歧义、季节、原意**

| 词 | 问题 |
|---|---|
| **夜来香** | 撞"倒夜香"（夜壶）——味太冲 |
| **二八年华 / 年方二八** | 容易串到"小尼姑年方二八"那句戏词上 → 换成"豆蔻年华"，或者索性写"长大" |
| **逝者如斯** | 原意时间流逝，但送别时用读起来像送终 → 改"光阴似箭" |
| **冰心** | 出自"一片冰心在玉壶"，说的是品格干净，跟"心凉了"没关系 → 改"寒星""寒夕" |
| **长鲸吸川** | 说的是豪饮，跟"吸取灵感"没关系 |
| **举案齐眉** | 本义是夫妻相敬，形容星球就跑偏 |
| **迢迢** | 本义是远，形容微风就跑偏 |
| **愿得君心似我心** | 指向性太强（闺怨语境），前面写求仙问药就割裂 |

> **从古诗里直接拿句子时，一定查出处对应的季节和意象——一查发现对不上就完了。**

### 改名句要改得通

> 原："彩舟云淡，星河鹭起" → 改："彩舟淡兴露起" = 没人看得懂了

"彩舟云淡"画的是彩船像浮在云上，情境立得住；改成"彩舟淡"，就没人知道在说什么了。
**改名句是允许的，但改完得自己讲得通。**

### 缝合时不能犯的两条

1. **扒得太重**——直接用原句，原作氛围跳出来压过你自己的东西
2. **硬凑在一起就很尬**——缝上了却没化开

**及格线：读起来不露拼接痕，只让人觉得在致敬，而不像直接缝上去。**
整段照搬原文反而更糟——原作的意思半分没落地，像"把字缝过来就完事，空得很"。

## 五、季节与物候

**规则：写春最多写到夏为止；写秋最多从夏起笔、到秋收住。要写清明，中间那段就一直停在清明。**

反面（一段里季节全乱）：
> "杨柳才青"（早春）→ "大漠孤烟"（一下跳到塞外）→ "霜叶红透"（春天没过完就入秋）→
> "鹊桥相会"（七夕在夏末，怎么排在霜叶后）→ "一梦醒来是清明"（七夕刚过就清明？）

**常识清单**：
- 惊蛰以前能开花的，**也就梅花**（温室里的杜鹃过年那阵能开一开）
- 自然在室外的花，都惊蛰之后才发芽才开
- **叶子都绿了，燕子才回来**
- **荷花一年生**，夏天败了就没花了（只能写"残荷"）
- **银杏的花小到几乎看不见**，古人从不拿它入典；二三月要写花，就写**迎春花**（花朵大而显眼）
- "彤云"得天色真红透了才配用；天色偏黄偏灰，就写"黄云""灰云"

> **落笔挑物象之前，先弄清这株植物、这只动物身上有什么特点。**

## 六、语体上的取舍

### 日语词得换成中文说法

日语词换成对应中文说法：
- "**羁绊**"——日语指人与人的联系，**中文里是碍手碍脚、碍事**
- "**宴座**"——中文里没这个词
- "全然/预想要/连勇气都失去了"这类**日式句法**

听得最多的一句吐槽："味儿太重，正常人谁这么讲话。"

### 念白

**很多作曲人非常讨厌念白。** 只在甲方明确要求时写；其余把这段信息交给旋律和歌词本身。
> 原理：**念白就是听不懂才显高级；一旦听明白，立刻掉价。**
> 好比插一句"师父，咱们这是要去哪儿呀"，整首歌的格调立刻往下掉。

非要写点听不懂的，那个"听不懂"也**必须有逻辑、有个 1、2、3**。

### 中文歌就全用中文

中文听众句句都听得懂，中间蹦出一句英文，割裂感立刻就来。日语歌敢夹英文，是因为"日式英语"早成了气候；
**中文还没养出成气候的中式英语。要造异质感，就靠意象和语体的变化去拿。**

### 只挑中文里现成的词

中文里查不到的词，硬写出来读者只能猜；**把日语词原样搬过来用，同样算造词**。
古风里有时确实可以造梗造词，但**造词等完全熟练之后再动手**。
底线：看的是你用得住用不住；新手造的词，多半是硬凑出来偷懒的。

### 审核规避

敏感词、粗鄙词能换就换；拿不准的找做审核的人问一下。

## 七、"故意写得不那么古"行不行？

别人说你的词不够古，最常见的挡箭牌是"我就是故意写得没那么古"——**这话站不住**：
嘴上说故意不往古里写，手上却做不到，落点只剩两个：**要么全古、要么全不古**。
要什么效果，就得让全篇**稳稳停在同一种效果里**。夹在两种效果之间的，不叫风格，叫失控。

### 先定选题，语体跟着选题走

**选题的分量高于语体、也高于体裁——第一件事是想清楚写什么。**
- 写先秦 → 要不要"古"成那样
- 写民国 → 半文半白正合适
- 重构宋词 → 学那个时代的用词与味道，典也只用那个时代的
- 完全架空虚构 → 没有硬性要求，但一般也会挂靠一个朝代来重构

**两项必查**：① 语体从开头到结尾是不是一条线 ② **史实有没有对不上的地方**（一个历史硬伤就让人不信了）。

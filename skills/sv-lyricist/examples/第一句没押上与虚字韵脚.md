# 案例：第一句没押上，又拿虚字充韵脚

> 📌 来源：SynthVCopilot-SKILLS\lyric-writing\examples\例2-第一句没押上与虚字韵脚.md（**摘要改写**；上游 source-available，不逐字照抄）

> 一句话结论：韵的基准是**第一句的韵脚**，第一句丢了整段就散；而句尾连塞虚字不是技巧问题，是积累问题——把虚字前面那个实词提到句尾去才治得了。

## 一、原作片段

一段示意的主歌（四句，同一段内应当同韵）：

```
[Verse 1]
我还留着你落在门口的那只发卡
伞上的雨还没干，滴成一小片花
想说的都卡在喉咙，成了半句废话
你大概早把它丢在别的城市
```

同一首里的另一段，句尾全是虚字：

```
[Verse 2]
旧照片我压在箱底了
台灯坏了一个星期吧
那年我们话都说不完呢
现在连名字也不提了啊
```

## 二、问题在哪

### 问题一：第一句没押上（新手第一通病）

先把四个韵脚字横向排一遍：**发卡 / 花 / 废话 / 城市**。

- 「花、废话」落在**发花辙（a / ia / ua）**，中间两块砖对上了；
- 第一句的「发卡」和第四句的「城市」掉到 i 韵——开头和结尾都没跟上。

注意：「发卡」的「卡」是 ia 韵，**同韵不要求韵母完全一样，韵头可以不同、韵尾相同就算同韵**，所以它本来完全押得上。问题不在能不能押，而在**写第一句的时候根本没打算押**。这就是最典型的病：**韵是写到一半才摸出来的，摸出来之后前面的句子就不肯回头改了。**

更常见的变体是「后面三句全押上、第一句丢了」。这种词哪怕故事完整、情绪也贴，**整体观感照样差一档**——听众说不清哪里不对，只会觉得"不整"。

四句一段，能走的只有这两条路：

- **四句全押上**；
- 或者**放过第三句**，1、2、4 押上（照七言绝句的规矩：第三句可以不押）。

**第一句必须押上。** 开头没押住，后面押得再准也救不回来。

### 问题二：拿虚字当韵脚

第二段的四个句尾：**了 / 吧 / 呢 / 啊**——全是虚字。

想不出韵脚的时候，最省事的做法就是往句尾塞一个语气词顶包。**偶尔用一次还行，连用两次以上就很尬。** 一段里三四个句尾全是虚字，等于当场告诉听众你的词库见底了。

这不是技巧问题，**是积累问题**——只能靠多看、多攒好句子。同理，句尾连着四个「下、下、下、下」这类同字重复也一样刺眼。

按我们仓的判据，这一段同时踩了 **凑韵**（句尾那个词在句子里不承重）和它更露骨的一种变体：**拿没有实义的虚字反复顶韵脚**。这两样都属于"念一遍就听得出来"的硬伤。

## 三、怎么改

### 问题一的改法：先定韵，再回头改第一句

**改哪一头，看哪头好词多。** 这段中间两句已经在发花辙上，动开头和结尾两句代价更小，所以统一往 **a 韵**收。

还有一条可唱性的理由：**句尾要拖长音的地方，韵留给开口音。** 「a」口型张得开，在副歌和长音上唱得住；i 韵（尤其 zhi / chi / shi 那一组齿音）收着嘴，该放的时候放不出来。这段句尾如果在副歌要延长，选 a 韵更顺。

一改（无效）：

```
我还留着你走那天的一把钥匙      ← 还是 i 韵，等于没改
```

二改（犯**重韵**）：

```
我还留着你走那天的一朵干花      ← 押上了，但上一句已经用过「花」
```

同一个字相邻两句重复押，比不押更扎眼；而且「干花」和后面"丢在别的城市"的物件对不上，**意象也没接住**。作废。

三改（又撞重韵）：

```
我还留着你走那年留下的话        ← 和第三句的「废话」重「话」
```

作废。

**最终版**：

改成同一层意思里的另一个具体小物——「发卡」既保住了"留着对方一件小东西"的原意，又不与「花 / 废话」重字：

```
我还留着你落在门口的那只发卡
伞上的雨还没干，滴成一小片花
想说的都卡在喉咙，成了半句废话
你大概早就换了钥匙，换了家
```

四个韵脚：**发卡(ia) / 花(a) / 废话(ua) / 家(a)** —— 发花辙一韵到底，没有重字，第一句押上了。

第四句的改动不只是换韵：原句「丢在别的城市」是单方向的抛弃，改成「**换了钥匙，换了家**」是"重新开始过日子"——**换了个更具体、更疼的说法**，还和第一句的"留着一件小东西"形成前后回勾：一个留着，一个换了。这就是**提到就要有用**，首句抛出的物件在段尾接到了回应，不是废笔。

### 问题二的改法：把虚字前面那个实词提到句尾

原则一句话：**虚字删掉或者前置，让句尾落到一个实词上。** 四句统一改成 **江阳辙（ang / iang / uang）**：

```
旧照片我压在箱底了      →  旧照片还压在箱底，没丢也没忘
台灯坏了一个星期吧      →  台灯坏了半个月，屋里一直没光
那年我们话都说不完呢    →  那年我们有的是话，能说到天亮
现在连名字也不提了啊    →  现在连你的名字，我都不敢想
```

改后韵脚：**没忘(ang) / 没光(uang) / 天亮(iang) / 敢想(iang)** —— 同辙、全是实词，而且都落在能承重的动词上。

留一个作废的尝试，说明**换韵脚不能顺手把意思带偏**：

```
现在你的名字我也不提    ← 「提」是 i 韵，出韵了；而且又把话咽回去，情绪反了
```

这一改除了换韵，还把"摊开讲情绪"换成了**动作和结果**（没丢没忘、没光、不敢想），符合 `references/意象与修辞.md` 的「多写动作，少写感受」。

### 顺带记住的几条押韵红线

| 韵忌 | 含义 | 怎么避 |
|---|---|---|
| **凑韵** | 为押韵硬塞词，句子接不上 | 每个韵脚字都得在句子里**站得住** |
| **重韵** | 同一个字重复押 | 同样的字隔远一点，分到不同段落 |
| **倒韵** | 为押韵造词或倒装 | 一律改掉（把日语词搬进中文也算造词）|
| **哑韵** | 挑了复杂元音，可用字太少 | 一般选单元音押 |
| **僻韵** | zhi / chi / shi 那一组 | 不在十三辙里、又是齿音，尾韵留给别的韵组 |

**一段之内守住同一个韵**，换韵只发生在段与段之间；**旋律完全相同的两段最好保持同韵**；**副歌的韵脚必须收住**。

**唯一可以不押的地方**：拖得极长的长音上，喊到破音、拖足好几拍，押不押根本听不出来——**这种地方先顾唱得顺，押韵往后放**。反过来，**两三个字的短句要尽量都押上**，字少藏不住，不押唱起来就怪。

## 四、可复用的判断标准

1. **定韵看第一句，不看曲风。** 第一句的韵脚字是什么，整段就跟着它走；写完先横着比一遍四个句尾，趁早发现开头丢了。
2. **改韵脚先算成本**：动一两句能收回来，就别动三句；哪头现成的好词多，往哪头靠。
3. **同步查重韵**：改一个韵脚字之前，先把这一段已有的韵脚字列出来——同一个字重复，比不押韵更扎眼。
4. **虚字连用两次以上就动手**：把虚字前面的实词提到句尾（"压在箱底了" → "没丢也没忘"），虚字删掉或前置。
5. **句尾长音优先开口音**：要放要喊的位置用 a、ang 这类张得开的口型，别把韵脚留在 i、ü 这类收着嘴的音上。
6. **换韵脚时盯住语义**：换字不能顺手把方向换反（拒绝换成咽回去，情绪就掉头了）。
7. **首尾要回勾**：第一句抛出的具体物件或动作，末句最好接住它，别让它在段尾消失。

## 五、检查清单

- [ ] 四句的**韵脚字**横着排过一遍了吗？第一句押上了吗？
- [ ] 这一段里有没有**同一个字被押了两次**（重韵）？
- [ ] 句尾有没有连着两个以上的**虚字**（啊 / 吧 / 呢 / 了 / 的 / 哒）？
- [ ] 有没有为了押韵**硬塞**进来的词？（单独拎出来读，它站得住吗）
- [ ] 这一段有没有**中途换韵**？换韵是不是只发生在段与段之间？
- [ ] 副歌的韵脚**收住**了吗？旋律相同的两段是否同韵？
- [ ] 句尾要拖长音的地方，用的是**开口音**吗？
- [ ] 两三个字的短句押上了吗？（字少藏不住）
- [ ] 极长的长音上，有没有为了好唱**主动放弃**押韵？
- [ ] 换掉的韵脚字，有没有把**语义方向**带偏（该拒绝的答应、该放下的回头）？

# 案例：倒字与连锁修改

> 分类：填词/咬字 ｜ 症状：词看着没问题，唱出来听着像**别的字**，甚至是不雅的谐音

## 一、原作片段

一句已填好的词"狂奔时仍然握紧你**手心**"，旋律在这里是个**长音**（拖 2 拍）。
试唱出来听着像"握紧你**收心**"——完全变了意思。

## 二、问题在哪

**倒字 = 唱出来听着像别的字。** 三个判据：
1. 字的声调走向和旋律走向**相反**（旋律往上，字调往下）
2. 听起来有**歧义**
3. 出现**不雅词 / 空耳**

这句命中的是 ①+②：`手心`（上声+阴平）按旋律走向唱，`手`字被拖在长音上，
调值走向和"收"接近 → 听成"收心"。

**关键：这个位置在"必须改"的清单里**——
- ✅ **长音上的字**（拖得长，藏不住）
- ✅ 句尾附近（扎眼）
- ✅ 指向性强的重要名词（"手心"是核心意象）

## 三、怎么改（连锁修改）

**❌ 错误的改法**：把"手心"直接平替成"的**心**" → "握紧你的心"，变成偷心了，意思跑偏。

**✅ 正确的改法**：后面（"你的心"）音调要保持、词也动不了，那就**改前面的词**：

```
改前： 狂奔时仍然 握紧 你手心
改后： 狂奔时仍然 拥有 你的心      ← 改前一个词，保住后段音调与原意
```

**纪律**：改一个词必须**看上下文**——把它旁边的词连起来读一遍。孤立换一个词会让句子不通。

## 四、可复用的判断标准

1. **倒字都是改出来的，第一遍一定有**——不慌，但**必须念出来再唱一遍**（看着歌词发现不了倒字）。
2. **按位置分级筛**（先改这些）：
   句尾字 → 句头动词 → 指向性强的重要名词 → 副歌全线 → 方位名词 → 二字/三字短句 → **长音上的字**。
3. **可以放过的**：句头非动词、句中形容词、介词、主歌、字密唱得快的地方、拖音特别长的（够长不会听成别的）。
4. **句头可以倒，但要分散**——全挤在句头就很显眼；挑一部分动手，**改掉六成就差不多稳了**。
5. **改倒字的四种手段**（代价从低到高）：换同义词 → 调字序 → 与相邻句换位置 → 整句重写。
6. **保大保小**：倒字和内容只能救一头时——**先保证没有语病，再保证没有倒字**（语病是骨头断了，倒字是摔跤）。
7. **万能补丁"的"**：三声位置容易倒，塞个"的"进去救急（"的"可作轻声也可作三声）。

## 五、检查清单

- [ ] **念出来、再唱一遍**（雷打不动：看着歌词发现不了倒字）
- [ ] **句尾**的字查了吗？**句头的动词**查了吗？**指向性强的重要名词**查了吗？**副歌全线**查了吗？
- [ ] 有没有**长音上的字**（拖 2 拍以上，藏不住）？
- [ ] 筛选顺序对不对：**长音上的字**排第一位，接着是句尾与句头动词，再到指向性强的重要名词，最后才轮到副歌、方位词和短句？
- [ ] **句头倒字是否分散**？（全倒在句头更明显；**修 60% 就够**）
- [ ] 改完有没有**把上下文连起来读**？（孤立换一个词会让句子不通）
- [ ] 有没有**语病**？（分量上语病更重：倒字只是摔一跤，语病等于骨头断了）
- [ ] 撞上**不雅词 / 动物名 / 特殊地点**了吗 → **一律改掉**（唯一说死的一档）
- [ ] 副歌准、主歌全掉（或反过来）= **割裂**，比零散几个更明显 → **三段要均衡**
